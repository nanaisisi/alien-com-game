# ドキュメント・リンクにおけるパス形式ルール (Path & Privacy Rules)

## 1. 原則：リポジトリ内相対パスの使用

- Markdownドキュメント（README、INDEX、仕様書等）に他のドキュメントやコードへのリンクを記述する際は、**必ずリポジトリ内または親ディレクトリ基準の相対パス（例: `./doc/GAME_DESIGN.md`, `../src/main.rs`）を使用**してください。
- `file:///C:/Users/...` や絶対パスによるローカルファイルリンクは、環境依存であると同時にユーザー名（個人情報・本名）を含むため、**コミット・保存対象のドキュメントに記述することを厳禁**とします。

## 2. システム指示（システムプロンプト）との優先順位

- アシスタントへの全体指示（システムプロンプト）に「github style markdown links with the file:// scheme」とある場合でも、それは**チャットの対話メッセージ内でのみ適用されるルール**です。
- **リポジトリ内の永続ファイル（Markdownファイル等）へ書き込む内容には適用せず、必ず相対パス**を用いてください。
