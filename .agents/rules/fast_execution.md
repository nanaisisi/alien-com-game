# 調査・解析および自律ループ抑制ルール

AIアシスタントは、以下のルールを厳格に遵守してください。

## 1. 調査・解析の上限
- ファイル閲覧（`view_file`）や検索（`grep_search` 等）は、**1つのリクエストにつき原則3回以内**に留めること。
- 無限に周辺ファイルや無関係な依存コードまで辿らないこと。
- 3回程度の確認で判断がつかない、または情報が不足していると感じた場合でも、勝手に追加調査を繰り返さず、**「現時点で判明していること」と「確認が必要な点」を簡潔にまとめてユーザーに回答・確認する**こと。

## 2. 計画モード・過剰な手順の省略
- ユーザーから明示的に長大な設計書の作成を指示されていない限り、過度な計画書作成（`implementation_plan.md` 等）に時間を浪費せず、速やかにコードの修正・提案・回答に移ること。
- 修正箇所が局所的（1〜2ファイル）な場合は、即座に修正内容を提示または適用すること。

## 3. 簡潔かつ迅速な応答
- 前置きや過度な自己対話を省き、結論ファーストで回答すること。
