# ALIEN COM GAME

## 導入方法

日本語・絵文字・アイコンフォントに UDEV Gothic (Nerd Fonts) を用いる。`assets/fonts/` に `UDEVGothicNF-Regular.ttf` および `UDEVGothicNF-Bold.ttf` を配置する。

## 改変を推奨

このゲームは私専用なので、このシステムは改変して自分の好み・標準に合わせることを推奨する。
ゲーム名称を変更して好きなシステムに改変するとよろしい。

## 推奨環境

- CPU: intel core i3相当以上(2020年以降)
- メモリ: DDR4・16GB以上(2020年以降)
- GPU: VRAM8GB以上(2020年以降)
- SSD: 空き容量100GB以上(2020年以降)
