# フロンティア脱退勢力（自発的失踪者）と段階的領土要求システム

本ドキュメントは、入植惑星における非国家第三極勢力「自発的失踪者（脱退者・漂流コミュニティ）」の生態・社会構造と、自然国境・実効支配に基づく「段階的領土要求」のメカニクスについてまとめた検討資料です。

---

## 1. 自発的失踪者（Deserters / Frontier Dissidents / 第三極コミュニティ）

### 1.1 発生背景と社会・技術基盤

* **発生機序**:
  * 国家による苛烈な開拓ノルマ、兵役義務、思想統制、あるいは本星条約に縛られた官僚的統治から逃亡・脱退し、公的台帳から「自発的に失踪」した市民・技術者・脱走兵によって形成される。
* **技術・物資の自活構造（民生ベース）**:
  * 正規軍のような先進軍需コンプレックスや潤沢な兵站線を持たない。
  * **民生用・開拓用の作業機械、土木重機、農業プラント、現地資源のDIY精錬**をベースに自給自足コミュニティを構築。
  * 故障部品は現地素材や他国スクラップからの削り出し・3Dプリンタ代替によって賄う。
* **武装・軍事力（「多少こなれた」現地適応）**:
  * ハイテクな最新鋭兵器（高出力荷電粒子砲や完全自動FCS）は維持不能。
  * しかし、過酷な原生生物（エイリアン）の襲撃を生き延びてきたため、**民生用大型クローラ・トラックの現地装甲化、削岩用レーザーや発破用火薬の兵器転用、手慣れたトラップ・対戦車バリケード**など、**「泥臭く実用的な武装化が多少こなれた」** 独特の戦術・ゲリラ戦能力を有する。

### 1.2 人口構成と地理的グラデーション

```text
[国家A Core] ─── (自国近傍) ───► [緩衝地帯 / 未開拓深部] ◄─── (他国近傍) ─── [国家B Core]
                  │                           │
           【A国出身者主体】           【多国籍混在コミュニティ】
          (言葉・文化が通じやすい)     (旧A国兵・旧B国技師・密輸商人)
          (懐柔・再統合が比較的容易)   (警戒心高、高度な技術融合、外交火種)
```

1. **自国近傍の集落**:
   * 自国からの脱走者・脱退者が過半を占める。言語・文化・価値観が自国と地続きであり、元家族や知人が自国領内にいるケースも多い。
2. **国境間緩衝地帯・辺境深部**:
   * 複数国家からの失踪者が寄り集まり、多国籍化したグレーゾーン・独立集落を形成。
   * 国家間の対立を逆手に取った密輸拠点や、非公式な闇市場（兵器パーツ・違法資源の交換）として機能する。

### 1.3 プレイヤー（国家）とのインタラクション

原生生物（エイリアン）が「駆除か生態系調和か」という環境的脅威であるのに対し、失踪者は**「人間社会と知性を持った政治・軍事・経済の第三極」**として振る舞う。

* **① 取り込み・帰順（統合アプローチ）**:
  * 医薬品、基礎工業品、発電セルなどの民生支援や恩赦（公的市民権の再付与）、あるいは「自治特別区」としての承認を通じて自国領へ平和裏に再統合。
  * 自国近傍の集落ほど統合コストが低く、即座に**熟練した現地開拓民・偵察部隊・土木労働力**として還元される。
* **② 敵対・武力排除（制圧アプローチ）**:
  * 補給線襲撃（通商破壊）や自国の重要資源タイルへの不法占拠に対して軍事介入を行う。
  * ただし、自国出身者が多い集落を強硬に武力弾圧・虐殺した場合、**自国内の民心低下、政治的反発、軍内での脱走率上昇**といった内政ペナルティ（反動）が発生する。
* **③ 他国との外交摩擦・スパイ工作（外交アプローチ）**:
  * 他国出身者が混在する集落を保護・併合した際、元国家から「指名手配犯や脱走兵、逃亡技術者の引き渡し」を巡る公式抗議・最後通牒を受ける。
  * 逆に対立国の国境付近にある失踪者集落へ武器・物資を横流しし、敵国の後方を攪乱させるゲリラ勢力として利用する謀略も可能。

## 2. 段階的領土要求（Territorial Claims）システム

### 2.1 根幹原則

1. **自然国境（Natural Borders）志向**:
   * 人為的な直線境界ではなく、**山脈の尾根、大河川、大峡谷、海岸線**など、天然の防御障壁となる地形区切りに向けて領土要求が自然発生・延伸する。
2. **「言うだけならタダだが、実効支配が必要」**:
   * 主張（Claim）を発すること自体には大きな資源コストはかからないが、**主張しているだけでは領有権は成立しない**。
   * 前哨基地（Outpost）の設営、哨戒部隊の駐留、道路・インフラ網の接続といった**「実効支配（Effective Control）」の既成事実化**が伴って初めて国際的・法的に有効化される。
3. **時勢に応じた動的変化**:
   * 国力、軍事バランス、資源発見、周辺情勢に応じて、国家が抱く領土要求の度合いは有機的に推移（格上げ・格下げ・撤回）する。

### 2.2 領土主張の4つの強度区分

| 区分 | 主張の性質・範囲 | 外交協議 | ゲーム上の挙動・効果 |
| :--- | :--- | :---: | :--- |
| **近傍領土主張** (Contiguous Claim) | 自国都市・前哨地の直近で、**他国の勢力圏から離れている**自然領域。 | **不要** (自明の権利) | ・他国からの摩擦は生じない。 / 領域内に失踪者集落がある場合、内政問題（自国の法治下）として保護・取り込みの正当性を得る。 |
| **超積極的領土主張** (Intransigent Claim) | 国家の防衛・経済上、**「絶対に他国へ譲れない」死活的要衝**。（チョークポイント、超希少鉱脈、重要地熱源など） | **協議不可** (妥協拒否) | ・**開戦事由（Casus Belli）に直結**。 / 他国がこの領域に進入・前哨基地を建設した場合、即座に外交危機・最後通牒へ発展。 / 国内世論・主戦派が強硬化し、撤回すると政権支持率が暴落する。 |
| **積極的領土主張** (Assertive Claim) | 自然国境までの拡大を目指すが、他国とのパワーバランス次第で妥協可能な領域。（大河の対岸、豊かな森林・盆地など） | **協議可能** (バーター可) | ・他国との境界画定条約における**「外交交渉カード」**となる。 / 「このタイルの領有を認めるなら、通商特権を与える」「共同開発区として非武装化する」といった取引が可能。 |
| **消極的領土主張** (Passive / Dormant Claim) | 「地理的・歴史的には我が国の勢力圏になり得る」と**名目上だけ言い置いておく**領域。（遠隔の自然障壁内、他国勢力圏近傍） | **協議可能** (容易に撤回可) | ・平時は実効支配を行わず、他国との決定的な摩擦も避ける。 / 相手国が弱体化（敗戦、内乱、国家解体）した際に、**「以前からの正当な要求である」として即座に武力進駐・実効支配へ乗り出すための伏線**となる。 |

### 2.3 実効支配の定着（Status Quo メカニクス）

```text
[領土主張の宣言] ──► [実効支配の開始] ──────────► [既成事実化 (Status Quo)] ──► [正式領有 (Core)]
 (言うだけならタダ)    (前哨基地・哨戒戦闘団)      (年月の経過・インフラ接続)     (国際承認・安定)
                       ※他国との摩擦発生           ※抗議・反発の風化             ※反乱リスク低減
```

* **主張の格上げ・格下げのトリガー**:
  * **資源探査**: 調査部隊が未知の特異資源を発見 → 「消極的/積極的」から「超積極的」へ引き上げ。
  * **軍事的劣勢**: 隣国が強力な機甲戦闘団を前進配備 → 「超積極的」を維持できず「積極的（協議妥協）」へトーンダウン。
  * **失踪者コミュニティの存在**: 自国寄りの集落が自発的に生活圏を広げている場合、それを追認する形で「近傍主張」や「積極的領土主張」が自動生成される。

## 3. 「失踪者」と「領土要求」のシステム的連動

1. **実効支配の代行者としての失踪者**:
   * 国家が公式な軍隊や開拓団を送る前に、失踪者コミュニティが自然国境の要所に集落を形成している場合がある。
   * 国家はこれを取り込む（懐柔・支援する）ことで、正規軍を動員せずに**「民生ベースの既成事実」として実効支配の基盤を手に入れる**ことができる。
2. **領土紛争のプロキシ（代理）化**:
   * 「積極的領土主張」が衝突する緩衝地帯において、相手国の失踪者集落を自国が支援して反乱を起こさせたり、逆に自国出身者を煽動して相手国の前哨基地周辺でサボタージュを行わせるなど、直接戦争を避けた非対称戦の舞台となる。
