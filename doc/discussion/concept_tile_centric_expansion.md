# タイル個別化・脱都市型拡張システム 設計仕様書 (Tile-Centric Expansion & Decoupled Infrastructure System)

## 1. 思想的背景と基本コンセプト

### 1.1 「脱・都市中心主義（Post-City Centric 4X）」
従来の4Xゲーム（Civilization等）では、「開拓者が単一マスに都市を建設し、その都市が全方位に円状の領土を広げ、人口・食糧・工業・研究・防衛を一手に抱え込む」という**都市中心主義（City-Centrism）**が標準となってきた。
しかし、本作の目指す「未知の惑星における過酷な入植開拓」「泥臭い前線軍事行動」「多段階サプライチェーンと町工場」「大戦略タイル×343サブタイルの作戦術」において、この方式には以下の強い違和感・構造的矛盾が生じる：

1. **不自然な全能性**: 荒野の山岳に設営した単なる「防衛用レーダー監視所」や「特定レアメタルの露天採掘場」を置きたいだけなのに、食糧生産や市民議会を持つ「都市」を丸ごと建てさせられる。
2. **点による面の支配の欺瞞**: 都市の周りのタイルは単なる「出力タイル（市民を配置してパンやハンマーを吸い上げるマス）」に格下げされ、タイル自体の土地の文脈や現場性が失われる。
3. **作戦術の矮小化**: 戦争が「都市の耐久力を削って都市を落とす」だけの単調な攻城戦になり、敵の「送電中継幹線」や「燃料パイプライン」「町工場クラスター」をピンポイントで断ち切って前線を兵站枯渇に追い込むという**近代・未来戦の醍醐味**が損なわれる。

### 1.2 タイル個別化の基本思想
本作では**「特権的かつ万能な都市オブジェクト」を完全に廃止**する。
すべての親タイルは大戦略マップ上で対等な「土地（領域）」であり、プレイヤーや勢力がどのようにインフラを引き、どのような施設群を展開するかによって、**タイル単位で個別の役割・気質・自律性を持つ機能サイト（Functional Site）**へと変貌・進化する。

> **「都市」の再定義**:
> 「都市」という固定のユニット・建造物は存在しない。
> 高度に開発された「居住ドーム群タイル」「商業・流通ハブタイル」「中枢行政府タイル」「軽工業コンビナートタイル」などが隣接して高密度に結合した**「空間的クラスタリング（集積現象）」の総体**を、便宜上「大都市圏（Metropolitan Area / Agglomeration）」と呼称する。

## 2. タイルの個別自律ステータス

各親タイルは、単なる地形（平原、砂漠、山岳等）だけでなく、人間社会とインフラの介入度合いを示す以下の**動的パラメータ（Tile Status）**を個別に保持する。

| パラメータ | 概要 | ゲーム的影響 |
| :--- | :--- | :--- |
| **機能サイト種別** | タイルの主たる特化用途（未開拓、前哨基地、資源採掘、重工業、居住、農耕等）。 | サブタイル内に建設可能な基本モジュール群および大戦略上の算出資源を決定。 |
| **インフラ結合度 (0〜100%)** | 隣接する親タイル群と道路・送電線・パイプライン等でどれだけ強固に結ばれているか。 | 50%未満で工業稼働率低下。0%（完全孤立）で停電・燃料枯渇・重工業麻痺が発生。 |
| **開発深度 / 整地率 (0〜100%)** | 内部の343サブタイルのうち、地ならし・対環境防護壁・基礎舗装が完了した割合。 | 移動コストの軽減、高精度工作機械の設置可否、エイリアン襲来時の防御ボーナス。 |
| **実効支配度 & 忠誠度 (-100〜+100)** | 国家・勢力の中央統制がどれだけ及んでいるか。 | 低下すると「自発的失踪者・私設民兵」が実効支配し、税や資源の横領、最悪の場合は独立。 |
| **現地住民気質 & 人口階層** | タイルに滞在・居住する人口の内訳（軍属、契約労働者、地球第1世代技術者、現地適応第2世代等）。 | ストライキ発生率、思想適応（ガイア共生／技術至上主義等）への親和性、治安コスト。 |
| **環境負荷 & 生態侵食度** | 重金属汚染、排熱量、エイリアン胞子の付着・侵入度。 | 原住生物の敵対行動誘発率、局所的変異植物の繁茂、作業員の風土病リスク。 |

## 3. タイル拡張とフロンティア開拓メカニクス

「開拓者が歩いていって、旗を立てたら都市ができる」という抽象化を排し、**物理的インフラの延伸とサブタイルの段階的設営**によって領土と機能を拡張する。

```text
       【既存開発タイル (Hub)】
                  │
                  ▼  (工兵部隊・敷設車両によるインフラ延伸)
            [送電・パイプライン・道路幹線]
                  │
                  ▼
       【未開拓の目標タイル (Target)】
                  │
    ┌─────────────┴─────────────┐
    │ 段階的開拓プロセス (343サブタイル内) │
    └─────────────┬─────────────┘
                  │
  [Step 1: 設営]   ├─ プレハブ設営所・仮設集積デポ投下 (親タイルが「前哨」化)
  [Step 2: 基礎化] ├─ 送電サブステーション・整地・防護フェンス展開
  [Step 3: 特化]   ├─ 資源採掘炉 / 工業ライン / 居住ドーム の本格建設
  [Step 4: 自律]   └─ 下請け町工場・現地コミュニティが自然集積
```

### 3.1 インフラ延伸（物理的接続ルール）
1. **開拓可能条件**:
   - プレイヤーは、既存の「自勢力拠点タイル」から物理的な**幹線インフラ（高圧送電線、舗装道路、パイプラインのいずれか）**が繋がっている隣接タイルにのみ、新たな開発プロジェクトを発令できる。
   - 道路がない山岳や湿地を越える場合、まず工兵部隊や自動敷設ドローンを送り込んで「ルート敷設（パイオニア・ライン）」を行わなければならない。
2. **インフラの脆弱性**:
   - 幹線インフラは親タイル同士の境界を跨いで物理的に存在する。敵の遊撃部隊や巨大エイリアンによって境界線上のインフラが切断されると、先端のタイルは「インフラ結合度」が急落し、エネルギーや物資が途絶する。

### 3.2 343サブタイルの段階的開拓（4つのステップ）

各親タイルの内部（343サブタイル＝半径約10〜11マス）における開発は、以下のように段階的に進行する：

#### Step 1: 現場設営（FOB / Site Staging）
- タイル中央付近の3〜5マスに「現場設営プレハブ」「仮設通信アンテナ」「物資集積デポ」を投下。
- この段階で親タイルは「前哨サイト」として認識され、最低限の視界と小部隊の駐留・燃料補給が可能になる。

#### Step 2: 環境防護と基幹整備（Groundbreaking & Shielding）
- 汚染胞子や野生エイリアンを遮断する「外周防護フェンス」「自動取水・浄化井戸」「送電サブステーション」をサブタイル内に配置。
- タイルの「整地率」が上昇し、大型掘削機や重工業設備の搬入が可能になる。

#### Step 3: 機能特化の本格化（Specialized Construction）
プレイヤーの戦略方針と土地の資源ポテンシャルに応じて、特化施設群を集中配置する：
- **資源採掘サイト**: 鉱脈サブタイル上に「自律露天採掘リグ」「一次精錬炉」「破砕プラント」を建設。
- **重工業・兵器生産サイト**: 「モジュール鋳造所」「部品組立ライン」「エンジンテストベンチ」を配置。
- **居住・バイオファームサイト**: 「加圧居住ドーム」「現地適応植物水耕温室」「医療ステーション」を配置。
- **軍事要塞・前線基地（FOB）**: 「長距離早期警戒レーダー」「強化トーチカ群」「地下弾薬庫」「弾道迎撃サイロ」を配置。

#### Step 4: 自律的集積と町工場の展開（Agglomeration）
- ターンが経過しタイルの安定度・稼働率が高まると、プレイヤーが直接指示しなくても、**「下請け町工場」「民間物資交換所」「労働者バラック」などの付帯施設がサブタイルの空きマスに自律的に出現**する。
- これによりタイルの工業基礎値や整備能力、人口自給率が底上げされる。

## 4. タイルの主要機能サイト分類（Functional Site Archetypes）

都市という単一概念に代わり、タイルは以下のような機能サイトとして特化・運用される。

```text
┌───────────────────────────┬───────────────────────────┐
│     【軍事・兵站サイト】   │     【資源・一次産業サイト】│
│ ・軍事前哨基地 (FOB)       │ ・鉱物・レアメタル採掘サイト │
│ ・要塞・防衛複合体         │ ・炭化水素・地熱採取サイト   │
│ ・野戦補給デポ・前線飛行場 │ ・バイオマス・現地農耕ドーム │
├───────────────────────────┼───────────────────────────┤
│     【工業・加工サイト】   │     【社会・居住サイト】    │
│ ・重工業コンビナート       │ ・開拓者居住ドーム区画       │
│ ・精密電子・兵器モジュール工│ ・中央行政府・統治コア       │
│ ・リサイクル・廃材再生プラント│ ・研究学術・現地生態研究所   │
└───────────────────────────┴───────────────────────────┘
```

1. **軍事前哨基地・野戦補給デポ（Forward Operating Base）**:
   - 住民は兵士と軍属のみ。食糧・電力は外部からの供給に依存するが、戦闘団の修理・弾薬再装填・燃料補給を極めて高速に行える。
2. **重工業・兵器モジュールコンビナート**:
   - 原料を受け取り、共通兵器モジュール（装甲板、火器、電子戦ポッド等）を大量生産する。排熱と大気汚染が酷く、住民の健康度は低いが、軍の心臓部となる。
3. **自立居住・学術クラスター**:
   - 人口増殖、教育、新技術の研究開発を担う。治安と環境要求が高く、近隣に重工業タイルがあると住民の不満（幸福度低下）が発生しやすい。
4. **複合メトロポリス（複数タイルの結合）**:
   - 「中央行政府タイル」を中心に、周囲の「居住タイル」「商業流通タイル」「軽工業タイル」が隙間なくインフラ接続された状態。強大な生産力と研究力を誇るが、1つのインフラ寸断で大規模な暴動や電力危機に陥る脆さも併せ持つ。

## 5. 作戦術・戦術戦闘への影響（プレイヤーのゲーム体験）

### 5.1 「拠点を攻め落とす」から「急所を断ち切る」兵站戦へ
従来の4Xでは、強固な防壁を持つ大都市を正面からすり潰す以外の選択肢が少なかった。
本システムでは、すべてのタイルが個別の機能を持ち物理インフラで繋がっているため、**極めて実践的かつ知的な作戦術（Operational Art）**が展開できる：

- **発電・変電タイルの奇襲破壊**:
  - 敵の重工業コンビナートそのものは強固でも、電力供給元の「地熱発電タイル」または「送電サブステーション」を少数の空挺部隊や快速部隊で襲撃・破壊する。
  - 結果：重工業タイルのインフラ結合度がゼロになり、敵の最新戦車・弾薬の生産が即座にストップする。
- **補給パイプラインの遮断による前線の孤立**:
  - 前線要塞タイルを直接攻めるのではなく、後方の「野戦燃料集積タイル」から延びるパイプラインを寸断。
  - 前進していた敵戦闘団は燃料・砲弾補給を受けられなくなり、数ターン後に戦闘行動能力が麻痺して投降・後退を余儀なくされる。

### 5.2 サブタイル戦術マップ（343マス）での破壊と略奪
戦術画面に突入した際、戦場となるのは常に「その親タイルの実態」である：
- **露天採掘タイルでの戦闘**: 巨大な掘削クレーター、鉱石ベルトコンベア、作業員事務所が障害物・遮蔽物となる。重火器でコンベアを吹き飛ばせば、大戦略マップ側の採掘効率が半減する。
- **町工場地帯の市街戦**: 入り組んだ町工場の建屋を利用した歩兵・歩行兵器の近接戦闘。施設を誤爆・破壊すると、戦闘後に自軍が占領した際の再建コストが跳ね上がるというジレンマ。

## 6. タイルの自律性と住民・ガバナンス（失踪者・民兵化）

タイルの個別化は、統治・内政面においても「都市の忠誠度」という単一数値を細分化し、リアルな領土摩擦を生み出す。

### 6.1 辺境の放置と「自発的失踪者・私設民兵」化
- 本土の中央政府（統治コア）からインフラ距離が離れ、治安部隊の巡回（パトロール）が途絶えた辺境の採掘・農耕タイルは、徐々に**実効支配度（State Control）**が低下する。
- 実効支配度がマイナスに転じると、現地の労働者や開拓民は「国家に見捨てられた」と判断し、以前検討した**[自発的失踪者（Frontier Dissidents）](./concept_frontier_dissidents_and_territorial_claims.md)**へと変異する。
- 彼らはタイルの施設を勝手に改造し、独自の私設民兵（自警団）を結成して資源を密売し始める。プレイヤーは「武力鎮圧」「経済的懐柔（インフラ再接続と減税）」「自治領としての承認」のいずれかを選択しなければならない。

### 6.2 占領統治における「パッチワーク支配」
敵勢力の領土を切り取った際、従来のように「都市を落としたから一帯がすべて味方になる」ことはない：
- 「前線防衛基地タイル」と「資源採掘タイル」は占領したが、途中の「精錬加工タイル」と「変電タイル」は敵が握っているため、占領した施設が全く稼働しない。
- プレイヤーは鹵獲したタイルを機能させるため、自国のインフラ網から臨時の野戦送電線や補給道路を突貫工事で敷設し直す（インフラ再編）という、リアルな占領軍政の苦労を体験する。

## 7. 実装・システムアーキテクチャ（Rustデータ構造設計）

```rust
/// 大戦略マップ上の親タイル
pub struct StrategicTile {
    pub tile_id: u32,
    pub coordinates: (i32, i32),
    pub terrain_type: TerrainType,
    pub site_profile: FunctionalSiteProfile,
    pub infrastructure: InfrastructureNetwork,
    pub governance: TileGovernance,
    pub ecology: LocalEcology,
    /// 内部の343サブタイル（フラクタル詳細マップ）
    pub sub_grid: Box<SubTileGrid>,
}

/// タイルの機能サイト定義
pub enum FunctionalSiteProfile {
    Wilderness,                         // 未開拓・自然
    ForwardOperatingBase { def_level: u8 }, // 軍事前哨・FOB
    ResourceExtraction { resource: ResourceType, tier: u8 }, // 資源採掘・精錬
    IndustrialComplex { factories: Vec<FactoryModule> },   // 重工業・町工場コンビナート
    HabitationCluster { population: u32, generation_ratio: f32 }, // 居住・都市コミュニティ
    AgriculturalDome { yield_type: CropType },            // 農耕・バイオファーム
}

/// 物理インフラの結合状態
pub struct InfrastructureNetwork {
    pub connected_to_power_grid: bool,
    pub road_connection_tier: RoadTier,   // なし / 簡易舗装 / 高速幹線
    pub pipeline_connected: bool,
    pub supply_continuity_score: f32,    // 物流途絶スコア (0.0=遮断, 1.0=完全円滑)
}

/// タイル単位のガバナンスと住民
pub struct TileGovernance {
    pub sovereign_faction: FactionId,    // 法的領有権
    pub effective_control: f32,          // 実効支配度 (-100.0 ~ +100.0)
    pub community_ethos: CommunityEthos, // 住民気質 (軍属, 企業技術者, 失踪者シンパ等)
    pub unrest_level: f32,               // 不満・サボタージュ率
}
```

## 8. まとめと今後の接続

本「タイル個別化・脱都市型拡張システム」の導入により、本作は以下のような強固な独自性を獲得する：

1. **4X特有の「都市偏重の退屈さ」の完全排除**: 
   開拓・建設・防衛・奇襲のすべてが「現場のタイル」という等身大の舞台で行われる。
2. **作戦術・補給線遮断ゲームプレイの確立**:
   補給線や発電所の破壊が、即座に前線部隊の継戦能力崩壊へとダイレクトに繋がる。
3. **343サブタイル・町工場・失踪者設定との完全な調和**:
   これまで検討してきた「町工場によるモジュール生産」「自発的失踪者の自活」「分断経済統治」が、すべてこのタイル個別化システムを共通の土台として美しく機能する。
