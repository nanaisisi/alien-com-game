# 偶発的・確率的イベント（不確実性・ハプニング駆動型イベント）の検討

本作（4X大戦略・ターン制）において、**「未知の惑星環境、予期せぬ事故、本星の遠隔動向、運不運に起因する突発的事象」**を扱うイベントシステムの検討ドキュメント。

---

## 1. 概念と役割

### 1.1 偶発的イベントの目的

- 状況必然的イベントが「プレイヤーや他国の行動・物理配置から論理的に生じる必然」であるのに対し、本イベントは**「制御不能な外部環境・不確実性がもたらすハプニング」**を取り扱う。
- ゲームプレイが硬直化（最適解のルーチンワーク化）するのを防ぎ、未知の入植惑星ならではの**「臨機応変な危機管理と偶発的チャンス」**を提供する。

### 1.2 状況必然的イベントとの明確な差異

| 項目           | 状況必然的イベント [`concept_event_situational.md`](./concept_event_situational.md) | 偶発的・確率的イベント (本作)                                |
| :------------- | :---------------------------------------------------------------------------------- | :----------------------------------------------------------- |
| **発生要因**   | 部隊の移動、国境越境、条約履行、施設配置などの直接的因果                            | 惑星気象、天体活動、本星での突発事故、予期せぬ発見           |
| **予測可能性** | 高い（自らリスクを冒した・敵と接触した結果として起きる）                            | 低い〜中程度（予兆や確率分布はあっても完全には予期できない） |
| **主な対象**   | 国家間外交の駆け引き、領境問題、特定部隊/サプライチェーン                           | 惑星自然現象、本星移民船の遭難、古代遺跡の偶然の露出         |

## 2. 偶発的イベントの4大カテゴリ

### 2.1 惑星自然・天体環境のハプニング（Planetary & Stellar Phenomena）

- **高エネルギー嵐・電磁パルス（Solar Flares & Ion Storms）**:
  - 特定リージョンの衛星通信・レーダー網が2ターン機能停止。単一タイル戦術戦での航空・長距離砲兵支援が遮断される。
- **瘴気バースト・地殻変動（Miasma Surge / Tremors）**:
  - 地震により休眠中の地熱ガス孔が破裂。一時的に周辺タイルが危険な高濃度瘴気に覆われ、迂回を強いられる。
- **未知の生態回遊（Alien Megafauna Swarm）**:
  - 繁殖期を迎えた海洋巨大エイリアンや砂漠巨獣の群れが突如出現し、沿岸航路や砂漠ルートを遮断。

### 2.2 本星通信・遠隔フロンティアの不確実性（Deep Space & Homeworld Vagaries）

- **本星輸送船・移民船の航行トラブル**:
  - 「予定されていた移民船が亜空間航路で機関トラブルを起こし、数年遅延」あるいは「軌道上で難破し、脱出ポッドが各地に飛散」。
- **本星での突発的な政権交代・法改正**:
  - 母星本国で新政権が誕生し、突然の関税引き上げや軍事規格の改訂通達が届く。

### 2.3 産業・研究開発のセレンディピティと産業事故（R&D Serendipity & Hazards）

- **実験的モジュールの偶然のブレークスルー**:
  - 新興テック企業が研究中の生体センサにおいて、予期せぬ周波数帯でのエイリアン探知能力が発見される。
- **新型核融合炉・推進剤の偶発的リーク**:
  - 工業サブタイルでの試験運転中に爆縮事故。生産ラインが一時停止するか、緊急消火で作業員に被害が出るかの二者択一。

### 2.4 未知の遺跡・漂着遺物の発見（Derelict Artifacts）

- **旧世代先遣探査機の残骸発見**:
  - 数十年前に通信途絶した初期無人探査機の墜落機が、地すべりによって露出。
  - 機密ログや初期の惑星地質データが回収可能。

## 3. 発生制御メカニズム（不条理感を防ぐ設計）

完全な「運ゲー（理不尽なランダム死）」に陥ることを防ぐため、以下のゲームデザイン原則を適用する。

1. **予兆（Early Warning）システムの存在**:
   - 探査衛星や気象レーダー、地震計などのインフラを整えている都市・勢力は、「2ターン後に第4管区に電磁嵐接近」といった予兆を事前に検知できる。
   - 準備していたプレイヤーは被害を回避・軽減できる（投資が報われる構造）。
2. **リスク・リターンと環境脆弱性**:
   - 危険な火山地帯や瘴気帯に拠点を築くほど、高確率でエネルギー湧出イベントが起きる反面、災害イベントのリスクも跳ね上がる。
3. **発生頻度のポアソン制御（バースト防止）**:
   - 同一ターンに大量の偶発イベントが連続して発生し、プレイヤーが消化不良になるのを防ぐクーリングタイム機構。

## 4. データ構造例（Rust設計モデル）

```rust
pub struct StochasticEventDefinition {
    pub id: &'static str,
    pub title: &'static str,
    pub category: StochasticCategory,
    pub base_probability: f32, // ターンあたりの基本発生確率
    pub condition_evaluator: fn(&WorldState) -> bool, // 発生可能な前提条件
    pub weight_modifiers: Vec<ProbabilityModifier>, // 探査施設、特定タイル地形による重み付け
    pub early_warning_threshold: Option<TechOrFacilityId>, // 予兆を事前察知できる条件
}

pub struct ActiveStochasticEvent {
    pub event_id: &'static str,
    pub affected_tiles: Vec<TileCoord>,
    pub remaining_duration: u32,
    pub status: EventStatus, // Warning -> Active -> Resolved
}
```

## 5. 状況必然的イベントとの接続

偶発的イベントが起点となって、状況必然的イベントへ発展する**「複合連鎖」**を許容する。

- 例:
  1. 【偶発】本星移民船の脱出ポッドが、自国と大公国Bの「国境緩衝地帯」に墜落（確率的事象）。
  2. 【必然】双方の回収部隊が同一タイルへ急行し、生存者の管轄権と搭載物資を巡って現場対峙が発生[`concept_event_situational.md`](./concept_event_situational.md) の状況必然的イベントへ遷移）。
