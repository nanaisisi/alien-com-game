# 勢力合意・領土割譲・規格統合イベント仕様書 (Consensus, Territorial Transfer & Standardizations)

本作（4X大戦略・ターン制）における、**「他勢力・部署との合意形成と吸収」「合意に基づく平和的タイル移管」「インフラ・工業の規格問題」**に関するイベントおよび外交システムの詳細仕様書。

---

## 1. 基本設計思想

従来の4Xゲームでありがちな「特定部署の突然の裏切りによる離反」や「一方的な文化・圧力によるタイルの強奪」を排し、**「全体の空気感・相互浸透を通じた完全合意による吸収」**と**「相手国の承認を前提とした平和的タイル移管」**を基本原則とする。

また、産業面では「独占や激しい企業競争」をテーマにするのではなく、**「自国規格・相手国規格・第三国規格・新規格の差異による不便さと統一コスト（規格問題）」**を中核に据える。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        合意・領土・規格イベントの3本柱                 │
└────────────────────────────────────────────────────────────────────────┘
  │
  ├── ①【他勢力・部署の親交と全体合意形成】
  │     └─ 部署単位で親密化（裏切りではない） ──► 全体空気感の熟成 ──► 完全合意による平和的吸収
  │
  ├── ②【合意に基づく平和的タイル移管】
  │     └─ タイル割譲の外交打診 ──► 相手国の同意（駐留部隊は安全撤兵） ──► 円滑な主権移管
  │         ※ 相手国が拒絶した場合は一方的に手を出すことは不可
  │
  ├── ③【インフラ・製造の規格問題】
  │     └─ 自国規格 / 相手国規格 / 第三国規格 / 新規格 / 規格なし
  │         接続部での輸送・整備ロス、共通化投資の意思決定
```

## 2. 他勢力・部署取り込みシステム（合意形成プロセス）

### 2.1 部署単位の親和化（裏切りではなく「親密な関係」）

各勢力は複数の「部署・セクター（外務部、技術研究開発部、輸送・補給部、資源採掘局、防衛軍司令部など）」を持つ。
プレイヤーは貿易、共同研究、合同防衛などの日常的な相互作用を通じて、特定の部署と「親密な連携関係」を築くことができる。

- **裏切り（反逆）の否定**:
  - 部署が自国を裏切ってプレイヤー側にスパイ活動をしたり、勝手に亡命・寝返ることはない。
  - あくまで「相手勢力内部における、プレイヤー派閥への理解者・強力なパイプ」として機能する。
  - 例: 技術部門との関係が深まると、相手国政府の正式な許可のもとで「共同研究協定」が通りやすくなる。

### 2.2 「全体の空気感」の醸成と完全合意（勢力吸収）

1. **部署パイプの水平展開**:
   - 外務、技術、補給、防衛など、相手国の主要部署の多くと親密な協調関係を構築していく。
2. **社会・世論の空気感（Zeitgeist）の変化**:
   - 部署間の緊密な連携が社会全体に波及し、「両派閥が統合・合邦することこそが自然であり、双方にとって最善である」という**全体の空気感**が醸成される。
3. **完全合意による吸収（平和的合邦）**:
   - 全主要部署および相手国政府中枢が合意に達して初めて、「統合条約（合邦）」のイベントが発生・締結可能となる。
   - 敵対的併合とは異なり、反乱・サボタージュ・忠誠度低下などのペナルティは一切発生せず、相手国の領土・インフラ・部隊が円滑に自派閥へ合流する。

## 3. 平和的タイル取り込みシステム（合意割譲）

### 3.1 相手国の同意を前提としたタイル移管

プレイヤーが他勢力の管轄する特定タイル（資源地帯、境界の重要中継地など）の取得を望む場合、**「外交的な提案と相手国の合意」**によってのみ平和的に取り込むことができる。

```text
[プレイヤーからのタイル割譲提案]
           │
           ├─► [相手国が拒絶]: 一切手出し不可（領土侵犯・一方的強奪は行えない）
           │
           └─► [相手国が同意]: 平和的移管プロセスの実行
                     │
                     ▼
           [駐留部隊・機能の安全撤退]
           相手ユニットは整然と本国領内へ撤兵
                     │
                     ▼
           [主権・インフラの円滑な移管]
           施設は破壊されず、自国の管轄下へ組み込まれる
```

### 3.2 移管プロセスのルール

1. **相手国拒絶時の不可侵**:
   - 相手国が提案を受け入れない場合、外交的・平和的手段での一方的な領土書き換えは不可能。
2. **合意時の撤兵と保全**:
   - 割譲が成立した場合、該当タイルに駐留していた相手勢力の軍事ユニット・作業部隊は、敵対することなく平和裏に相手国の直近の領内へ撤退（自動移動）する。
   - サブタイル施設やインフラ（道路・鉄道・採掘施設）は損壊せず、そのままプレイヤーの管理下へ引き継がれる。
3. **合意を引き出す要因**:
   - 見返りとしての代替資源・資金・技術供与。
   - 自国側のインフラ網に囲まれ、相手国側からの飛び地・維持困難になっている現状（現場の合理的判断）。
   - 前述の「部署・全体の合意形成レベル」の高さ。

## 4. 兵器・電子機器の適合性と調達課題（Weapon & Avionics Compatibility）

新環境における規格問題は、前世紀的な鉄道軌間（ゲージ）のような単純な物理インフラの差異ではなく、**「データリンク・通信プロトコル・アビオニクス（電子機器）の適合性」**および**「兵装・弾薬規格」**にフォーカスする。（※鉄道軌間などの基礎交通インフラは全勢力共通で接続され、線路幅問題などは存在しない）。

### 4.1 基本原則：不適合兵器の配備不可と「最終艤装」

軍用通信機、暗号鍵、敵味方識別（IFF）、データリンクといったC4I中枢は**国家最高機密**であり、他国へそのまま渡すことも、他国から完全な形で受け取ることも本来あり得ない。
そのため、車体・機体や基礎兵装の製造・輸入と、中枢電子機器の組み込みは工程上明確に分離され、**「自国での最終艤装（Final Outfitting）」**として扱われる。

- **配備不可（出撃制限）**:
  - 通信機やデータリンク規格が自軍の指揮系統に非対応の兵器（他国仕様の鹵獲品、暗号機未搭載の輸入ベース機など）は、**そのまま戦闘団へ編成・配備することはできない**（部隊間連携や管制不能のため）。
- **調達・適合プロセスの区分**:
  1. **ライセンス生産（自国工場での一貫生産・完全適合）**:
     - 相手国から設計図・ライセンスを取得し、**自国の兵器工場で最初から自国の通信機・FCSおよび自国兵装を組み込んで製造**する。
     - 自国工場からロールアウトした時点で完全適合品となるため、追加艤装・改造は不要で**即時配備可能**。
  2. **輸入機の自国最終艤装（配備可否のクリア）**:
     - 相手国からは「通信暗号機を抜いた車体・機体・動力などの準完成プラットフォーム（Green Vehicle/Aircraft）」を輸入する。
     - 自国ドックで自国の通信機・暗号モジュールを**最終艤装**することで出撃可能（配備可能）となる。
  3. **兵装の自国仕様化（改造・改修 / Refit）**:
     - 他国規格の主砲・ミサイルランチャー・弾薬口径のまま運用することも可能だが、弾薬補給ラインが他国依存となり補給コストが跳ね上がる。
     - 整備ドックで砲塔・マウント・給弾機構を換装し、自国の標準弾薬・ミサイルを使えるよう**「改造・改修（兵装自国化）」**を行うことで、補給を自国サプライチェーンに完全統一できる。
  4. **鹵獲・接収品の再生（通信最終艤装 ＋ 兵装改造・改修）**:
     - 鹵獲機は敵通信機を撤去して自軍通信機を「最終艤装」して配備可能とし、必要に応じて自国弾薬を使えるよう「兵装改造・改修」を施す。

### 4.2 適合・艤装・改造の状態区分

| 状態区分                               | 定義・現状                                                   | 配備可否        | 補給・維持の帰結                                                         |
| :------------------------------------- | :----------------------------------------------------------- | :-------------- | :----------------------------------------------------------------------- |
| **自国完全適合 (自国製/ライセンス機)** | 自国工場で最初から自国通信機・自国兵装で生産された機体。     | **即時配備可**  | 通常の補給・整備コスト。連携ボーナス100%。追加工事不要。                 |
| **輸入機 (最終艤装済・兵装他国仕様)**  | 通信機は最終艤装したが、主砲・弾薬は相手国規格のまま。       | **配備可能**    | 連携は正常。ただし弾薬補給に相手国パーツ・弾薬輸入が必要。               |
| **自国兵装改造型 (改造・改修済)**      | 輸入機や鹵獲機の兵装マウントを換装し自国弾薬仕様にした機体。 | **配備可能**    | 改造・改修コスト発生。弾薬・補給ラインは自国サプライチェーンに完全統一。 |
| **輸入機 (準完成・未艤装)**            | 車体・基礎兵装のみ（通信機未搭載）。                         | **❌ 配備不可** | 自国整備ドックで通信機等の**最終艤装**を行うまで出撃不可。               |
| **不適合・敵暗号残存機 (鹵獲原型)**    | 相手国の通信機・暗号が残存（または未暗号化で孤立）。         | **❌ 配備不可** | 実戦運用不可。保管・解体分析するか、通信艤装＋改造ドックへ投入。         |

### 4.3 適合性・最終艤装に伴う具体的イベント・選択

#### イベント例1: 友好国からの重装甲車両の供与打診

- **発生状況**: 相手国との部署合意が深まり、相手国の主力重装甲車両の供与提案を受けた時。
- **事象**: 相手国から車両本体が納入されるが、最高機密である通信暗号機・IFFは相手国によって抜き取られており、未艤装状態のため即座には配備できない。
- **選択肢**:
  - **[選択A] 自国ドックでの最終艤装（輸入機ルート）**: 自国の通信機・射撃管制モジュールを組み込む最終艤装ラインを確保（少量の工業部品・艤装工期を消費して正規配備）。
  - **[選択B] ライセンス生産契約への切り替え**: 設計ライセンスを取得し、自国工場で最初から自国通信機を載せた正規車両としてライン生産（初期費用大だが完成品は即配備可）。
  - **[選択C] 予備部品・装甲材としての解体利用**: アビオニクス艤装コストを惜しみ、既存部隊の補修用資材としてストックへ回す。

#### イベント例2: 鹵獲・接収した先鋭無人機群の処遇

- **発生状況**: 相手国施設や不時着部隊から無人機・電子戦ユニットを無傷で接収した時。
- **事象**: 敵国の軍用暗号・自律プロトコルでロックされており、機密保持のため解析も困難。自軍ネットワークに接続できず出撃不可。
- **選択肢**:
  - **[選択A] 敵暗号基盤の強制撤去と自軍アビオニクス最終艤装**: 内部の電子戦モジュールをごっそり抜き取り、自軍の無人機自律コアを換装（基本機体性能を活かして再配備）。
  - **[選択B] 機密解読研究（リバースエンジニアリング）**: 配備は行わず、機密暗号プロトコルを安全なラボで解析して相手国の電子戦対抗データを獲得。
