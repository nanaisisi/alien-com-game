# 状況必然的イベント（因果駆動型イベント）の検討

本作（4X大戦略・ターン制）において、**「特定の現場・対象物・行動・条約関係などの具体的な個別因果」**によって必然的・論理的に発生・推移するイベントシステムの検討ドキュメント。

---

## 1. 概念と基本原則

### 1.1 「統計パラメータの閾値ポップアップ」との決別

- 従来の4Xにある「好感度メーターが70を超えたから同盟打診が出る」「不満度が上がったから汎用暴動が起きる」といった抽象的・統計的な判定ではない。
- **「どこで（タイル/施設）」「誰が（特定部隊/特定勢力）」「何を理由に（交戦、越境、資源枯渇、契約履行/不履行）」「どう行動したか」**という具体的な個別事実（イベントパラメータ）の交差によって必然的にトリガーされる。

### 1.2 状況必然的イベントの3大特徴

1. **現場（物理的エンティティ）との結合**:
   - イベントは空中に浮いたダイアログではなく、全体マップ上の「特定タイル」「特定部隊」「特定都市のサブタイル施設」に紐づく。
2. **状況の継続性と推移（State Machine）**:
   - 1回の選択肢で「はい/いいえ」で完結して消えるのではなく、「火種」「対峙」「交渉中」「報復待機」などの状態を持ち、現場の物理的変化（増援到着、施設破壊など）によって次の局面へ進む。
3. **具体的な事実としての波及**:
   - 結果は抽象的な「友好度+10」ではなく、「第2採掘区における越境既成事実」「押収された探査船の残骸データ」「相手国に対する正当な開戦事由（Casus Belli）」「共同防衛ラインの成立」といった**具体的な権利・負債・物理的状況**として残る。

## 2. 状況必然的イベントのメカニズム構造

```text
[1. 物理的・個別状況の交差]
  - 例: 大公国Bの「民間探査団」がエイリアンに追われ、自国領「第2採掘区」へ無断越境。
  - 要因: タイル位置、部隊種別、損傷度、条約（国境封鎖中か）、現地守備隊の有無。
                      │
                      ▼
[2. 必然的な状況の発生 (Situational Dilemma)]
  - 現地プラントがエイリアンに巻き添えで攻撃される。
  - 大公国探査団から緊急救難信号（傍受通信ログ）。
                      │
                      ▼
[3. プレイヤーの文脈的介入・現場判断]
  - 介入A: 現地部隊でエイリアンを排除し、大公国船を拿捕（機密取得 / 外交カード化）。
  - 介入B: 境界ゲートを閉鎖して見殺し（プラント保全 / 大公国世論に深い遺恨フラグ）。
  - 介入C: 大公国守備隊に一時進入を許可して共同作戦（現場の信頼醸成 / 軍事情報露呈リスク）。
                      │
                      ▼
[4. 具体的かつ永続的な事実の定着]
  - 「大公国に対する不法越境の外交的追求権」の獲得。
  - あるいは「第2採掘プラント前での合同作戦記念碑（現場部隊の親善関係）」。

## 3. 重要設計原則：対象エンティティの消失・撃破への動的適応

現場のユニットや施設が戦闘・解散・エイリアン襲撃等によって「消滅」した場合の振る舞い。

### 3.1 「進行不能・回避グリッチ」の防止と物理的介入の許容
- **課題**:
  - イベントに関与しているユニットを消すことで、不都合なイベントを強制スキップ・無効化するグリッチ（エクスプロイト）が生じると白けてしまう。
  - 一方で、「邪魔な他国部隊をあらかじめ先制攻撃で消す」「自軍部隊を損害回避のために退却・解散させる」といった物理的介入自体は、戦略的な妨害・意思決定として認められるべきである。
- **原則：事態は「消滅を織り込んで」別の文脈へと前進する**:
  - 対象が消えたからといってイベントが消滅（リセット）するのではなく、**「対象が消滅したという事実」が新たなトリガーとなり、状況が別ルートへ自動推移する**。

```text
[事象: 大公国の探査船が境界越境中]
               │
      +--------+--------------------------+
      │                                   │
[正常進行: 救助または拿捕]        [妨害・消失: 探査船が撃破・消滅]
      │                                   │
      ▼                                   ├─ 自軍が先制攻撃で破壊 ──► [証拠隠滅 or 不法攻撃の外交危機]
[完全な報酬・外交協定]                    ├─ エイリアンが撃破 ────► [残骸サルベージ・ブラックボックス回収]
                                          └─ 自軍が撤退・現場放棄 ──► [他国による非難・残骸の強奪]
```

### 3.2 報酬設計：途中であれ最後であれ「程々の落とし所」

- 理想的な結末（ハッピーエンドや完全解決）に届かず対象が失われた場合でも、プレイヤーの行動に応じた「程々の報酬」や成果物を手に入れられるようにする。
  - **残骸サルベージ**: 対象ユニットが爆散しても、残された残骸から技術チップや少量の希少資源を回収可能。
  - **政治的成果**: 救助には失敗したが、「救助しようとした事実（誠意）」によって相手国との関係悪化を防ぐ、あるいは「撃破したことで機密流出を阻止した」という実利。
  - **途中経過の成果**: 複数フェーズがある場合、途中まで護衛・調査した段階で部分的な情報・報酬（経験値、データログ）が確定付与される。

## 4. 主要な状況必然的シナリオ群

### 4.1 領境・主権・条約の必然的摩擦（Frontier Sovereignty）

- **退避・越境インシデント**:
  - エイリアンや過酷な環境（瘴気帯の急拡大など）に追われた他国部隊が、無断で緩衝地帯や国境を突破して避難してくる。
- **航路・海峡の無断航行**:
  - 自国の管轄海域（チョークポイント）を、他国の武装船艦隊が無通告で通過。
  - 「通航税の徴収」「威嚇射撃による退去勧告」「拿捕」など、国際海運協定と力関係に応じた直接的措置が求められる。
- **資源鉱脈の境界跨ぎ**:
  - 隣接する国境タイルの地下で、同一の希少鉱脈・地熱脈がつながっていることが判明。
  - 「過剰採掘による相手側圧力低下」「共同開発コンソーシアムの設立」「武力による採掘権の排他主張」。

### 4.2 産業・サプライチェーンの必然的破綻・依存（Industrial Interdependence）

- **重工ライセンス供与国の戦争勃発**:
  - 自国の主力戦車が依存しているベース車体の供給元（例: 連邦C）が他国と開戦し、自国への保守部品輸出を差し止め。
  - 「部品不足による稼働率低下」「自国工場での違法デッドコピー生産の強行（特許侵害・外交摩擦）」「新興テック製モジュールへの換装による応急対応」。
- **下請け・コンビナートのストライキ連鎖**:
  - サブタイルの化学精錬クラスターで爆発事故が発生。それに伴い、隣接する組立ドックへの素材供給がストップし、戦闘団の補充が滞る。

### 4.3 本星指令と現場実態の乖離（Homeworld vs Frontier Reality）

- **本星からの即時開戦命令 vs 現地の相互依存**:
  - 本星で大戦が再燃し、本国枢密院から「即座に隣接する大公国Bの都市を攻撃せよ」と公電が下令。
  - しかし現場では、大公国からの食糧輸入に依存しており、今攻撃すれば自国都市が餓死する状況。
  - 「本星命令の無視（本星支援の打ち切りリスク）」「形式的な砲撃と密約による偽装交戦」「強硬な突撃と自滅的危機」。

## 5. データ構造と状態管理設計（Rust実装モデル）

状況必然的イベントは、個別の「状況インスタンス（SituationalInstance）」としてメモリ/セーブデータに保持される。

```rust
pub struct SituationalEvent {
    pub id: EventInstanceId,
    pub scenario_type: ScenarioType, // 例: BorderIncursion, SupplyChainSeverance
    pub target_tile: Option<TileCoord>,
    pub involved_factions: Vec<FactionId>,
    pub involved_entities: Vec<EntityId>, // 特定部隊、特定施設
    pub current_phase: EventPhase, // 例: IncursionAlert -> HostageTaken -> Resolution
    pub expiration_turn: Option<TurnNumber>, // 放置された場合の自動推移ターン
}

pub enum SituationalOutcome {
    DiplomaticLeverage { target_faction: FactionId, claim_type: ClaimType },
    TreatyViolationFlag { violator: FactionId, treaty_id: TreatyId },
    FacilityDamaged { tile: TileCoord, facility_id: FacilityId },
    IntelligenceAcquired { tech_module_blueprint: ModuleId },
}
```
