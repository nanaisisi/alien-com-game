# 海上統治・海洋工学仕様検討書 (Maritime Governance & Ocean Engineering)

本ドキュメントは、異星開拓における海洋タイルの領有・統治形態、ならびに【埋め立て】【固定式】【半固定式】【メガフロート】の4大工法によるインフラ整備、海上都市の自治・市民生活、海洋軍事・通商路（シーレーン）の維持メカニクスを定義する総合設計書である。

---

## 1. 背景と基本方針

### 1.1 「脱・大地依存」と海洋開拓の意義

人類が降着した異星地表において、陸上は瘴気（ミズマ）の自律拡散、原生生物の巣窟（Nest）、険峻な山岳地帯に覆われており、陸路延伸には莫大な浄化・整地コストがかかる。
これに対し、**海洋（Ocean）**は以下の決定的な利点とリスクを持つ。

* **戦略的利点**:
  * **地表瘴気の遮断**: 胞子・菌糸による陸生瘴気汚染から物理的に隔絶されており、空気浄化コストが低い。
  * **無制限の冷却能・電力立地**: 海水を利用した冷却により、高発熱の核融合/核分裂炉、大規模AIデータセンター、レールガン工廠に最適。
  * **高効率な自活食料（海洋養殖）**: 閉鎖型生簀・プランクトン培養プラントによる、高密度タンパク質の安定生産。
* **内在する致命的リスク**:
  * **地盤の不在と浮力・動力依存**: 陸上都市と異なり、「動力（電力・バラストポンプ）喪失＝沈没・全滅」に直結する。
  * **海洋巨大エイリアン（リヴァイアサン級・深海共鳴種）**: 水中音や電磁ノイズに誘引され、浮体や係留索、海底基礎を直接襲撃する。
  * **極限環境（塩害・高水圧・嵐）**: 耐食塗料・海洋重工（IND-6）サプライチェーンの途絶が即座に構造寿命の枯渇を招く。

### 1.2 統治思想と管轄形態

海洋は固定的な境界標示が困難なため、**「工法の選定」「係留・浮力インフラの維持」「哨戒網（実効支配）」**の3要素が揃って初めて統治権（領海権・排他的経済水域）が確立される。

## 2. 海洋進展の4大工法比較

海洋タイルの開発・居住化は、水深（浅海・大陸棚・外洋深海）と技術・産業基盤に応じて4つの工法に大別される。

## 2. 実現工法の体系（普天間基地代替・SACO/米軍MOB工学モデル）

本作の海洋工学および海上統治は、現実の**「普天間飛行場代替施設（SACO最終報告および移設検討）」における技術論争・6大工法**を原型とし、異星の地政学・生態系リスクに適応させた体系を採用している。

```text
【海洋展開工法の6大体系（現実のSACO検討・MOBモデル）】

  固定・着底系 (Fixed & Bottom-Found)              浮体・機動系 (Floating & Mobile)
 ┌────────────────────────────────────┐         ┌──────────────────────────────────────┐
 │ ① 埋め立て案 (Reclamation)        │         │ ④ メガフロート（ポンツーン方式）    │
 │    土砂・消波堤による永久陸地化    │         │    超大型箱型鋼製浮体（平水・沿岸向け）│
 ├────────────────────────────────────┤         ├──────────────────────────────────────┤
 │ ② 杭打ち桟橋工法（QIP工法）案     │         │ ⑤ メガフロート（セミサブ式）        │
 │    ジャケット脚による海流阻害低減  │         │    半潜水型浮体柱（荒天・外洋向け）  │
 ├────────────────────────────────────┤         ├──────────────────────────────────────┤
 │ ③ 重力着底型（GBS）案             │         │ ⑥ 移動海上基地（MOB: Mobile Offshore │
 │    巨大ケーソン自重着底（防波堤兼）│         │    Base）案（モジュール自走・遠征型）│
 └────────────────────────────────────┘         └──────────────────────────────────────┘
```

### 2.1 6大工法マトリクス比較

| 工法（現実モデル） | 構造特性・建設技術 | 資材・産業依存 | 耐久・環境・エイリアン耐性 | 可動・可逆性 | ゲーム内戦略・軍事・統治機能 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **① 埋め立て案 (Reclamation)** | 護岸工＋土砂・鉱滓埋設。完全な地盤を形成。 | 初期土砂・セメント：**極大** / 維持費：**極小** (IND-1採鉱 / IND-5建材) | 地震・津波：**強** / 潜水襲撃：**完全遮断**（海洋生態系は完全消滅） | **不可（不可逆）**（撤去・原状回復は事実上不可能） | **恒久重工業・大型ロケット射場・重艦工廠**：海洋タイルを完全な陸地化。被弾・衝撃に最も強く、陸上大型施設を無制限に建設可能。 |
| **② 杭打ち桟橋工法 (QIP案: Quick Installed Platform)** | 海底地盤に鋼管杭（ジャケット）を打ち込み、上部デッキを支持。 | 初期鋼材・工期：**中** / 維持費：**中** (IND-2合金 / IND-6海洋重工) | 潮流疎通性：**極めて高** / 深海巨獣の突進：**脚部脆弱**（水中爆薬・魚雷に脆弱） | **部分撤去可能**（デッキ・杭切断） | **沿岸哨戒飛行場・中継桟橋・防空タワー**：潮流を堰き止めず沿岸生態系の激変を防ぐ。平時の外交摩擦（環境負荷）が最も低い。 |
| **③ 重力着底型プラットフォーム (GBS: Gravity Based Structure)** | 巨大コンクリート/鋼製ケーソンを沈設し、自重で着底。 | 初期コンクリート：**大** / 維持費：**小〜中** (IND-5建材 / IND-2鉄鋼) | 巨大波浪・体当たり：**極強** / 地盤沈下・軟弱地盤：**弱**（地盤改良が必須） | **困難（非可逆）**（注水着底・固定） | **防波堤一体型要塞・深海鉱床直上リグ**：巨大な自重でリヴァイアサン級の激突を耐え抜く。外洋の荒波を遮断する人工港湾のコア。 |
| **④ メガフロート（ポンツーン方式）** | 巨大な鋼製箱型浮体を連結。喫水が浅く広大な甲板を確保。 | 初期鋼材：**極大** / 維持費：**高（電食防食）** (IND-6造船海洋重工) | 静穏海域（湾内）：**極めて平穏** / 外洋波浪：**長周期動揺大**（外周防波堤が必須） | **撤去・分割可**（ユニット切離し・タグボート曳航） | **洋上滑走路・メガフロート都市・乾ドック**：広大な平地を生み出し、数万人規模の都市デッキを即席展開。湾内・礁湖の急速軍事化。 |
| **⑤ メガフロート（セミサブ式）** | 浮力を生むロワーハル（没水体）と複数のコラム（柱）で支持。 | 初期建造コスト：**極めて高** / 維持費：**高** (IND-6高度造船技術) | 巨大波浪・外洋荒天：**最強**（波浪エネルギーを透過） / 係留索切断：**転覆リスク** | **移動可能**（バラスト調整＋係留解除で外洋回航） | **外洋前進航空基地・深海採掘プラットフォーム**：防波堤なしで外洋深海に設置可能。波浪による揺れが極小で、精密航空・砲撃運用が可能。 |
| **⑥ 移動海上基地 (MOB: Mobile Offshore Base)** | 準自走式の超巨大セミサブ・モジュール複数隻を洋上で連結。 | 初期建造・動力：**最大** / 維持費：**極大（常時機関維持）** (IND-6/IND-7推進機関) | 潜水艦・魚雷：**集中迎撃要** / 生存性：**区画隔離で高** | **完全自走・再配置可**（戦域間を数ターンで自力航行・合体分離） | **外征用洋上展開要塞・機動方面軍司令部**：敵国沿岸タイルへ急行し、洋上から航空・揚陸作戦を展開。戦局変化に応じて即座に撤収・転進。 |

## 3. 海上都市（Ocean City）の統治・市民生活メカニクス

メガフロートや埋め立て人工島を中心とする「海上都市」は、陸上都市と全く異なる社会動態と統治課題を抱える。

### 3.1 人口収容と区画構造（レイヤード・シティ）

海上都市（メガフロート型）は、上下3層の立体構造を持つ。

1. **上層（デッキ層 / Sky Deck）**:
   * 居住区、商業施設、航空機用滑走路、ソーラー/防空システム。海風と日光を享受する開放区画。
2. **中層（ハル内部 / Hull Core）**:
   * 造船・組立工場、軽工業、AIデータセンター、配電・バラスト調整室。都市の生命線。
3. **下層・海中（サブサーフェス / Subsea Shell）**:
   * 閉鎖循環型養殖生簀（アクアカルチャー）、海水淡水化プラント、海底係留アンカー接合部、水中防護グリッド。

### 3.2 統治上の3大危機管理リスク

#### ① 浮力・動力途絶パニック（Buoyancy Panic）

* **現象**: 陸上都市では停電しても建物は倒壊しないが、メガフロートでは**「動力停止＝排水バラスト停止＝傾斜・浸水・沈没」**を意味する。
* **メカニクス**:
  * タイルの電力供給が50%以下に低下すると、住民の「危機指数（Panic Level）」が急上昇。
  * 暴動や脱出用シャトルの奪い合いが発生し、行政機能が急速に麻痺する。
  * これを防ぐため、海上都市には「非常用原子炉/バックアップ蓄電モジュール」の冗長化が義務付けられる。

#### ② 塩害・生体付着（Bio-fouling & Corrosion）

* **現象**: 異星の腐食性海水と、付着性原生微生物（フジツボ状の生体珪素殻）による浮体外殻の劣化。
* **メカニクス**:
  * 毎ターン、`造船・海洋重工（IND-6）`から「防食ケミカル」「超音波防汚パルス発生器」「メンテナンス部材」を消費。
  * 供給ラインが遮断されると、構造強度が段階的に低下し、補修コストが倍増する。

#### ③ 水中音共鳴とエイリアン襲来（Acoustic Threat）

* **現象**: 海上都市が稼働する発電・空調の低周波振動が海中へ伝播し、**「超大型海洋エイリアン（リヴァイアサン級）」**を誘引する。
* **メカニクス**:
  * タイルの生産活動（インダストリー稼働率）に比例して「水中ノイズ値」が上昇。
  * ノイズが閾値を超えると、群泳刺胞獣の取水口目詰まりや、大型種の激突イベントが発生。
  * 対策として「能動静粛防振ダンパー（工業モジュール）」や「外周深度爆雷ライン」の整備が必要。

## 4. 海洋タイルの進展システム（Tier 0 〜 Tier 4）と工法分岐

陸上タイルのTierシステム（[`concept_tile_progression_system.md`](./concept_tile_progression_system.md)）と連動し、海洋タイルも段階的な進展を遂げる。海洋では**「どの工法を選択してTierを進めるか」**によって、最終的な機能・機動性・維持コストが分岐する。

```text
Tier 0: 未踏外洋 (Wild Ocean)
  └─ 航行・漁撈のみ。海棲エイリアンの危険海域。
     │
Tier 1: 海洋観測・航路標識 (Oceanic Recon)
  └─ 係留型ソナーブイ網、気象観測塔。視界確保とシーレーン安全度向上。
     │
Tier 2: 資源リグ・前進哨戒所 (Offshore Rig & Outpost)
  ├─ 【固定系】杭打ち桟橋（QIP）式前哨（沿岸・浅海）
  └─ 【浮体系】半固定式（セミサブ）採掘リグ（大陸棚・深海）
     │
Tier 3: 複合拠点・海洋要塞 (Marine Complex)
  ├─ 【着底型】重力着底式（GBS）防波堤要塞（高耐撃・荒波遮断）
  ├─ 【浮体型】メガフロート（ポンツーン型）航空デッキ（湾内平水）
  └─ 【半潜水】メガフロート（セミサブ型）外洋航空基地（荒天外洋）
     │
Tier 4: 海上都市環 / 人工島複合都市 / 機動洋上基地 (Oceanic Metropolis / MOB Hub)
  ├─ 【埋立型】完全埋め立て人工島都市（超重工・ロケット射場・恒久陸地化）
  ├─ 【都市型】ポンツーン連結型海上メガシティ（数万人居住・閉鎖養殖セル環）
  └─ 【機動軍事型】移動海上基地（MOB）複合艦隊（自走・戦域間転進可能な洋上司令部）
```

### サブタイル（3×3）の工法別配置

海洋タイル内も9分割のサブタイルとして管理される。

* **中央サブタイル**: メガフロート本体／GBSコア／人工島中枢（都市核・指令センター）
* **外周サブタイル**:
  * **港湾・繋留・QIP桟橋ブロック**: 輸送船・哨戒艦の接岸
  * **消波堤・防護ネット（GBS/浮体防波堤）**: 外洋の長周期波・津波の減衰
  * **養殖・バイオセル**: 下層没水型のアクアカルチャー
  * **海底ケーブル・パイプライン陸揚点**: 陸上または海底資源鉱床との直結ライン

## 5. 海洋軍事・通商路（シーレーン）と海上境界

### 5.1 シーレーン（海上補給路）の力学

* **敷設コストゼロ、だが維持コスト高**:
  * 海上輸送は道路・鉄道の敷設資材が不要であり、長距離大量輸送のコスト効率が最も高い。
  * 一方で、哨戒艦艇（Patrol Fleet）を巡回させない海域では、**「通商破壊（海賊・野生エイリアン・敵対潜水艇）」**による船舶喪失率が跳ね上がる。
* **物理インフラ（海底ケーブル・パイプライン）**:
  * 陸上タイルや他洋上プラットフォームとのエネルギー融通には海底敷設が必要。工作潜水艇による切断破壊作戦（グレーゾーン攻撃）の標的となる。

### 5.2 要塞化と移動性（メガフロートの戦略価値）

* **位置の可変性（リロケーション）**:
  * 陸上都市と決定的に異なり、メガフロート軍港・都市は**「放棄せずに安全な海域へ曳航・退避」**が可能。
  * 前線海域で敵対勢力の陸上弾道ミサイル射程に入った場合、外洋へ後退させる戦略機動が取れる。
* **不沈空母としての機能**:
  * CTOL（通常離着陸）戦闘機を運用可能な長大な甲板を提供し、陸上飛行場を持たない離島・孤立戦線への航空優勢を確立。

### 5.3 領海境界と公海紛争（グレーゾーン）

* **既成事実化（Fait Accompli）**:
  * どの勢力にも属さない公海（無主海域）の資源豊富タイルに対し、**半固定式リグやメガフロートを曳航・固定し、周囲に防護ソナー網を張ることで一方的に領海編入**を宣言できる。
* **航行の自由作戦（FONOPS）イベント**:
  * 他国が自国領海と主張する海洋タイルに対し、駆逐艦・哨戒艦艇を無通告で通航させることで、相手の領有権主張を無効化する外交軍事アクション。

## 6. 産業サプライチェーンとの結合

海上統治の持続は、以下の国内工廠・資源チェーンに完全に依存する。

1. **IND-6: 造船・海洋重工 (Naval & Marine Engineering)**:
   * メガフロート用箱型浮体ブロック（ポンツーン）、バラスト調整ポンプ、大口径推進プロペラ。
2. **IND-2: 鉄鋼・耐食特殊合金 (Alloy Smelting)**:
   * 海水耐食チタン複合鋼板、高張力海底係留索。
3. **IND-5: 建材・セメント工廠 (Concrete & Geopolymers)**:
   * 埋め立て用急速硬化スラグ、消波ブロック、海底杭打ち用グラウト材。
4. **資源・食料自活の環**:
   * 海上都市が産出する「バイオ原質（養殖藻類・魚介）」は、本土の人工子宮培養液や合成食料リアクターへ送られ、内陸国家の食糧危機を救済する。
