# タイル個別化・共通フォーマット進展度システム 設計仕様書 (Tile Common Format & Progression Dynamics)

## 1. 思想的背景と設計方針

### 1.1 「タイル種程度の共通フォーマット」＋「進展度（Progression）」の狙い

タイルの用途ごとに全く異なる複雑な個別ルール（都市ルール、鉱山ルール、軍事ルール…）を多数用意してしまうと、プレイヤーの認知負荷が跳ね上がり、ゲームのテンポを阻害してしまう。
そこで本作では、**「すべてのタイルが完全に共通のデータ構造（フォーマット）を持ち、その主属性（タイル種）と【進展度合い（Progression Tier）】によって性能・外観・機能が拡張されていく」**という、極めてシンプルかつ奥深い統一システムを採用する。

- **フォーマットの共通化**: すべてのタイルは等しく「インフラ接続」「進展度（Tier 0〜4）」「稼働率」「実効支配度」「環境負荷」を持つ。
- **進展度（Progression）が主役**: 最初は荒野の仮設テントから始まり、投資・時間・兵站の維持によって徐々に恒久施設・要塞・コンビナートへと進展（深化）していく。
- **後退（Regression / 荒廃）の恐怖**: 補給や電力が途絶したり、戦火を浴びると進展度が後退・劣化する。この「維持のフリクション」が前線維持の緊張感を生む。

## 2. 共通タイルフォーマット（Universal Tile Schema）

全タイルは以下の統一データ構造を持ち、UI上でも同一のメーター・カード形式で一覧・管理される。

```rust
/// 全タイル共通のデータフォーマット
pub struct StrategicTile {
    pub id: u32,
    pub coords: (i32, i32),
    pub terrain: TerrainType,             // 土地の自然地形（平野, 荒地, 山岳, 湿地等）
    
    // 【コア属性】
    pub tile_category: TileCategory,       // タイル主区分（大枠の方向性）
    pub progression_tier: ProgressionTier, // 進展度合い（Tier 0 〜 Tier 4）
    pub progression_progress: f32,         // 次のTierへの進展蓄積値 (0.0 ~ 1.0)
    
    // 【領有・部隊配置（タイル単位管理：1タイル1部隊が原則）】
    pub controlling_faction: Option<FactionId>, // タイルの実効領有勢力
    pub active_garrison: Option<CombatGroupInstance>, // 主任務を担うアクティブ駐留戦闘団（最大1部隊）
    pub stranded_overflow_units: Vec<CombatGroupInstance>, // 移動先がなく滞留した余剰部隊（戦闘能力喪失・兵站負担加速）
    
    // 【共通状態メーター】
    pub infrastructure_connectivity: f32, // インフラ結合度 (0.0 ~ 1.0: 道路・送電・通信)
    pub operational_efficiency: f32,      // 稼働率 (インフラ供給と維持費による実効性能)
    pub effective_control: f32,           // 実効支配度 (-1.0 ~ +1.0: 統制 vs 失踪者/民兵化)
    pub environmental_hazard: f32,        // 環境負荷/胞子汚染度 (0.0 ~ 1.0: 原生生物刺激度)
    
    // 【サブタイル展開】
    pub sub_grid: Box<SubTileGrid>,       // 内部343マス（戦闘時や詳細視点での物理展開）
}
```

## 3. タイル種（大区分：TileCategory）の最小フォーマット

タイルの大区分は、複雑な細分化を避け、以下の**4つの基本カテゴリ**に集約する。

| タイル大区分 | 主な役割 | 代表的な出力・機能 | 依存する資源/インフラ |
| :--- | :--- | :--- | :--- |
| **① 産業・生産 (Industry)** | モジュール製造、兵器組立、町工場 | 工業力、補給物資、修理能力 | 電力、原材料（鉱石/炭化水素） |
| **② 資源・採取 (Extraction)** | 鉱床採掘、地熱採取、現地バイオ | 素材原料（金属、エネルギー、食糧） | 輸送路（道路/パイプライン）、労働力 |
| **③ 社会・居住 (Habitation)** | 開拓民収容、行政、研究・学術 | 人口、研究ポイント、実効支配力 | 食糧、電力、治安・低汚染 |
| **④ 軍事・前哨 (Military)** | 警戒監視、防空、防衛陣地、航空中継 | 視界、迎撃能力、弾薬/燃料集積 | 補給線（弾薬/燃料）、維持電力 |

> **未開発地 (Wilderness / Tier 0)**:
> まだカテゴリが決まっていない自然状態のタイル。インフラが到達した時点で上記のいずれかのカテゴリを選択して進展を開始する。

## 4. 進展度（Progression Tier 0〜4）の共通メカニクス

すべてのタイル種は、**共通の5段階の進展度（Tier 0 〜 Tier 4）**を辿る。進展度が上がるにつれて、大戦略上の出力が向上し、内部の343サブタイル上に物理的な施設群が自動展開・拡張される。

```text
[Tier 0: 未開地] ──(インフラ到達・設営)─→ [Tier 1: 仮設・前哨] ──(基礎整備)─→ [Tier 2: 本格運用]
                                                                                   │ (集積・投資)
[Tier 4: 要塞・中枢複合] ←──(極限特化)─── [Tier 3: 高度集積] ←───────────────────┘
```

### 段階別進展テーブル（共通 progression）

| Tier | 段階名 | サブタイル展開（343マスの占有率） | タイル状態と特徴 | 脆弱性と維持コスト |
| :---: | :--- | :---: | :--- | :--- |
| **0** | **未開地 (Wilderness)** | **0%** (自然地形のみ) | 人の手が入っていない原野。移動困難、視界なし。 | 維持費ゼロ。エイリアンの生息域。 |
| **1** | **仮設・前哨 (Outpost)** | **約 5%** (中核3〜5マス) | プレハブ設営所、簡易通信塔、資材デポ。最低限の機能発揮。 | 非常に脆弱。インフラ切断で即座に放棄・自然消滅リスク。 |
| **2** | **本格運用 (Operational)** | **約 20%** (主要施設10〜20マス) | 本格建屋、送電サブステーション、防護フェンスが完成。安定出力。 | 道路・送電の常時接続が必須。切断されると稼働率が半減。 |
| **3** | **高度集積 (Integrated)** | **約 50%** (町工場・周辺施設多数) | 下請け工房、作業員バラック、補助発電機などが自律的に集積。高効率。 | 敵のピンポイント爆撃や破壊工作の標的になりやすい。 |
| **4** | **要塞・中枢 (Fortified Hub)** | **約 80%** (重層防御・巨大複合体) | 地下シェルター、重装甲隔壁、専用変電所。親タイル全体が強固な要塞化。 | 膨大なエネルギーと維持費を消費。落とされた時の損失が致命的。 |

## 6. 進展（Promotion）と後退（Regression / 荒廃）のダイナミクス

### 6.1 進展の条件（どうやってTierが上がるか）

進展は「ボタンを押して即座に完了」するのではない。以下の3条件が満たされている間、ターンごとに `progression_progress` が蓄積され、1.0に達するとTierが1段階上昇する。

1. **インフラ結合度 (Connectivity >= 80%)**:
   - 幹線道路や送電網が安定して本土と繋がっていること。
2. **必要な資材・維持費の継続供給**:
   - 産業系なら鉱物、居住系なら食糧、軍事系なら弾薬/エネルギーが毎ターン供給されていること。
3. **治安・安全の確保 (Hazard < 50%, Control > 0)**:
   - 周囲にエイリアンの巣窟がなく、敵の奇襲や暴動に晒されていないこと。

### 6.2 後退・劣化のメカニクス（放置・補給遮断の代償）

本作の重要な緊張感として、**「維持できない領土は自然とTierが崩壊していく」**というルールが存在する。

- **インフラ切断・補給停止**:
  - 前線の軍事基地（Tier 3）への補給パイプラインが敵に切断されると、まず「稼働率（Operational Efficiency）」が激減。
  - その状態が数ターン放置されると、`progression_progress` がマイナスに転じ、**Tier 3 → Tier 2 → Tier 1 へと施設が荒廃・機能停止（デグレード）**していく。
- **実効支配度の喪失による民兵化**:
  - 居住タイルや採掘タイルの中央統制が失われると、進展度は維持されたまま、現地の住民が自衛のために「自発的失踪者・私設民兵（Dissidents）」へと看板を架け替え、国家から離反する。

## 7. タイル単位の占有権とユニット配置メカニクス

都市を介さず「タイルそのものを支配・防衛・駐留する」ための明確なルール体系。

### 7.1 タイル占有（領有権）の判定

- **占有の確立**:
  - タイル内に自勢力の戦闘団が駐留している、または自勢力のインフラ網と結ばれた進展度（Tier 1以上）が存在する場合、そのタイルの実効領有権（`controlling_faction`）が確立される。
- **無主地（Tier 0）への進入**:
  - 未開拓の親タイルへ部隊を進出させると即座に「一時占有」となる。そこに設営命令を下すことでTier 1（前哨）へと進展し、恒久領土化が開始される。
- **敵対タイルの占領（Capture）**:
  - 敵勢力のタイルに部隊が進入した場合、後述の駐留部隊との防衛戦闘が発生。
  - 駐留部隊を撃破または撤退させ、敵施設の中枢を制圧することでタイルの占有権が移行する。

### 7.2 ユニット配置の原則（「1タイル1部隊」による管理負荷の最小化）

個別部隊が増殖して毎ターンの操作が煩雑化するのを防ぐため、大戦略マップ上の**配置原則は「1タイル＝1戦闘団（アクティブ部隊）」**とする。
前線が渋滞したり退却時に行き場を失った場合のみ「スタック」が発生するが、これは軍事的強化ではなく**純粋な「兵站事故・重荷」**として扱う。

#### ① アクティブ部隊（Active Garrison: 最大1部隊）

- タイルに最初に駐留した1個戦闘団のみが、タイルの哨戒・迎撃・防衛行動をアクティブに行う。
- 大戦略マップ上での指示・命令対象も原則この1部隊のみであり、プレイヤーが1マス内の複数部隊をチマチマ切り替えて操作する手間は一切発生しない。

#### ② 余剰スタックユニット（Stranded Overflow: 移動不能な滞留部隊）

退却時に行き先がない、または包囲・交通遮断によって逃げ場を失い同一タイルに押し込まれた部隊は、**「余剰滞留ユニット（Stranded Units）」**となる。

| 項目 | 余剰滞留ユニットのルール・挙動 |
| :--- | :--- |
| **戦闘能力の喪失 (Combat Ineffective)** | 狭い同一区画に押し込められ指揮系統・射界が混乱しているため、**戦闘力はゼロ（加算されない）**。敵が攻撃してきた際も合算防御を行えず、単なる「的（巻き添え）」となる。 |
| **移動不能（Immobilized）** | タイルが空かない限り能動的な進撃・展開は不可。前方の友軍が移動して枠が空くか、後退路が開通するまで待機を強いられる。 |
| **兵站・維持負担の加速 (Exponential Burden)** | 狭隘なインフラに過密滞留しているため、食糧・水・電力・燃料の消費が**2倍、3倍と指数関数的に急増**する。 |
| **タイルの稼働率・進展阻害** | 余剰部隊が居座ることで、タイルの本来の生産・採掘・研究活動が麻痺（`operational_efficiency` が半減〜激減）。 |
| **放置時の自壊・降伏** | 補給が追いつかない状態が続くと、器材の共食い整備（スクラップ化）が始まり、最終的には部隊維持不能で自動解散・自爆または敵への投降に至る |

> **設計思想の意図**:
> 「ユニットを重ねて要塞化する」ことを完全に無意味化し、むしろ「部隊を無理に詰め込むと兵站が自爆する」というリアルな軍事フリクションを導入。これにより、プレイヤーは**自然と「1タイルに1部隊を配置して整然と前線を引く」運用に誘導**され、ユニット管理の煩雑さが根本から解消される。

### 7.3 タイル防衛戦闘の発生フロー

1. **敵部隊の進入**:
   - 敵の戦闘団が自軍タイルへ移動コマンドを実行。
2. **防衛側のアドバンテージ**:
   - タイルの**アクティブ駐留部隊（1個戦闘団）**が、地形・陣地設営ボーナスを得て迎撃。
   - タイル自身の進展度（Tier 2以上）に応じた防衛設備（タレット等）が支援。
   - ※同一タイルに余剰滞留部隊がいても戦闘力には一切寄与しない。
3. **戦闘の解決**:
   - **オートリゾルブ**: 大戦略マップ上で即座に損耗・勝敗を計算。
   - **サブタイル戦術戦**: プレイヤーが直接343マスの戦術マップへ潜り、建屋や防護壁を遮蔽物として防衛・迎撃指揮を執る。
4. **個別部隊ごとの損耗・残存と降伏判定**:
   - 戦闘終了時に「一括で全員が包囲殲滅される」ような抽象的処理は行わない。
   - 損害を受けた部隊は、**部隊ごとの損耗率、残存弾薬、士気、国家ドクトリン（降伏裁量）**に基づいて個別に判定される。
   - 戦闘継続が不可能な部隊は白旗を上げて個別降伏（捕虜化）し、指揮官や器材が耐え残った部隊は**「孤立した残存ユニット」としてそのタイルに踏みとどまる**。

### 7.4 隣接タイルの干渉と戦場過密（「みちみち」の大混戦ダイナミクス）

1つの親タイル自体は「1部隊配置」が基本原則であっても、**戦闘発生時には「周囲6方向の隣接タイル」から敵味方の増援部隊が次々と突入してくるため、戦場が部隊でみちみちに埋まる大激戦**が発生し得る。

```text
               [北の友軍戦闘団]
                     │ (増援突入)
   [西の敵戦闘団] ──> 【 交戦親タイル 】 <── [東の敵戦闘団]
                     │ (343サブタイル)
                     │ (後続の友軍)
               [南の友軍戦闘団]
   ===> 1タイル内に敵味方の複数戦闘団がひしめき合う「みちみち」状態！
```

| 現象・メカニクス | 具体的な挙動とゲームプレイ |
| :--- | :--- |
| **隣接からの逐次進入 (Sub-tile Edge Ingress)** | 隣接タイルの部隊は、サブタイル戦術マップの外周エッジ（進入元の方角）から直接物理的に突入してくる。東西南北から部隊が殺到すると、343マスが車両・歩行兵器・歩兵で文字通り「みちみち」になる。 |
| **過密による射線・機動フリクション** | サブタイル内に味方や敵がひしめき合うと、**「友軍誤射（フレンドリーファイア）リスク」「装甲車両同士の衝突・進路妨害」「砲兵の最小射程割れ」**が発生。 |
| **大戦略マップ上の「交通マヒ（グリッドロック）」** | 決戦タイルの周囲に部隊が集中しすぎると、後方の補給トラックや工兵が前進できなくなり、**周囲一帯のインフラ結合度・物資供給が一時的に麻痺**する。 |
| **戦闘終了後の再編と個別残存** | 戦闘終結時、無事な増援部隊は隣接タイルへ整然と再配置される。退却路がない敗残部隊も一律で消滅するのではなく、**壊滅寸前まで戦って降伏した部隊**と、**頑強に陣地に籠もって生き残った個別残存ユニット（次ターンの補給遮断や包囲圧力を受ける）**として厳密に個別計算される。 |

> **ゲームデザイン上の面白さ**:
> 「大戦略マップ上では1マス1部隊で整然と並んでいる」にもかかわらず、「ひとたび局所戦が始まると、周囲のタイルから敵味方が一斉に吸い寄せられてサブマップ上がみちみちの大乱戦になる」という、**マクロの操作しやすさとミクロのド派手な大戦争感（決戦の迫力）**が見事に両立する。
> さらに、戦闘結果も「全滅か生き残りか」の二元論ではなく、個別の部隊が降伏したりボロボロのまま居座ったりする**リアルな戦場残滓のドラマ**が生まれる。

## 8. 戦術マップ（343マス）との直結ルール

大戦略画面での「Tier」は、戦術画面（343サブタイル）のマップ生成・戦場構造に直接反映される。

- **Tier 1 の戦場**:
  - 大半が荒野。中央に数棟のプレハブ小屋とアンテナがあるのみ。障害物が少なく、遠距離射撃戦や機動戦になりやすい。
- **Tier 3 の戦場**:
  - サブタイルの半分が工場建屋、防護壁、パイプライン、倉庫で埋め尽くされている。市街地戦・近接遭遇戦となり、歩兵や小回りの利く軽車両・多脚兵器が遮蔽物を利用して猛威を振るう。
- **施設破壊のフィードバック**:
  - 戦術戦闘中に砲撃や爆撃でサブタイルの施設群を木っ端微塵に破壊した場合、大戦略マップ側の **`progression_progress` が大幅に削られ、戦闘終了後にTier低下（荒廃）**を招く。

## 9. 本設計によるゲーム体験の向上

1. **認知負荷の大幅な軽減**:
   - 「このタイルは何マス？」「どんな特殊建造物がある？」と悩む必要がない。
   - プレイヤーはマップを一目見て、「あのタイルは【産業・Tier 2】、こっちは【軍事・Tier 3】」と瞬時に戦力・インフラ状況を把握できる。
2. **前線維持のリアルな苦しみと作戦術**:
   - 前進してTier 1の前哨を設営するのは容易だが、それをTier 2、Tier 3へと育て上げるには、後方からの道路敷設と補給トラックの定期パトロールが不可欠。
   - 敵の背後の「Tier 3 送電タイル」を特殊部隊で急襲してTier 1へ叩き落とし、前線全体の進展を崩壊させるような**鮮やかな電撃戦・兵站戦**が楽しめる。
