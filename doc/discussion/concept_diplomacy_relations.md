# 国家間関係・外交システムの検討

本作（4X大戦略、入植惑星、架空の6国家）における国家間関係、外交力学、多層的な利害構造に関する検討ドキュメント。

---

## 1. 前提と世界観的背景

[`Faction.md`](../Faction.md) に規定されている架空の6国家：

1. **帝国(国A)**: 伝統的超大国、貴族制と大資本家、皇太子主導。
2. **大公国(国B)**: 立憲君主制・実態は共和化。建前は帝国の従属国だが実際は対抗馬。
3. **連邦(国C)**: 多様な統合連邦。アメリカ合衆国風。
4. **共和国(国D)**: 大陸西部の大国。
5. **共同体(国E)**: 企業体と労働組合による連合体、企業統治機構。
6. **連合(国F)**: 別大陸の覇権国家。制度上の統合性が高く、強大な世界トップ勢力。

### コア命題

- 「入植惑星での関係は、母星での関係とは直接一致しない」
- しかし、本星での条約・力関係（建前と実態）という**「過去のしがらみ」**と、入植惑星における領土拡張・希少資源確保・エイリアン防衛という**「現地の即物的な利害」**が複雑に交錯する。

## 2. 幅広い多層的利害関係（外交パラメータと力学）

単純な「好感度（-100〜+100）」の一元的な数値ではなく、国家間の関係性を複数の具体的な利害軸で規定する。

```text
+-------------------------------------------------------------------------+
| [1. 本星条約・建前の秩序 (Homeworld Legitimacy / Status Quo)]             |
|  - 帝国の宗主権・名目上の従属、大戦停戦協定、本星貿易協定              |
+-------------------------------------------------------------------------+
                                    ↕ 摩擦・乖離
+-------------------------------------------------------------------------+
| [2. 地政学・領土・資源利害 (Geopolitical & Frontier Friction)]          |
|  - 入植境界線の確定、緩衝地帯設定、チョークポイント（海峡/山道）の確保   |
|  - 希少資源（特異鉱脈・地熱/核融合燃料）の占有権                        |
+-------------------------------------------------------------------------+
                                    ↕ 損得・依存
+-------------------------------------------------------------------------+
| [3. 経済・産業的相互依存 (Industrial & Trade Interdependence)]           |
|  - 部品・モジュール供給（例: 共同体の電子部品 ⇔ 連邦の重工車体）       |
|  - 輸送路（民間船・回廊）の安全保障                                      |
+-------------------------------------------------------------------------+
                                    ↕ 脅威認識
+-------------------------------------------------------------------------+
| [4. 原生脅威・エイリアン安全保障 (Security & Threat Perception)]         |
|  - 大規模エイリアン侵攻への共同対処、緩衝地帯での防衛線分担             |
+-------------------------------------------------------------------------+
```

## 3. 具体的な外交状態と条約システム

### 3.1 建前と実態の多重協定

- **宗主・従属関係（建前上の従属）**:
  - 大公国Bは建前上は帝国Aの従属国だが、実質的に独自軍備と領土拡張を行う。
  - 帝国Aは従属義務（上納や支援要請）を名目に行使しようとし、大公国Bはそれを巧みに躱しながら他国（連合F等）と接近する。
- **緩衝地帯（Buffer Zone）協定**:
  - 隣接する国同士が特定タイルへの軍事戦闘団進入を禁止する不可侵緩衝区を設定。
  - 違反した民間人や調査戦闘団がエイリアンに襲撃された際の管轄権問題など、火種になりやすい。
- **航路・回廊通行権（Corridor Rights）**:
  - 海上戦闘団や輸送船が相手国の排他的影響水域・海峡を通過する権利。通商妨害や封鎖による緊張。

### 3.2 産業・技術アライアンス

- **兵器プラットフォーム・ライセンス契約**:
  - 連邦Cの重工車体ライセンスを共同体Eに供与し、見返りに共同体Eの高度電子FCSモジュールを購入する。
  - 戦争が勃発するとパーツ供給停止（サプライチェーン断絶）の危機に直面する。

### 3.3 勢力均衡（軍拡・勢力包囲）

- 連合Fや帝国Aのような超大国が単独で肥大化した場合、周囲の中小勢力（大公国B、共和国Dなど）が自然と秘密同盟や相互防衛協定を結びやすくなる。

## 4. 各国家ペアごとの固有ダイナミクス

| 国家ペア | 表向きの関係 | 実態・利害の対立点 / 協調点 |
| :--- | :--- | :--- |
| **帝国A - 大公国B** | 宗主国と従属国 | 歴史的対抗馬。名目上の敬意を払いつつ、入植地では軍事的牽制。大公国は連合Fを後ろ盾に利用。 |
| **帝国A - 連合F** | 大戦停戦国（微妙） | 新大陸の超大国同士の冷戦。直接対決は避けつつ、緩衝国の囲い込みと資源競争で対立。 |
| **共和国D - 共同体E** | 微妙・緊張 | 計画・統制志向の共和国と、利益最優先の企業国家連合。労働問題や権益独占を巡る摩擦。 |
| **連邦C - 各国** | 普通・実利志向 | バランスブローカー。通商と産業供給の要所として各陣営と等距離外交を模索。 |
| **共同体E - 連合F** | 良好 | 経済的結びつきが強く、資本・テック分野で協調関係にある。 |
