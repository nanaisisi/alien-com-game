# イベントジャンル大系・具体的カタログおよび連鎖構造設計書

(Event Genres Taxonomy, Concrete Event Catalog & Dynamic Event Chains)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**イベントのジャンル分類（大系）**、現場の物理的エンティティと結合した**具体的イベントカタログ**、および選択肢の累積が不可逆な大事件へ波及する**連鎖イベント（Event Chains）**の設計仕様書である。

---

## 1. イベント設計思想と8大ジャンル体系

従来の4Xゲームにありがちな「好感度が70になったから同盟打診が出る」「幸福度が下がったから汎用暴動が起きる」といった抽象的ポップアップを排し、**「現場（タイル/部隊/施設）」「個別文脈（原因）」「プレイヤーの倫理・戦略判断」**が噛み合って必然的に発生するイベントを8つのジャンルに分類する。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        本作におけるイベントの8大ジャンル                │
└────────────────────────────────────────────────────────────────────────┘
  │
  ├── ①【初期生存・過酷環境（フロンティア・サバイバル）】
  │     └─ 異星の大気・瘴気、食糧危機、未知の風土病、地球規格の限界
  │
  ├── ②【社会・世代間摩擦（入植社会の分断と変革）】
  │     └─ 地球生まれの第1世代（保守） vs 異星生まれの第2・第3世代（土着）
  │
  ├── ③【未知生態系・接触（ゼノ・コンタクト＆エコロジー）】
  │     └─ 巨大タイタンの回遊、群生生物の異常活性化、フェロモン交信
  │
  ├── ④【地政学・冷戦・偶発紛争（他国との境界摩擦）】
  │     └─ 国境未定地の利権争奪、脱走・亡命者、拿捕、スパイ・不正規戦
  │
  ├── ⑤【産業・技術ブレイクスルー（科学と倫理のジレンマ）】
  │     └─ 新興テック事故、禁断の遺伝子改変、無人AI暴走、規格ライセンス違反
  │
  ├── ⑥【母星（地球）からの影（星間通信・後発船団）】
  │     └─ 100年遅れの地球通信、母星本国からの不条理な勅命、難民船の降着
  │
  ├── ⑦【先住古代文明の遺産（遺跡考古学・オーパーツ）】
  │     └─ 人類以前の地下遺構、封印された防衛機構、環境制御テラフォーマー
  │
  └── ⑧【不可逆な連鎖イベント（惑星クライシス・大転換）】
        └─ 小さな選択の累積が大陸全土を揺るがす大厄災・全面戦争へ発展
```

## 2. 各ジャンルの具体的事例カタログ (Event Catalog)

### ①【初期生存・過酷環境（フロンティア・サバイバル）】

#### E-101: 地球規格エアフィルターの目詰まり事故

* **発生状況**: 瘴気（ミズマ）帯に隣接した第1開拓都市。
* **事象**: 地球から持ち込んだ高密度フィルターが、異星特有の微細結晶粉塵によって想定の10倍の速度で目詰まりを起こし、換気停止の危機に直面。
* **選択肢と結末**:
  * **[選択A] 予備部品を緊急充当**: 基礎工業部品（Layer 1）を即座に消費して交換。都市機能は維持されるが、軍用補給物資が一時的に枯渇。
  * **[選択B] 現地シリカ粘液による代用コーティング**: 現地植物の粘液をフィルターに塗布。耐性は向上するが、住人に微弱な幻覚・アレルギー症状（一時的な生産効率低下）。
  * **[選択C] 工業地区の強制換気停止**: 民間居住区のみ守り、重工プラントを一時シャットダウン。資材は温存できるが生産遅延。

#### E-102: 食糧備蓄庫の未同定カビ汚染

* **発生状況**: 雨季を迎えた農業タイル。
* **事象**: 地球産小麦サイロに異星由来の赤色菌糸が侵入し、全備蓄の半分が汚染される。
* **選択肢と結末**:
  * **[選択A] 汚染区画の即時焼却**: 安全を優先。食糧備蓄が激減し、配給制限による不満度上昇。
  * **[選択B] 菌糸の成分抽出・品種改良（バイオ研究）**: 毒性を中和し、現地環境に強いハイブリッド穀物への転換を試みる（技術ポイント獲得、低確率で食中毒発生）。
  * **[選択C] 他国への食糧緊急輸入要請**: 隣接する他国へ食糧支援を要請（外貨・資源流出、外交的借りを作る）。

### ②【社会・世代間摩擦（入植社会の分断と変革）】

#### E-201: 「故郷を忘れた子供たち」の成人式

* **発生状況**: 入植後30年〜50年が経過し、第2世代（現地生まれ）が労働人口の中核を占めた都市。
* **事象**: 地球の祝日を祝う式典に対し、現地生まれの若者たちが「一度も見舞われたことのない青い地球の歌を歌う意味はない」と反発し、現地植物の開花祭を公認するよう要求。
* **選択肢と結末**:
  * **[選択A] 地球伝統の徹底（地球純血主義）**: 伝統規律を厳格化。治安・士気は維持されるが、若年層の不満蓄積・生産性低下。
  * **[選択B] 新生惑星文化の公認（土着・現地適応）**: 祝祭を改定し現地適応を祝福。アフィニティが「現地適応」へ傾斜し、現地資源の採取効率が恒久向上。
  * **[選択C] 企業主導のプラグマティズム（合理主義）**: 双方の感情を退け、年間労働目標の達成率に応じた能力給制度へ移行。

#### E-202: 密閉シェルター撤廃デモ（「外気呼吸権」の主張）

* **発生状況**: 瘴気浄化が進んだ都市、または第3世代が増加した都市。
* **事象**: 現地大気への耐性を獲得しつつある若年開拓民が、高圧密閉ドームの出入り制限を「旧世代による監視と過剰統制」と見なし、外気解放ゲートの開放を要求。
* **選択肢と結末**:
  * **[選択A] 段階的減圧・外気解放区の設置**: コストをかけて中間減圧区画を新設。都市の幸福度上昇、現地適応アフィニティ上昇。
  * **[選択B] 安全基準の維持とデモ解散**: 医療リスクを理由に拒否。旧世代の支持は維持されるが、一部の若者が都市を離れて辺境農村へ不法離脱。

### ③【未知生態系・接触（ゼノ・コンタクト＆エコロジー）】

#### E-301: 巨獣（リヴァイアサン級）の産卵回遊

* **発生状況**: 大陸横断運河や鉄道網の敷設ルート上。
* **事象**: 数十年に一度、大陸を縦断して海岸へ向かう超巨大エイリアンの群れが、自軍の重要補給路（兵站パイプライン）に向かって直進している。
* **選択肢と結末**:
  * **[選択A] 砲兵・戦闘団による実力排除**: 機甲部隊を展開して射殺。巨獣の生体装甲素材を大量獲得するが、周囲の野生エイリアン全体の警戒度（Aggression）が急上昇。
  * **[選択B] 超音波・フェロモンによる進路誘導**: 費用を投じて音響発振器を前線配置し、荒野へ迂回させる（補給路防衛、環境負荷小）。
  * **[選択C] 敵対他国の回廊へ意図的誘導**: 進路を微調整し、他国の採掘前哨基地へ直撃させる（他国へ甚大な損害、露見時に重大な開戦事由）。

#### E-302: 巣窟（Nest）からの低周波パルス傍受

* **発生状況**: 調査戦闘団が古代巣窟タイルの境界を調査中。
* **事象**: 巣窟深部から、自然現象ではあり得ない数学的規則性（素数列）を持った低周波音波が観測される。
* **選択肢と結末**:
  * **[選択A] 心理感応アンテナによる応答送信**: 通信を試みる。成功すると巣窟との共生親和度が上昇し、特殊バイオ技術が解禁。失敗すると部隊が精神的混乱（パニック）。
  * **[選択B] 巣窟中枢への電撃急襲**: 知性化する前に巣窟を壊滅させ、中枢核を摘出（大量の科学ポイント獲得、周辺巣窟の激怒）。
  * **[選択C] 観測ステーションの恒久配置**: 一定距離を保ち、長期的な生態モニタリングを継続。

### ④【地政学・冷戦・偶発紛争（他国との境界摩擦）】

#### E-401: 国境未定地での他国探査船拿捕事件

* **発生状況**: 領土境界の緩衝地帯。
* **事象**: 大公国Bの武装探査団が、自国が発見したレアアース結晶タイルの試掘を無断で開始しているのを発見。
* **選択肢と結末**:
  * **[選択A] 武装解除と乗員拿捕**: 探査団を拘束し機材を押収。相手国の最新モジュール技術をリバースエンジニアリング可能だが、相手国との外交関係が「敵対」へ急落。
  * **[選択B] 警告射撃による国外退去**: 主権を示しつつ穏便に追い出す。既成事実は防げるが技術的収穫はなし。
  * **[選択C] 共同採掘協定の緊急打診**: 資源を50%ずつ分け合う合弁事業を提案（通商関係改善、経済的果実の共有）。

#### E-402: 他国亡命軍用機（パイロット）の不時着

* **発生状況**: 自国前線基地または沿岸部。
* **事象**: 帝国Aの最新鋭ステルス偵察機が被弾し、自国滑走路へ不時着。パイロットは政治亡命を希望している。
* **選択肢と結末**:
  * **[選択A] 亡命を受け入れ機体を解体調査**: 相手国の軍事機密・暗号キー・ステルス塗膜技術を入手。相手国から最後通牒（開戦危機）。
  * **[選択B] 機体とパイロットを返還**: 相手国への誠意を示し、緊張緩和と賠償金（物資）を受け取る。国内世論（軍部）は軟弱外交と批判。
  * **[選択C] 第三国（連合F）へ極秘売却**: 闇ルートで他国へ横流しし、巨額の外貨と工業物資を獲得。

### ⑤【産業・技術ブレイクスルー（科学と倫理のジレンマ）】

#### E-501: 自律AIエッジノードの「誤射」シミュレーション

* **発生状況**: Tier 2無人兵器（自律僚機）を試験運用中の戦闘団。
* **事象**: 前線AIが通信途絶下で行った迎撃シミュレーションにおいて、友軍の補給トラックを「敵性エイリアン変異体」と誤認・攻撃する確率が12%に達すると判明。
* **選択肢と結末**:
  * **[選択A] キルチェーン厳格化（有人承認の完全義務付け）**: 誤射をゼロにするが、無人兵器の反応速度・命中率にペナルティ。
  * **[選択B] アルゴリズムの現場実戦学習を容認**: 現場配備を強行（実戦投入）。戦闘能力は向上するが、将来的に友軍誤射イベントのリスクを抱える。
  * **[選択C] 新興テック企業へのペナルティと開発差し戻し**: ソフトウェア納入企業に損害賠償を請求。無人化技術の研究が一時停滞。

### ⑥【母星（地球）からの影（星間通信・後発船団）】

#### E-601: 70年遅れの超空間電信「本国秩序の崩壊」

* **発生状況**: ゲーム中期、深宇宙通信アレイを建設後。
* **事象**: 地球本星から微弱な暗号電信を受信。「母星で大規模核交換／気候崩壊が発生し、中央政府が瓦解。以後、各植民地は独自の判断で自活せよ」。
* **選択肢と結末**:
  * **[選択A] ニュースの完全秘匿（情報統制）**: 社会パニックを防ぐため軍部・上層部のみで隠蔽。地球規格の継続を装うが、発覚時の暴動リスク。
  * **[選択B] 「惑星独立宣言」の即時布告**: 地球本星との法的紐帯を断ち、新国家として独立。住民の独立意識が高まり、生産・研究ボーナス。
  * **[選択C] 全勢力へ公表し「惑星統一サミット」を招集**: 他国へ情報を開示し、地球の滅亡を前提とした新たな秩序形成を主導。

#### E-602: 突如出現した「第2波移民船」の軌道上停泊

* **発生状況**: ゲーム中期。
* **事象**: 100年遅れで母星を出発した巨大世代船が惑星軌道上に到達。船内には数十万人の避難民と、老朽化したが膨大な地球規格の機械類が積載されている。
* **選択肢と結末**:
  * **[選択A] 自国領内への優先降着と全受け入れ**: 都市人口が爆発的に増加し、初期労働力と工業基盤を獲得。ただし食糧危機・住宅不足・風土病感染のリスク。
  * **[選択B] 厳格な検疫と技術者・軍人のみ選別収容**: 有用な人員と資材のみ接収。残りは他国の降着地点へ誘導。
  * **[選択C] 軌道上での解体と資材投下（移民拒絶）**: 船体資材のみを地表へ落とし、人口流入を拒絶（国内治安は安定、人道条約違反フラグ）。

### ⑦【先住古代文明の遺産（遺跡考古学・オーパーツ）】

#### E-701: 地下巨大テラフォーマーの再起動

* **発生状況**: 古代遺跡タイルを調査戦闘団が発掘完了。
* **事象**: 惑星の地殻深くに、数万年前に先住文明が設置した巨大な気候制御プラントが眠っていた。起動すれば大陸全体の瘴気を浄化できる可能性があるが、地殻変動を誘発する恐れがある。
* **選択肢と結末**:
  * **[選択A] 全出力再起動（惑星大気浄化）**: 大陸全体の瘴気濃度が恒久的に低下。ただし直後に巨大地震が発生し、沿岸インフラに損害。
  * **[選択B] 機構の解体と超伝導コアの回収**: プラントを動かさず、内部のオーパーツ（常温超伝導リアクター）を都市へ持ち帰り、自国のエネルギー出力を倍増。
  * **[選択C] 封印の維持と現状保存**: 不測の事態を恐れて再封印。

## 3. 連鎖イベント（Dynamic Event Chains）のメカニズム

単発で終わるイベントとは異なり、**「選択した結果が数ターン〜数十ターンにわたって段階的に悪化・変異・拡大していく」**不可逆な連鎖構造。

```text
┌──────────────────────────────────────────────────────────────┐
│       連鎖構造例：【胞子パンデミックと生体兵器化の道】       │
└──────────────────────────────────────────────────────────────┘
  [Phase 1: 兆候]
    農業タイルで作業中の兵士が未知の胞子に感染（咳と皮膚の硬質化）
      ├─ 選択A: 感染者を完全隔離（人権侵害・現場反発） ───→ [Phase 2Aへ]
      └─ 選択B: 特効薬を求め現地エイリアン組織を研究 ───→ [Phase 2Bへ]
                          │
  [Phase 2A: 隔離都市の蜂起]
    隔離コロニーで不満が爆発、武装暴動が発生
      ├─ 選択A-1: 軍事鎮圧（自国民への発砲・治安悪化）
      └─ 選択A-2: 経済封鎖と放置（数ターン後に変異ミュータント軍閥へ変貌）
                          │
  [Phase 2B: 生体変異の軍事転用]
    研究陣が「皮膚硬化による防弾効果」を発見
      ├─ 選択B-1: 兵士への合意の上での生体強化剤実戦投与（超人歩兵の解禁）
      └─ 選択B-2: 倫理条約違反として研究凍結（平和維持）
                          │
  [Phase 3: 惑星規模の帰結 (Final Outcome)]
    ・超人歩兵部隊の反乱／他国からの「生物兵器使用」に対する国際制裁
    ・あるいは、原住エイリアンとの完全な免疫共生（調和アフィニティへの不可逆シフト）
```

## 4. イベント実装アーキテクチャ (Bevy ECS連動)

ゲームエンジン（Rust / Bevy）において、これらのイベントを表現するためのデータ構造。

```rust
// イベントトリガーの条件定義
#[derive(Component)]
pub struct EventTriggerCondition {
    pub target_tile: Option<Entity>,      // 現場タイル（特定プラント、巣窟、国境）
    pub involved_faction: Option<Entity>, // 関与勢力
    pub required_affinity: Option<AffinityType>,
    pub trigger_state: EventState,        // 兆候、発生中、連鎖待機
}

// 連鎖イベントを管理するステートマシン
#[derive(Component)]
pub struct EventChainNode {
    pub chain_id: String,                // 例: "spore_pandemic_01"
    pub current_phase: u32,              // フェーズ1〜3
    pub turns_until_next_escalation: u32,// エスカレーションまでの猶予ターン
    pub player_choice_history: Vec<u32>, // 過去の選択履歴
}
```

## 5. まとめと今後の拡充

1. **現場主義**: 全てのイベントは「全体マップのどこかのマス」で発生し、地図上の部隊や都市に目に見える影響を与える。
2. **白黒つけられないジレンマ**: 単なる「正解」の選択肢は存在せず、どの選択肢も「資源、軍事、外交、住民感情」のいずれかに代償を強いる。
3. **連鎖の醍醐味**: 開拓初期の些細な「カビの放置」や「探査船の拿捕」が、50ターン後の世界大戦や生態系大暴走の直接の引き金となるドラマ性を実現する。
