# 今後の実装・世界観設計検討書：SF大戦略における時空階層と産業・戦術構造

本ドキュメントは、大戦略（マクロ）と局所戦術・内政（ミクロ/サブタイル）の融合を目指す本作において、今後の実装検討に向けた論点・設計思想・システム構造を体系化した検討書である。

主に以下のコア論点を取り扱う：
1. **世界観とSF設定の難しさ**（定常化した未来世代概念、変化後という「定着した未来」の描画）
2. **タイル内タイル（サブタイル）の施設タイル化**
3. **マクロ河川とサブタイル河川の連続性・水系インフラ**
4. **工業サブタイルの複数機能化（コンビナート化・複合産業）**
5. **産業構造と兵器モジュール体系**（ジャンル別メーカー制、共通モジュール、部隊内小部隊の装備連動）

---

## 1. SF世界観設計の難しさ：「未来という定常化した世代概念」と「変化後」のジレンマ

### 1.1 「未来という定常化した世代概念」の難しさ
古典的なSFや歴史ストラテジーでは「技術ツリーを進める＝未来へ向かう」という進歩史観が前提となる。しかし、植民星系や遥かな未来においては以下のような**定常化の壁**が存在する：

1. **「超未来」の日常化（コモディティ化）**:
   - 地球を脱出し新惑星に到達した世代にとって、反重力、遺伝子編集、ナノマシン、AIなどは「驚くべき新技術」ではなく、単なる「蛇口をひねれば水が出る」レベルのインフラ・既得技術（定常状態）である。
   - プレイヤーにとってはSF的な驚異に見える技術も、作中世界の人間にとっては「当たり前の制約・コスト・常識」として固定化している。
2. **世代による断絶と世界観の平準化**:
   - 開拓第一世代（地球の記憶・技術体系を持つ）から、第二・第三世代（植民星生まれ）への移行に伴い、技術への崇拝や進歩意欲は「局所的な生存」「既にある機械の維持・だましだまし運用」へと矮小化・定常化しやすい。
   - ゲームデザイン上、「時代（Era）の進化」を単なる数字の上昇（攻撃力+10%）にするのではなく、**「新惑星の定常環境と人間側の世代的価値観の変容（アフィニティ・生存哲学）」**として落とし込む必要がある。

### 1.2 「変化後（ポスト・カタストロフ／ポスト・アライバル）」の難しさ
「未知の惑星に降り立った直後の大変革」から、ある程度時間が経過した「変化後」の世界を描く難しさ：

1. **「新常識」が固定化した世界の歪み**:
   - 瘴気（Miasma）や原住エイリアンの存在は、初期には「異常事態」だったが、数十年経てば「天気予報で花粉情報を見るように、今日の瘴気濃度をチェックする」という**過酷な環境の日常化**が生じる。
   - 異変そのものが日常化した社会において、軍事・産業・都市構造は「対エイリアン・対環境防護」を前提として極限まで最適化・硬直化している。
2. **「過去へのノスタルジー」と「不可逆な変異」の相克**:
   - 地球型産業（製鉄、内燃機関、標準工業規格）を保とうとする「純正派」と、惑星環境・エイリアン生態系を産業基盤に組み込んだ「共生・適応派」の間で、**技術基盤そのものの互換性が喪失**していく。
   - これにより、後述する「産業構造」「兵器モジュール」の規格統一に深刻な亀裂が生じる（地球規格メーカー vs 惑星適応バイオメーカー）。

## 2. サブタイルにおける「施設タイル化」の設計

親タイル（大ヘックス）内部に展開されるサブタイル（小ヘックス群：半径3＝37ヘックス または 半径4＝61ヘックス）において、単なる自然地形だけでなく**都市・インフラ・軍事拠点を「施設タイル」としてどう配置・機能させるか**の仕様設計。

### 2.1 施設タイルの種別と階層

親タイルが「都市」「工業基地」「要塞」である場合、サブタイル内部は単一の箱ではなく、機能分散した**都市複合体（シプレックス）**として展開される。

```text
               [サブタイル内部の施設展開イメージ]
                         (山岳・フリンジ)
                             /\
                       /‾‾‾‾\  /‾‾‾‾\
                      | 行政核 | 工業A |
                /‾‾‾‾\ \____/  \____/ /‾‾‾‾\
               | 住宅区 |      | 兵站倉 | 防衛砲台 |
                \____/  \____/  \____/ \____/
                      | 港湾/川 | 水力発電|
                       \____/  \____/
                             \/
```

1. **中枢施設（Core Facilities）**:
   - **都市行政コア（City Core）**: 親タイルの支配権・防衛の要。ここが制圧されると親タイル全体が陥落・降伏判定となる。
   - **司令本部・通信タワー（HQ & Relay）**: 小部隊への指揮範囲・戦術スキル供給源。
2. **機能特化施設（Functional Outposts）**:
   - **防衛施設（タレット・シールド発生器・掩体壕）**: 小部隊が駐留することで強力な遮蔽ボーナス・迎撃射撃を提供。
   - **兵站集積所・整備ドック（Logistics Depot）**: 範囲内の小部隊の弾薬・装甲補修・燃料を毎ターン回復。
   - **エネルギー供給施設（発電プラント・地熱タワー）**: 破壊されると防衛施設やシールドが機能停止する。

### 2.2 施設タイルのゲームメカニクス
- **占領と破壊の非対称性**:
  - 攻撃側は「施設を砲撃で瓦礫にして無力化する」か「歩兵小隊で突入して無傷で鹵獲する」かを選択できる。
  - 無傷で占領すれば、マクロ復帰後にその施設の生産・研究ボーナスをそのまま獲得可能。
- **都市型戦闘（CQB）の発生**:
  - 施設タイル内は視界（LoS）が遮られ、戦車や大型兵器の機動力が低下。歩兵小隊や近接兵器が極めて有利になる戦術空間を創出。

## 3. マクロ河川とサブタイル河川の幾何学的・戦術的接続

親タイルの「タイル間河川（Hex Edge Rivers）」が、サブタイル内部の「河川タイル（Hex Face River / Water Tile）」へどう連続的に変換されるか。

### 3.1 幾何学的接続モデル：エッジからメッシュへの展開

```text
【大戦略（親タイル）】                【サブタイル（内部展開）】
     タイルA                               タイルA (外周フリンジ)
      /   \                                    / \
     /     \                                  /~~~(川の流入点)
====[ 河川 ]==== (境界エッジ上)    ===>       | ~~~ |
     \     /                                  |  ~  (渡河点/中州)
      \   /                                   \ ~~~ (川の流出点)
     タイルB                                   \ /
```

1. **親タイルの河川定義（Hex Edge）**:
   - 大戦略レベルでは、河川はヘックスの「辺（Edge）」を流れる。移動コスト増加や防御側ボーナスとして機能。
2. **サブタイルへの射影ロジック（Edge-to-SubGrid Mapping）**:
   - 親タイルの特定の辺（例：北東辺）に河川が存在する場合、サブタイルの北東側外周フリンジから、反対側の辺（あるいは自然な高低差に従ったエッジ）へ向かって**サブタイルヘックス列として川が貫通描画**される。
   - 単なる直線ではなく、パーリンノイズ等の地形生成により、サブタイル内では蛇行（Meander）、中州、浅瀬（フォード）が形成される。

### 3.2 水系インフラと戦術的意義
- **渡河ペナルティと架橋工兵**:
  - 深い河川サブタイルは歩兵・装甲車両が侵入不可（または極端な移動力消費）。
  - 「浅瀬」「橋梁施設」「工兵による即席架橋」が戦術上のチョークポイント（激戦地）となる。
- **水運・取水インフラ施設**:
  - 河川沿いのサブタイルには「浄水プラント」「工業冷却用取水塔」「水上輸送ドック」などの特有施設が自動生成され、都市の経済値・工業値に補正を与える。

## 4. 工業サブタイルの「複数機能化」（コンビナート化）

大戦略ゲームにありがちな「工業タイル＝ハンマー（生産力）が+5されるだけの無機質なマス」を脱却し、サブタイル内の工業施設群に**複合的な役割（生産・兵站・改修・エネルギー循環）**を持たせる。

### 4.1 単機能工場から「複合コンビナート」へ

1つの工業親タイルの中には、複数の役割を持ったサブ施設が共存・連携する：

| サブ施設種別 | 直接機能（ミクロ戦術時） | マクロ大戦略への還元機能 |
| :--- | :--- | :--- |
| **重機組立ドック** | ビークル小隊の即時HP修復・弾薬再装填 | 戦闘団の生産・補充ターン短縮 |
| **精製・製錬プラント** | 引火・爆発トラップ（攻撃で敵を巻き込む） | 特殊資源（レアメタル・樹脂）の供給 |
| **動力変電サブステーション** | 防衛ドローン・EMP兵器の給電拠点 | 工業タイル全体の稼働効率向上 |
| **モジュール規格換装ヤード** | 戦闘団内の兵器モジュール即時交換 | 前線での部隊アップグレード・仕様変更 |

### 4.2 資源・エネルギー連鎖と弱点の創出
- **パイプライン・電力網の切断**:
  - サブタイル内の「発電施設」や「精製パイプライン」を特殊部隊でピンポイント破壊されると、重機組立ドックが停止し、そのタイルでの部隊補充がマクロ層で数ターン不能になる。
- **副産物の利用（エコシステム連動）**:
  - 工業排水や排熱が周囲の河川や森林サブタイルに影響を与え、エイリアンを誘引する（あるいは特定の変異エイリアンを撃退する防壁になる）など、環境パラメータとの双方向結合。

## 5. 産業構造の定義：兵器モジュールのジャンル別メーカー制と共通性

戦闘団（戦闘集団）を構成する小部隊（戦車、歩兵戦闘車、自走砲、航空機など）の装備・モジュールにおいて、**リアリティとカスタマイズ性を両立する産業構造**を定義する。

### 5.1 産業のリアリティ：「単一メーカー」ではなく「産業エコシステムの組み合わせ」

現代・近未来の軍事産業を直視すると、兵器は単一の「〇〇社製」で完結することは稀である。
- **実例の構図**:
  - 先進大型無人機（UAV/UCAV）を開発する場合でも、機体・動力・原子力／大型プラットフォームを担う**「老舗の重工・原子力大手」**と、自律飛行AI・センサ統合・ソフトウェアを担う**「新興防衛テック企業（AndurilやPalantir等のようなスタートアップ）」**が協業・重複して参画する。
  - さらにその足元には、表に名前は出ないが超精密加工や油圧、特殊ボルト、電子基板を供給する**無数の「サプライヤー／町工場（産業基盤・サプライチェーン）」**が存在し、これらが揃って初めて兵器が成立する。

しかし、これをゲーム内で「数千社の下請け・部品企業を管理する」形にすると、プレイヤーの認知負荷が爆発し、大戦略（4X）としてのゲームプレイが破綻してしまう。
したがって、**「リアリティを感じさせつつ、操作は直感的に収まる（抽象化・自動化された）産業エコシステム設計」**を目指す。

---

### 5.2 産業構造の3層レイヤー（抽象化モデル）

兵器開発・生産を、以下の3つの「産業レイヤーの組み合わせ」として表現する。

```text
+-------------------------------------------------------------------------+
| [Layer 3: 新興テック・特化企業 (Emerging Tech)]                           |
|  - 自律AI、高度電子戦、エイリアン生体神経同調、指向性エネルギー          |
|  - 「革新的機能・特異能力」を付与（ソフトウェア・アビオニクス）           |
+-------------------------------------------------------------------------+
                                    │ 統合・協業 (Co-Development)
+-------------------------------------------------------------------------+
| [Layer 2: 既存重工大手 (Prime Contractors / Heavy Industries)]           |
|  - 車体/機体フレーム、大型動力炉（核融合/タービン）、大口径火砲          |
|  - 「基本スペック・耐久力・量産規模」を担保（プラットフォーム）          |
+-------------------------------------------------------------------------+
                                    │ 立脚・支台 (Underpinned by)
+-------------------------------------------------------------------------+
| [Layer 1: 都市・タイルの基礎産業基盤 (Industrial Base / Supply Chain)]    |
|  - 特殊鋼、微細加工、樹脂、規格ボルト、熟練整備工（町工場群）            |
|  - サブタイルの工業集積度（コンビナート規模）によって自動計算される基礎値 |
+-------------------------------------------------------------------------+
```

1. **Layer 1: 基礎産業基盤（目に見えない町工場群・サプライチェーン）**:
   - プレイヤーが個別企業名を選ぶ必要はない。都市やサブタイルの「工業化レベル」「熟練工インフラ」として**バックグラウンドで自動集計**。
   - これが不十分な辺境植民都市では、「いくら設計図があっても部品精度が出ず、最新兵器の稼働率・整備性が激減する」という形でリアルに反映。
2. **Layer 2: 重工プラットフォーム（ベース車体・機体）**:
   - 装軌車体、装輪車体、大型航空フレーム、艦体など。
   - 複数の兵種（戦車、歩兵戦闘車、自走砲）が**「同一の共通プラットフォーム」**から派生することで、量産コスト削減・生産ライン共用が可能。
3. **Layer 3: 機能特化・新興モジュール（協業コンポーネント）**:
   - RWS（リモートウェポンステーション）、長距離FCS、アクティブ防護（APS）、生体センサなど。
   - 重工の頑丈な箱の上に、新興企業の最新電子装備やエイリアン共生パーツを「アドオン」する。

---

### 5.3 兵種間のモジュール共通性と「重複・協業」のリアリティ

兵器カテゴリー間（戦車、装甲車、防衛タレット、大型無人機など）で、部品やモジュールがどう共通化され、産業的に連動するか：

1. **RWS（Remote Weapon Station）の普遍的共通性**:
   - 装輪装甲車の上面、主力戦車の車長用銃塔、基地サブタイルの防衛トーチカに、**全く同一の新興テック製RWSユニット**が流用・搭載される。
   - **ゲーム的メリット**: RWSを開発・量産するだけで、陸上戦闘団の近接防空能力と都市防衛タレットの迎撃能力が同時に底上げされる。
2. **大型プラットフォームと無人化・新興技術の融合**:
   - 重工メーカーが製造した旧世代の頑丈な「装甲兵員輸送車」や「大型輸送機」のフレームに対し、新興防衛企業が「無人自律操縦キット」を供給して最新の大型無人兵器（UGV / UCAV）へ再生・改修。
   - まったく新しい兵器を1から開発するのではなく、**「既存の重工車体 × 新興テックのAIモジュール」の掛け算**で新兵器種が誕生する。
3. **兵站・整備性（Logistics）への自動反映**:
   - 部隊（戦闘団）内で同じ重工プラットフォームや共通モジュールを多く採用している場合、**「部品の共用化率（Commonality）」**が自動計算され、現場の整備小隊の修理速度向上や、損耗補充コストの低下として還元される。

---

### 5.4 プレイヤーの操作量（UI/UX）を増やさない「自動化とプリセット」

「町工場や多重下請けのリアリティ」を出しつつ、プレイヤーをマイクロマネジメント地獄に落とさないためのルール：

- **基本は「完成品パッケージ（制式採用プリセット）」**:
  - ゲーム側であらかじめ「〇〇重工プラットフォーム＋△△テック社FCS＋標準規格サプライチェーン」による標準兵器テンプレートを用意。
  - プレイヤーは「標準型」をそのまま生産・配備するだけでOK。
- **こだわりたい場合の「モジュール換装」**:
  - 「装甲を少し落として、新興企業の最新APS（アクティブ防護）を積む」「旧式車体にエイリアン生体装甲を貼り付ける」といった一部の換装のみをスロット式で選択可能にする。
- **産業基盤の自動成長**:
  - サブタイルで工業タイルを発展させると、自動的に地域の「産業基盤（町工場サプライチェーン指数）」が上昇し、その都市で生産される全兵器の信頼性・品質がパッシブに向上する。

## 6. まとめと今後の検討ステップ

| フェーズ | 検討・検証項目 | 具体的アウトプット |
| :--- | :--- | :--- |
| **Step 1** | **世界観・設定の骨子決定** | 世代概念（第1〜第3世代の価値観変容）と3大メーカーのフレーバーテキスト策定 |
| **Step 2** | **幾何学・描画PoC（河川・施設）** | 親タイルエッジ河川からサブタイル河川へのプロシージャル変換アルゴリズム試作 |
| **Step 3** | **工業サブタイルのデータ構造定義** | サブタイル施設（ドック、発電、精製）がマクロ生産・兵站に与える変数設計 |
| **Step 4** | **兵器モジュール・メーカー制プロトタイプ** | 共通モジュール（シャシー、動力、主兵装）と戦闘団ステータス連動ロジックの実装 |
