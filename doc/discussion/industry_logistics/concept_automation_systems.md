# ゲーム内「自動処理（Automation System）」総合検討・仕様書

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「自動処理（オートメーション）」の全体設計思想、対象ドメイン、内部シミュレーションの計算構造、およびプレイヤー体験（UX/インスペクション）**について網羅的に検討・定義した設計仕様書である。

---

## 1. 全体設計思想：「要素は細密・多層、操作は集約・自動化」

### 1.1 背景と課題：マイクロマネジメント地獄の回避

4Xゲームや戦略シミュレーションにおいて、リアリティや深みを追求して「部品単位の規格」「兵站サプライチェーン」「下請け町工場」「弾薬口径の適合」「各都市の施設建設」などの変数を細かく設定すると、ターン経過に伴ってプレイヤーの操作量が指数関数的に爆発し、ゲームプレイが作業（マイクロマネジメント地獄）と化す。

### 1.2 核心原則：シミュレーション解像度とプレイヤー入力の分離

本作では、以下の2層アーキテクチャによって「圧倒的なリアリティ・世界観の厚み」と「テンポの良い快適な大戦略体験」を両立する。

```text
+-----------------------------------------------------------------------------------------+
| 【プレイヤー入力層（高位マクロ操作）】                                                  |
|  - ドクトリン指定（コスト重視 / 性能重視 / 共通化重視 など）                             |
|  - ゾーニング指定（工業特化 / 農業維持 / 防衛拠点化 など）                               |
|  - 優先順位・大枠予算スライダー（防空優先 / 弾幕優先 / 艦艇建造枠 など）                |
+--------------------------------------------┬--------------------------------------------+
                                             │ 指針・パラメータ伝達
                                             ▼
+-----------------------------------------------------------------------------------------+
| 【内部自動処理エンジン（低位ミクロ自律計算）】                                          |
|  - 補給幕僚AI / 企業AI / サプライチェーンルーター / 自律都市発展 / オートリゾルブ        |
|  - グラフ探索（最適モジュール調達・代替互換判定・サプライチェーン最短経路）             |
|  - 経験値波及・改修パッチ自動配信（トポロジー伝播）                                     |
+--------------------------------------------┬--------------------------------------------+
                                             │ 状態・結果のフィードバック
                                             ▼
+-----------------------------------------------------------------------------------------+
| 【プレイヤー認知層（インスペクション・覗き見の楽しさ）】                                |
|  - ユニット詳細パネル：「裏で精緻な産業基盤が動いていること」をフレーバー＋実数値で可視化 |
|  - NPC国家のジレンマ観察：自動化の恩恵とNPCの補給破綻・トラブルの対比                    |
+-----------------------------------------------------------------------------------------+
```

## 2. 自動処理の4大ドメインとメカニクス

ゲームシステムにおける自動処理は、大きく以下の4領域に分類される。

| ドメイン | 対象領域 | プレイヤー操作（マクロ） | 内部自動処理（ミクロエンジン） |
| :--- | :--- | :--- | :--- |
| **① 軍備・兵器調達** | モジュール選定、代替充足、弾薬管理 | 調達ドクトリン設定、更新優先度 | 最適モジュール選択、互換代替判定、口径平準化 |
| **② サプライチェーン・兵站** | 部品供給、インフラ経路、改修伝播 | 輸送網建設、補給拠点防衛 | 最小コスト経路探索、ボトルネック検出、品質伝播 |
| **③ 内政・都市発展** | サブタイル施設配置、民間投資 | タイル特化指定、ゾーニング | 民間施設自律増殖、工業集積度計算、公害・需要調整 |
| **④ 戦闘・戦術解決** | 接敵時の戦闘、小部隊指揮 | 手動指揮 vs 自動解決の選択 | 陣形・増援・射程・損耗の統計的即時計算（オート） |

## 3. ドメイン別詳細仕様

### 3.1 軍備・兵器調達の自動化（Procurement AI）

#### (1) 調達ドクトリンによる自動構成

プレイヤーが戦闘団を編成・新設する際、車体フレームや主砲、FCS、エンジン等の細部パーツを1点ずつ手動選択する必要はない。国家または方面軍ごとに設定された**「調達ドクトリン」**に基づき、補給幕僚AIが最適なモジュールを自動選定・発注する。

- **ドクトリンプリセット例**:
  - **低コスト・大量配備（Mass-Production）**: 既存の旧式重工シャシー＋標準ボルト規格＋汎用火器。生産ターン短縮、維持費最小化。
  - **人命尊重・ハイテク防護（High-Tech / Survivability）**: 先進半導体FCS＋アクティブ防護（APS）＋熟練町工場の高精度部品。高コストだが生存率・戦闘効率極大。
  - **現地調達・バイオ適応（Bio-Adaptive）**: 撃破したエイリアンのキチン質外殻や生体燃料を積極流用。孤立した前線基地での自給自足率向上。

#### (2) 類似性マトリクスに基づく「代替モジュールの自動互換充足」

前線で戦闘団が損耗した際、補給線上に正規部品の在庫がない場合でも、システムは「産業・モジュール類似性マトリクス」を参照して自動で代替補充を行う。

$$\text{補充判定} = f(\text{Similarity}(M_{\text{req}}, M_{\text{stock}}))$$

- **類似度 1.0（完全一致・完全互換）**: ペナルティなしで即座に補充完了。
- **類似度 0.70 〜 0.85（近縁モジュール）**: 現場調整工数（整備時間わずかに延長）が発生するが、戦闘団の稼働率を維持したまま充足。
- **類似度 0.30 以下（非互換）**: 互換不可。部品到着待ちとなり、戦闘団の一部中隊・小隊が稼働停止状態となる。

#### (3) 弾薬・火工品の自動平準化

弾薬の口径（105mm/120mm/155mm等）や炸薬原料の配分は、プレイヤーが工場ごとに指示するのではなく、軍団全体の需要予測に基づき自動平準化される。
口径統合を進めているプレイヤー国家は「調達・補給コストの逓減（スケールメリット）」を自動的に享受できる。

---

### 3.2 兵站・サプライチェーンの自動化（Logistics & Routing）

#### (1) 自動ルーティングとボトルネック検出

- **最短経路・高インフラ優先探索**: 工業都市から前線デポ・戦闘団への補給線は、道路・鉄道・河川・沿海航路のインフラ容量（Throughput）を評価し、**ダイクストラ法/A*アルゴリズムにより毎ターン自動計算**される。
- **インフラ容量オーバーの自動迂回**: 特定ルートが過密または敵の航空・砲撃脅威に晒されている場合、余力のある別ルートへ自動で輸送能力が配分される。

#### (2) 部品品質・改修パッチの自動伝播

- 熟練度の高い中核都市（超精密加工・高度電子コンビナート）と補給線がつながっている戦闘団には、**「高品質部品ボーナス（故障率低下・命中率向上）」**が自動伝播する。
- 補給線が切断された部隊は、自動的に現地急造品や廃品回収部品への依存度が高まり、故障率や整備負荷が自動的に悪化する。

#### (3) 実戦経験値（$\Delta Exp$）の自動波及

- 前線の戦闘団で特定モジュール（例: ガスタービンエンジン GT-1500）が実戦過酷データを収集すると、トポロジーグラフを辿り、同系統のモジュール（小型版GT-800、海軍仕様GT-1500M等）へ類似度に応じた経験値がバックグラウンドで自動配信される。

$$\Delta Exp_{\text{target}} = \Delta Exp_{\text{source}} \times \text{Similarity}(M_{\text{source}}, M_{\text{target}}) \times \text{DampingFactor}$$

### 3.3 内政・都市発展の自動化（Autonomous Sub-tile Growth）

#### (1) 自律ゾーニング発展（Autonomous District Sprawl）

- 親タイルの特性（工業特化、商業特化、要塞都市など）とインフラ接続状況に応じて、サブタイル内の未開発ヘックスへ**民間・企業資本による施設が自動発生・増殖**する。
  - 例: 金属加工工場が集積すると、隣接サブタイルに「熱処理プラント」「精密金型工房」「工具流通センター」などが自動で建設される。
- プレイヤーはすべてのサブタイル施設を手作業で建てる必要はなく、都市全体の方向性（大枠のゾーニング）と、国家主導の巨大プロジェクト（軍用工廠、大型港湾、宇宙港など）のみを手動建設する。

#### (2) 環境・公害・冷却水需要の自律シミュレーション

- 大規模発電所や重化学コンビナートが増大すると、「冷却水需要」や「電力グリッド負荷」が自動計算され、不足が発生した場合は自動的に効率低下や警告（要インフラ投資）がプレイヤーへ提示される。

---

### 3.4 戦闘・戦術解決の自動化（Auto-Resolve）

#### (1) 手動指揮と自動解決のシームレスな棲み分け

- 全体マップ上で敵部隊と接触した際、プレイヤーは**「手動指揮（単一タイルマップへ突入）」**か**「自動解決（全体マップ上で即座に計算）」**を自由に選択できる。
- 日常的な掃討戦や圧倒的優勢/劣勢な戦闘は自動解決でテンポよく消化し、要衝の防衛戦やボス戦、未知の遺跡調査などの勝負所でのみ手動戦術戦に没入できる。

#### (2) 自動解決エンジンの計算ロジック

自動解決は単なる「戦力値の引き算」ではなく、戦闘団の内部構成および戦術ドクトリンを統計的にシミュレーションする。

- **評価要素**:
  1. **兵科相性・射程階層**: 偵察小隊の視界、ミサイル/榴弾砲の長距離先制打撃、戦車・装甲車の前衛突破力、歩兵の地形防御効果。
  2. **周辺タイル増援**: 隣接する味方戦闘団（1タイルにつき最大1個）の支援射撃・増援効果。
  3. **補給・モジュール稼働率**: サプライチェーン状況、部品共通化率による整備継続力。
  4. **地形・天候修正**: 湿地、森林、市街地、電磁嵐などの環境ペナルティ。

## 4. プレイヤー体験とUI演出（「自動化」を面白さに変える工夫）

自動処理の最大の落とし穴は、「裏で何が起きているか分からず、プレイヤーが関与している実感が薄れること」である。これを防ぐための演出設計を導入する。

### 4.1 インスペクション（覗き見）パネル

戦闘団や戦車小隊をクリックした際、詳細情報パネルに「裏で動く自動産業エコシステム」が誇らしく表示される。

```text
+-------------------------------------------------------------------+
|  第3機甲戦闘団 [近衛重装甲大隊]                                    |
|  - 状態: 良好 (稼働率: 98.4%)                                     |
|                                                                   |
|  【装備構成・産業サプライチェーン情報】                           |
|  - 主車体: 帝国重工 T-72改 シャシー (重工IND-2 類似度: 1.0)       |
|  - 主砲: 120mm 滑腔砲 Mk-IV [共通砲身規格] (火薬IND-4)            |
|  - FCS/AI: オプティマ・テック製 自律射撃管制 Ver 4.1 (電子IND-7)  |
|  - 補給元: 首都第1工業コンビナート (道路・鉄道 複線直結)           |
|  - 部品品質評価: 「高精度熟練工加工 (故障率 -15%, 命中精度 +8%)」 |
|  - 代替補充履歴: なし (正規部品による100%充足)                    |
+-------------------------------------------------------------------+
```

### 4.2 NPC国家のジレンマ観察（世界観フレーバー＆外交交渉）

プレイヤー国家の補給幕僚AIが高度に平準化・自動処理を行っているのに対し、NPC国家は現実的な産業・兵站ジレンマに直面し、それが外交イベントとして可視化される。

- **多口径工場の立ち上げトラブルに悩む大国**:
  - 急速に軍備拡張したNPC国が、工場の段取り替えトラブルで弾薬不足に陥り、プレイヤーに「弾薬・火工原料の緊急融通」を打診してくる。
- **前線での口径乱立・兵站破綻**:
  - 各国からバラバラに兵器を買い集めたNPC軍が、前線で「105mmと155mmの砲弾補給が混乱して砲兵が射撃不能」に陥る様子を偵察で確認できる。

## 5. 自動化システムの制御・オーバーライド（プレイヤーの介入権）

「基本は自動化」としつつも、こだわりたいプレイヤーや危機的状況のための**限定的オーバーライド機能**を提供する。

1. **優先補給指定（Priority Supply Flag）**:
   - 特定の最精鋭戦闘団や危機に瀕した要塞に対し「最優先補給」フラグを付与。幕僚AIは他部隊の配分を削ってでも最高品質部品と正規弾薬を集中回送する。
2. **モジュール固定（Lockdown）**:
   - 代替部品への応急換装を禁止し、「正規の最新型モジュールが届くまで待機」を命じる設定。
3. **ゾーニング指定（District Designation）**:
   - サブタイルの特定区画を「軍事専用区」「重工業保護区」として手動指定し、民間の雑多な施設による侵食を防止する。

## 6. 実装・開発フェーズにおける段階的検証（ロードマップ）

| フェーズ | 開発内容 | 自動処理の検証項目 |
| :--- | :--- | :--- |
| **Phase 1: コア調達＆充足** | 類似性マトリクスと補給判定ロジック | 欠品時に類似度に応じた代替モジュール自動選定が正しく機能するか |
| **Phase 2: サプライチェーン伝播** | 最短経路ルーティングと品質・経験値配信 | インフラ網に沿って品質補正・Expが自動波及するか |
| **Phase 3: サブタイル自律成長** | 都市周辺サブタイルの自律ゾーニング増殖 | 親タイルの発展に応じて適切な関連施設が自動生成されるか |
| **Phase 4: UIインスペクション** | 詳細情報パネルとNPC外交イベント | プレイヤーが自動化の恩恵と裏側のリアリティを実感できるか |
