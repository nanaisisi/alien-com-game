# 資源カテゴリ・物資格納・食料と弾薬規格の進化流通仕様書 (Resource Economy, Munition Standards & Food Systems)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「資源品目、弾薬規格のグローバル共通化から独自分化・再統合の力学、および陸・海・工業培養による食料供給・文化システム」**を体系的に定義する仕様書です。

---

## 1. 基本思想と全体像

本作における物資・経済システムは、単なる「数字のストック」ではなく、**「歴史的経緯（冷戦直後の地球グローバリズム規格）から出発し、惑星環境への適応と国家間関係に応じて分化・再統一していく動的な規格体系」**として設計されます。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       資源・物流・規格の多層循環構造                        │
└─────────────────────────────────────────────────────────────────────────────┘
  [一次資源 (Raw)]     : エネルギー、構造鉱物、機能鉱物、バイオ原質
         │
  [中間部品 (Parts)]   : 共通機械部品、電子・論理コア、特殊合金装甲
         │
  [軍事・弾薬 (Ammo)]  : 【初期】旧地球統一規格（NATO/ワルシャワ条約統合的レガシー）
                       │ ├─ 同時期並行開発による独自分化（口径・信管・レールガン規格）
                       │ ├─ 後追い開発・同盟関係によるライセンス/後方共通化
                       │ └─ 時間経過・技術標準化会議による再統合
         │
  [食料システム (Food)]: 陸（土壌農業・畜産）／海（閉鎖養殖・海洋資源）／工業（細胞培養）
                       │ ├─ 文化ごとの嗜好・適応度（南国・北国・極限環境での自活）
                       │ └─ 異星現地生態の摂取（あるものを食う：毒性適応とリスク）
```

## 2. 弾薬規格の進化ダイナミクス（共通化 → 分化 → 再統合）

### 2.1 初期段階：冷戦直後型「地球共通規格（Legacy Standard）」

* **背景**:
  * 第一次入植船団が地球を出航した時期は、大戦終結後の国際協調・グローバリズム全盛期。
  * 弾薬や基礎火薬規格（機関砲弾、誘導ミサイルバス、戦車砲規格など）は、現実のNATO標準弾薬（5.56mm/7.62mm/120mm砲弾等）のように**世界的に極めて高度に規格統一されていた**。
* **初期ゲームでの恩恵**:
  * 降着初期〜開拓初期において、**他国の物資備蓄や投棄弾薬をほぼ無加工で流用可能**。
  * 鹵獲兵器もそのまま即座に自軍の弾薬サプライチェーンで撃てる。

### 2.2 発展と分化（同一設計からの離脱）

* **同時期開発による並行分化**:
  * 各国が独自の次世代兵器（高初速電磁投射砲、指向性エネルギー、特殊徹甲弾など）を同時並行で研究し始めると、**技術的必然として口径・電力プラグ・薬莢規格が分かれていく**。
  * 国家関係が冷戦・対立へシフトするにつれ、「敵国に自国の弾薬を鹵獲利用させない」「自国の特殊装甲を貫徹するための専用弾」として意図的な非互換（分化）が進む。
* **後追い開発による共通化の余地**:
  * 先行国が確立した新規格に対し、後発国がリバースエンジニアリングやライセンス供与で追従する場合、**あえて新規格を作らず先行国の規格を採用することで共通化率を維持**できる。

### 2.3 再統合のメカニクス

* **同盟・国際協調による標準化**:
  * 同盟関係の締結、あるいは特定超大国の兵器市場独占によって、再び規格が統合へ向かう（協定締結によるライン転換）。
* **時間経過とデファクトスタンダード（事実上の標準）**:
  * 最も戦場で大量消費され、稼働率が高かった兵器規格が民間・民兵・同盟国へ普及し、時間とともに自然な再共通化が起きる。

| フェーズ | 規格状態 | 補給・整備への影響 | 鹵獲弾薬の利用 |
| :--- | :--- | :--- | :--- |
| **初期（開拓期）** | **地球統一グローバル規格** | 補給負担は最低。どの国の弾薬庫からも補給可能。 | そのまま100%利用可能 |
| **中期（並行開発期）** | **独自分化（ガラパゴス化）** | 自国専用弾薬が必要。補給ラインが細分化し兵站摩擦増大。 | 互換性なし（改修・火薬抽出が必要） |
| **後期（同盟/市場覇権）** | **ブロック標準化 / 再統合** | 陣営内共通規格の確立。生産効率・融通性が飛躍。 | 同盟・規格共有国のみ即時利用可 |

## 3. 食料システム：3大生産方式と文化・異星適応

食文化はもともと分化しているが、旧地球のグローバリズムによって基本枠組み（タンパク質・炭水化物・脂質の必須要件）はある程度統合されており、ゲーム上は煩雑になりすぎないよう簡略化して扱います。

### 3.1 食料生産の3大アプローチ

```text
┌──────────────────────────────────────────────────────────────┐
│                    食料生産の3大アプローチ                   │
├──────────────────────────────────────────────────────────────┤
│ ①【陸】土壌農業・閉鎖温室・畜産                              │
│   ・気候・土壌依存。平野部・温帯タイルで高効率。             │
│   ・地球種栽培（低異星度）から現地変異種交配（高異星度）へ。 │
├──────────────────────────────────────────────────────────────┤
│ ②【海】閉鎖養殖・海洋プランクトン採取                        │
│   ・沿岸・海洋タイル専用。高密度タンパク質の安定供給。       │
│   ・地球水産種（低異星度）から異星海棲生物の養殖（高異星度）。 │
├──────────────────────────────────────────────────────────────┤
│ ③【工業】細胞単位の工業的バイオリアクター（培養肉・藻類合成）│
│   ・気候・環境に完全非依存（地下、砂漠、ツンドラでも稼働）。 │
│   ・純粋な化学・遺伝子配合により「異星度」を任意に調合可能。 │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 食料における「異星度（Xeno-Index）」ダイナミクス

食料は単なる数量ではなく、**「どれだけ異星（現地生態系）の生体物質・アミノ酸・未知分子を取り込んでいるか」を示す「異星度（0%〜100%）」**という質的パラメータを持ちます。

```text
  [地球純血食 (異星度 0%)] ─────── [混合適応食 (30〜60%)] ─────── [完全現地食 (90〜100%)]
      (完全管理温室/地球種)        (工業培養/交配農水産)          (原生生物捕食/ミズマ生体)
   ・生産コスト：極大             ・生産コスト：中               ・生産コスト：極小 (現地調達)
   ・純正派閥  ：士気向上         ・全派閥    ：安定自活         ・純正派閥  ：拒絶・中毒・暴動
   ・現地適応派：拒絶（虚弱化）   ・身体変化  ：緩やかな適応     ・現地適応派：劇的身体強化・覚醒
```

* **異星度 0%（地球純正食・ピュアテラ）**:
  * 持ち込んだ地球由来の種子・家畜・凍結胚を、密閉ドームや無菌工業リアクターで厳格に維持・生産。
  * **メリット**: 地球純正主義の住民・兵士の士気を最大化。生理的不拒絶を完全保証。
  * **デメリット**: 現地環境への耐性が一切なく、インフラ維持・除染・エネルギーコストが極めて高い。
* **異星度 30%〜70%（混合・工業適応食）**:
  * 工業的バイオリアクターで地球由来のタンパク質基本骨格に現地の高栄養分子を組み込む、あるいは土壌農業で現地気候に適応した変異交配種を栽培。
  * **メリット**: 南国・北国・ツンドラ・乾燥帯を問わず、少ないインフラ投資で安定して高効率自活が可能。旧地球の食文化の枠組み（主食・主菜の感覚）を工業的に再現できる。
  * **影響**: 人体の生理代謝が徐々に現地環境へ馴染み、軽微な環境毒性への耐性を獲得していく。
* **異星度 80%〜100%（完全現地原生食・「あるものを食う」サバイバルから共生へ）**:
  * 原生生物の狩猟肉、未同定の自生植物、ミズマ（瘴気）で増殖する現地菌類の直接採取。
  * **メリット**: 補給線が途絶した最前線や孤立前哨でも、周囲の自然タイルから即座に「現地調達」して兵站を自給可能。
  * **リスクと派閥分岐**:
    * **未適応・純正派**: 消化器不全、アレルギー性ショック、精神変容イベント、部隊の脱落を誘発。
    * **現地適応（調和）派**: 「聖なる糧」として歓迎。傷病の超回復、夜視力・ミズマ耐性などの身体能力ブースト（種分化の加速）をもたらす。

* **「異星度」とイデオロギーの非直結性（実利・調理加工と文化の分離）**:
  * 摂取する食料の異星度は、**必ずしも国家のイデオロギー（アフィニティ）と1対1で完全一致するわけではない**。
  * **実利的な適応**: たとえ純正主義を掲げる国家であっても、前線の過酷な環境で自活するために「高度に無毒化・精製された異星由来タンパク質（見た目や味は地球風）」を兵站として採用することは日常的。
  * **調理・加工技術による中和**: 「地球型のアプローチ（火を通す、醸造する、地球型調味料で味付けする）」を施すことで、心理的拒絶感なく異星食材を日常食として組み込むことが可能。イデオロギーは「何を信じるか」であり、兵站と胃袋は「現実的にどう生き延びるか」という実利の選択となる。

* **テラフォーミング（環境改造）による地球型食料の効率向上**:
  * 開拓初期は現地環境（高濃度ミズマ、異種土壌菌）に阻まれて地球型食料（低異星度）の生産コストは極めて高いが、**タイルのテラフォーミング（土壌改変・大気浄化・水質中和）が進展するにつれて生産効率は劇的に向上**する。
  * 完全に地球化（テラフォーム）されたタイルでは、密閉ドームや膨大な除染エネルギーを必要とせず、屋外農場や通常の放牧で低コストに地球型食料を大量自給できるようになる。
  * これにより、「現地適応（高異星度を受け入れて低コスト化）」を選ぶか、「テラフォーミング（環境そのものを書き換えて地球型のまま低コスト化）」を目指すかという、環境改変アプローチの選択肢が成立する。

## 4. 資源カテゴリ定義一覧（ゲーム内データ構造）

### 4.1 一次資源（Raw Resources）

採掘施設・採取プラントから直接産出される基礎物質。

| 資源名 | 主な産出地 | 用途・機能 |
| :--- | :--- | :--- |
| **エネルギー (Energy)** | 発電所、地熱孔、核融合炉 | 工場稼働、都市維持、シールド・ビーム兵器の維持 |
| **構造鉱物 (Structural Ore)** | 鉱山、山岳・丘陵タイル | 製鉄・チタン精錬。建材、車両シャシーの基礎 |
| **機能性レアアース (Rare Minerals)** | 深部採掘、特殊鉱脈 | 半導体、超伝導体、センサー、ビーム発振器 |
| **バイオ原質 (Biomass)** | 農業、海洋養殖、原生林採取 | 食料原料、医薬品、生体モジュール、人工子宮培養液 |

### 4.2 二次資源・工業中間財（Manufactured Goods）

一次資源を工業コンビナートで加工した、流通可能な工業モジュール。

| 品目名 | 原料 | 用途・機能 |
| :--- | :--- | :--- |
| **基礎機械部品 (Standard Parts)** | 構造鉱物 + エネルギー | 車両の定期整備、施設維持、共通シャシーの組立 |
| **電子・論理コア (Logic Cores)** | 機能性鉱物 + エネルギー | 自律無人機、高度火器管制、研究所出力、指揮通信 |
| **耐熱複合装甲板 (Composite Armor)** | 構造鉱物 + 機能性鉱物 | 重装甲車両、防衛要塞、耐環境シェルター |
| **規格化レーション (Standard Rations)** | バイオ原質（陸/海/工業） | 人口維持、戦闘団の基本携行兵站食料 |

### 4.3 軍事・兵站消費財（Consumables & Munitions）

戦闘団（師団）が作戦行動および交戦時にリアルタイムで消費する物資。

| 消費品目 | 規格依存度 | 枯渇時のペナルティ |
| :--- | :--- | :--- |
| **軍用弾薬 (Munitions)** | **高**（地球共通 → 国家独自 → ブロック統合） | 戦闘団の攻撃力激減（白兵・体当たり・退却のみ） |
| **推進剤・燃料 (Fuel/Propellant)** | 中（重水素・合成炭化水素） | 戦闘団の移動力喪失、補給パイプライン停止 |
| **野戦交換部品 (Field Spares)** | 兵器モジュール共通化率に依存 | 損傷車両の自然回復停止、故障による脱落 |

## 5. まとめと開発連携

本仕様により、以下のシステム間連携が明確になります：

1. **外交・技術連携**: 技術ツリーでの独自口径開発と、同盟・標準化協定による弾薬互換性の回復。
2. **タイル・マップ連携**: 気候タイルごとの「陸・海・工業」食料自活プラント設営と、兵站遮断時の現地食材摂取リスク。
3. **戦闘団・兵器共通化連携**: 車体だけでなく、使用弾薬の規格共通化による後方兵站摩擦の軽減。
