# 兵器・モジュール共通化と運用経験値の個別事例集 (Case Studies)

本ドキュメントは、[`concept_weapon_module_commonality.md`](concept_weapon_module_commonality.md) で定義された理論・システム設計を、具体的な国家、兵器、モジュール、運用環境シナリオに当てはめた事例集である。

## 1. 調達形態とサプライチェーンの個別事例

### 事例 1-A: 連邦（国C）製車体プラットフォームのライセンス生産と「魔改造」

- **背景**:
  - 大公国（国B）は自国の重工基礎基盤（Layer 1）が限られており、主力車体を1から新規開発する国力がない。
  - 大公国は、実利志向の連邦（国C）から装軌装甲車体「バイソン・プラットフォーム」のライセンス生産権を購入。
- **ゲーム内の運用ダイナミクス**:
  - **国内生産**: 大公国国内のコンビナート（親タイルの工業地区）で組立を行い、生産コストと調達リードタイムを抑える。
  - **自国特化モジュールへの換装（魔改造）**:
    - 大公国は連邦標準の機関砲塔を取り外し、国内新興企業が開発した「高精度長距離対エイリアン滑膛砲」と「自律照準FCS」を搭載。
    - 連邦製車体の信頼性（高水準の車体経験値）を享受しつつ、大公国の防衛教義に合致した駆逐戦車型バリアントを短期間で戦力化。
  - **リスク・摩擦**:
    - 宗主国を自認する帝国（国A）から「他国規格兵器の導入は条約精神に反する」と公式抗議を受け、外交緊張度が上昇。

### 事例 1-B: 共同開発プロジェクト「タイフーン防空システム」

- **背景**:
  - 帝国（国A）と共同体（国E）が、広域に侵入するエイリアン飛行群を迎撃するため共同開発を開始。
  - **分担**:
    - 帝国（国A）: 重装甲装輪キャビンおよび大型ミサイル発射機構（重工・構造体担当）。
    - 共同体（国E）: 多目標同時追尾フェーズドアレイレーダーおよびAI管制モジュール（電子・ソフトウェア担当）。
- **ゲーム内の運用ダイナミクス**:
  - **開発費・量産効果**: 両国の開発研究ポイントを折半し、開発期間が40%短縮。完成後は両国コンビナートでモジュールを分担生産し、相互供給。
  - **破綻リスク（サプライチェーン危機）**:
    - 共同体内部の労働争議や、領土緩衝地帯での小競り合いにより両国の関係が悪化。
    - 共同体からのレーダー供給が滞った帝国軍の前線部隊では、「車体とミサイルはあるが索敵AIが載せられない未完成ユニット」が基地に滞留する事態が発生。

### 事例 1-C: 完成品輸入の代償「禁輸による稼働率崩壊」

- **背景**:
  - 共和国（国D）は急激なエイリアン侵攻に対処するため、連合（国F）から完成品の第5世代大型制空戦闘機「ファルコン-X」を2個飛行隊分、緊急輸入。
- **ゲーム内の運用ダイナミクス**:
  - 即座に最高峰の制空戦闘能力を獲得し、前線のエイリアン航空脅威を排除。
  - その後、中立地帯の資源採掘権を巡り連合（国F）と共和国（国D）の外交関係が冷え込み、連合が「軍事用補修部品の禁輸措置」を発動。
  - ブラックボックス化された部品の自国修理が不可能なため、過酷な実戦で消耗した部品の交換ができず、**わずか3ターンでファルコン-X飛行隊の稼働率が85%から15%へと急落**。前線が突如崩壊の危機に陥る。

## 2. 共通モジュール vs 類似モジュールの個別事例

### 事例 2-A: 全軍共通「オメガ・マルチロール・タービンエンジン」

- **共通モジュール (共通性 100%)**:
  - 連合（国F）が開発した高出力ガスタービンエンジン「オメガ-1000」。
  - **採用兵器**:
    1. 【陸】主力重戦車「タイタン」
    2. 【海】沿岸高速ミサイル艇「シーハリアー」
    3. 【陸】重自走榴弾砲「コロッサス」
- **効果**:
  - **部隊共通化率 85%**: 戦闘団に重戦車と自走砲を混成配備しても、整備小隊が携行する予備エンジン・補機類・オイルフィルターが1系統で済むため、物資輸送枠が半分で済む。
  - **整備時間短縮**: 整備兵が1種類のエンジンの構造を熟知しているため、野戦での換装時間が劇的に短縮される。

### 事例 2-B: 類似モジュール「120mm電熱化学砲」の世代間・派生関係

- **類似モジュール (共通性 60%)**:
  - Mk.1（初期型）: 帝国軍の標準120mm電熱化学砲。
  - Mk.2（改良型）: 長砲身化・急速自動装填装置を付加した改良型。
  - Mk.1-L（大公国ライセンス型）: 現地の入手しやすい希土類素材で代用した省資源型。
- **効果**:
  - Mk.1の運用経験値（砲身寿命データ、給電パルスの最適化）が、Mk.2の開発・初期信頼性に60%還元。Mk.2は配備直後の初期不良（ジャム率）が低く抑えられる。
  - 戦場での鹵獲・緊急修理: 大公国軍の部隊が帝国の補給所を占領した場合、Mk.1-L用の予備部品として帝国のMk.1弾薬・砲身部品を60%の適合率で流用可能（残りは加工・調整が必要）。

### 事例 2-C: 動力管理情報「定格1,500 kW出力級」による陸海共通化

- **管理パラメータ**: 定格出力 1,500 kW / 重工級ブロック規格。
- **採用兵器**:
  - 連邦の第4世代主力戦車「アイアンハイド」
  - 連邦海軍の双胴沿岸高速戦闘艇「シーランナー」
- **運用ダイナミクス**:
  - 戦車と高速艇で同一の1,500 kW出力コアブロックを共有。
  - 陸上運用の激しい加減速で得られた「タービン動翼の熱疲労データ」が、海軍側の予防保全プログラムへ即座に反映され、艦艇の洋上機関トラブル停止率が60%低下。
  - 戦車が1,800 kWへ過給機改修（出力アップ版）された際は、コアブロック共通の「類似モジュール（共通性 60%）」へ移行し、整備基盤の完全断絶を防ぐ。

### 事例 2-D: アンテナアレイ素子のスケーリング自由度と戦闘機多機能統合（FCS/ECM/ESM/通信）

- **共通基礎素子**: 窒化ガリウム（GaN）高周波T/R素子「TR-8チップ」（Layer 1で量産）。
- **大型艦船・基地の機能分担設計（専用分散型）**:
  - 連合（国F）のミサイル駆逐艦「トライデント」:
    - 艦橋4面に**広域対空捜索レーダー（Sバンド特化面・各3,200素子）**を配置。
    - マスト上部に**火器管制・終末誘導専用の射撃指揮装置（イルミネーター）**を独立配置。
    - マスト各所に**専用ECM妨害送信機**と**高感度ESM逆探知アンテナ**を分散配置。
    - **メリット**: 各装置が特化性能を極限まで発揮でき、故障・被弾時の機能局所化（生残性）が高い。
- **戦闘機の極限多目的・多機能統合設計（Multi-Function RF System）**:
  - 連合空軍の制空戦闘機「ファルコン-X」のノーズアレイ「AN/APG-90」:
    - ノーズコーン径の制約から、TR-8素子は**最大950個**のみ。
    - 別個にECM装置やESMアンテナを積む容積・重量の余裕がないため、**単一のアレイ面で「捜索レーダー」「精密照準FCS」「広帯域ECMジャミング」「ESM電波逆探知」「指向性高速ミリ波通信データリンク」を時分割・ビーム合成で全て実行**。
    - 制御ソフトウェアと高密度液冷パッケージの要求水準が極めて高く、モジュール単価は艦船の単一レーダー面より高価。
- **ゲーム内の運用ダイナミクスと経験値の還元**:
  - **素子製造ラインの共用**: 駆逐艦の大量建造によりTR-8素子の単価が下がり、戦闘機レーダーの製造コストも自動的に25%低下。
  - **戦闘機の多機能実戦経験値が艦船に波及**:
    - ファルコン-Xが対エイリアン電子戦で蓄積した「敵生体電波パルスを逆探知（ESM）し、即座に同一周波数でジャミング（ECM）を浴びせる適応ビーム波形アルゴリズム」が、駆逐艦の電子戦室（専用ECM/ESM計算機）に即時アップデートされ、艦隊全体の対エイリアン電子防護率が跳ね上がる。
  - **艦船の射撃指揮経験値が戦闘機に波及**:
    - 駆逐艦の大出力射撃指揮装置が海上で収集した「超低空・高機動目標のクラッター（雑音）除去・追尾フィルタ」が、戦闘機のルックダウン・シュートダウン照準精度を向上させる。

### 事例 2-E: 「ダイヤモンド半導体素子」の実用化と戦闘機電子戦の次元転換

- **背景**:
  - 連合（国F）は国家戦略予算を投じ、次世代パワー半導体「ダイヤモンド素子（DIA-X）」の量産技術を確立。
- **ブレークスルーの内容**:
  - 従来のGaN（窒化ガリウム）素子に比べ、熱伝導率が10倍以上、耐電圧が数十倍に跳ね上がる。
  - **戦闘機の熱限界ブレークスルー**:
    - ファルコン-X改（第6世代仕様）は、小型機首の限られた冷却容積のまま、**従来の3倍の放射電力を連続出力可能**に。
    - 単なる火器管制レーダーの探知距離延伸にとどまらず、**「指向性マイクロ波兵器（HPM）」レベルの高出力パルスを放ち、接近する敵無人機群やエイリアン飛翔体の神経・電子回路を物理的に焼損**させる電子攻撃能力を獲得。
- **産業・共通化インパクト**:
  - 初期は人工ダイヤモンド合成コンビナート（超高コストなLayer 1施設）が必要なため、超高コストかつ生産数が限定される。
  - しかし、DIA-X規格素子を「戦闘機ノーズアレイ」「大型艦の指向性エネルギー防護」「高放射線宙域の探査プローブ」に共通採用（モジュール共通化）することで、数年かけて量産効果（規模の経済）を達成し、全軍の電子戦能力を一段上のステージへ押し上げる。

## 3. 運用環境・実戦経験値の個別事例

### 事例 3-A: 砂塵・高塩分環境（陸・海）での「過酷度蓄積」とフィードバック

- **シナリオ**:
  - 共和国（国D）の第3機甲戦闘団が、エイリアン生息地である高熱・高塩分の砂漠地帯（過酷度: 極大）に展開。
- **経過と獲得知見**:
  - **初期トラブル**: 細かい塩化砂塵が装甲車の吸気フィルターを突破し、エンジン焼き付きが多発（初期の稼働率ペナルティ -25%）。
  - **経験値の爆発的蓄積**: 5ターンにわたる過酷運用により、該当装甲車の「砂塵環境適応経験値」が最大値に到達。
  - **改修パッケージのアンロック**: 「サイクロン式自掃気フィルター＋耐塩ナノコーティング」の改修案が自動生成される。
  - **横断ボーナス**:
    - 同一フィルター系統を採用している沿岸警備部隊のホバークラフト（海ドメイン）にも即座に適応ボーナスが適用され、海軍側の塩害故障率が40%低下。

### 事例 3-B: 実戦（対エイリアン戦）における「酸性体液耐性」の獲得

- **シナリオ**:
  - 平時演習では決して得られない、エイリアン（中型酸分泌種）との激しい実戦。
- **蓄積される実戦経験値**:
  - 酸性液体の直撃を受けた複合装甲の融解速度、センサーレンズの白濁化データが軍本部に即時送信される（実戦係数: ×5.0）。
  - **戦闘団のドクトリン進化**:
    - 装甲モジュールに「犠牲剥離セラミック層」を追加するフィールド改修キットがアンロック。
    - 実戦経験を経た小部隊は、酸を吐き出すエイリアンの予備動作を学習し、自動回避・アクティブ防御の成功率が上昇。

### 事例 3-C: 「50年使い続けた旧式車体」の底力

- **シナリオ**:
  - 連邦（国C）の多目的装軌車体「M-40 リパブリック」。初配備から40年が経過し、総配備数は1万両を超える。
- **特性**:
  - **カタログ性能**: 装甲・速度ともに最新鋭車体に劣る。
  - **蓄積された運用経験値**:
    - 成熟度MAX（初期不良率 0%）。
    - どんな僻地の簡易修理工場でもパーツが手に入り、現地修理時間が最新鋭機の1/4。
    - 「寒冷地」「熱帯雨林」「泥濘地」の全環境適応ボーナスをコンプリート済み。
  - **戦略的価値**:
    - 最前線の決戦兵力としては力不足だが、広大な補給線護衛、後方エイリアン巣窟掃討、辺境開拓都市の防衛において、**「極めて安価で絶対に壊れない万能ワークホース」**として比類なきコストパフォーマンスを発揮する。
