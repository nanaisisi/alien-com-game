# 惑星フロンティア世界観・文明発展および地表力学設計書

(Planetary Frontier Worldview, Civilization Divergence, Ecosystem Adaptation & Ground Dynamics)

本ドキュメントは、本作の舞台設定、星間文明としての技術水準制約、異星生態系と人類社会の適応関係、先行入植文明と後発移民文明の非対称性、および「距離と規模の防壁」による長期消耗・占領戦の力学を体系化した設計仕様書である。

## 1. 舞台背景と星間技術水準の制約

本作は銀河帝国や超光速艦隊戦を描くスペースオペラではなく、**「見知らぬ異星の大地と生態系に縛り付けられた人々の泥臭い生存・統治・戦争」**を描く。
宇宙を主役にせず地表へプレイヤーの視線を集中させるため、星間技術には冷徹で合理的な物理的制約を課す。

```text
       【宇宙空間（希薄・閉鎖・不可逆）】
        ・FTLなし / 亜光速・コールドスリープ世代船
        ・推進剤制約（ロケット方程式）：地表への片道降着
        ・軌道デブリ網（ケスラーシンドローム）の恐怖
                         │
                         ▼ （大気圏突入：不可逆の重力井戸）
 ┌──────────────────────────────────────────────────────────────────┐
 │                  異星惑星の地表（主戦場・生活の全て）            │
 │                                                                  │
 │   ・未知の生態系、大気、土壌、風土病、気候変動                   │
 │   ・食糧、エネルギー、工業生産の100%を地表で賄う必然性           │
 │   ・長大な距離（未開の荒野数千km）が天然の防壁として機能         │
 └──────────────────────────────────────────────────────────────────┘
```

### 1.1 宇宙を「背景の壁」とする3大原則

1. **重力井戸とロケット方程式の冷酷さ**:
   - 地表から物資・兵力を軌道へ打ち上げるには法外な燃料と耐熱コストを要する。
   - 軌道爆撃（質量弾投下）は、厚い大気による散乱・減速に加え、着弾時の衝撃波で周囲の農地・インフラ・生態系を破壊し尽くすため、「資源と居住地を奪い合う」戦争において最も割に合わない選択肢となる。
   - すなわち**「地表の富は、地表に軍足を着けて人間が制圧・管理しなければ手に入らない」**。

2. **「片道切符」の移民・降着ドクトリン**:
   - 地球（母星）から到達した宇宙船は、惑星大気圏へ突入・着陸した時点で燃料を使い果たし、再び宇宙へ戻る能力を持たない。
   - 船体は地上で速やかに解体され、最初の都市核（核融合リアクター、生命維持施設、精錬プラント）として大地に根を下ろす。

3. **限定的宇宙戦と「軌道閉鎖（ケスラーシンドローム）」**:
   - 先行勢力と後続勢力の間で低軌道上での衛星破壊や小規模な迎撃戦（キラー衛星、レールガン、ミサイル）が発生した場合、破砕されたデブリが高密度で軌道帯を覆う。
   - 新規の降着カプセルや通信中継は極めて危険となり、**「敵味方双方が、この惑星の大気圏内に完全に閉じ込められる」**。

## 2. 文明の「100年の時間差」と非対称構造

母星（地球）側の技術水準は安定期・均衡状態にあり、先行船団の出発から後発船団の到達までに約100年の歳月が流れている。
この時間差が生み出す文明力学は、通常のSF（「後から来た方が圧倒的にハイテク」）とは逆転した構造を持つ。

```text
                        【約100年前】
            地球の環境閉塞・資源危機に伴う第1次移民船団発進
                               │
                               ▼
            ┌────────────────────────────────────────┐
            │       先行入植文明（自国・先行勢力）    │
            │  ・未知の過酷な星の刺激で技術が爆発的進化│
            │  ・生態系に適応・土着化（第2〜第4世代） │
            │  ・分散型の広大な拠点網・都市連合へ発展 │
            └───────────────────┬────────────────────┘
                                │ 100年後の現在
                                ▼
            ┌────────────────────────────────────────┐
            │        後発移民文明（他国船団群）      │
            │  ・地球の安定した「枯れた旧式技術」     │
            │  ・生態系への耐性ゼロ（地球規格依存）   │
            │  ・だが「まとまった初期人口と工業密度」 │
            └────────────────────────────────────────┘
```

### 2.1 先行文明の特質：「刺激的な星」での急激な発展と土着化

- **強烈な外的刺激による技術革新**:
  - 地球の閉塞した環境とは異なり、未知の有機化合物、特殊な結晶鉱物、極端な気候サイクル、未知の電磁気現象に直面したことで、生き残りを賭けた研究が爆発的に進展。
  - 地球の教科書にはなかった**独自の物理・バイオ・材料工学**を確立している。
- **土着化（クレオール化）した社会**:
  - すでに第2世代〜第4世代が社会の中核を担い、地球の記憶は歴史の教科書の中にしかない。
  - 現地の動植物を品種改良した主食を食べ、大気中の微粒子や風土病に対する基礎免疫・共生腸内細菌を獲得している。
- **分散と規模の拡大**:
  - 100年の間に、最初の着陸地点から河川・山脈・地下空洞沿いに複数の衛星都市、農村、採掘コロニーを展開。数百万〜数千万人規模の生活圏を築いている。

### 2.2 後発文明の特質：「地球規格の頑丈さ」と「凝縮された初期規模」

- **枯れた旧式技術（枯渇した地球規格）**:
  - 地球で100年前にほぼ完成していた成熟技術（内燃・ガスタービン、重装甲、化学火薬、古典的通信網）の延長線上で構築されている。
  - 異星の特殊な現象に対応できず、フィルター詰まりや腐食、電子戦障害に悩まされる。
- **生態系への脆弱性**:
  - 現地の大気や胞子に対するアレルギー、未知の感染症に対して無防備。密閉式シェルターや環境スーツから出られない。
- **侮れない凝縮規模**:
  - 技術では遅れているが、母星の国家が威信をかけて送り込んだ「数万人〜数十万人の軍人・技術者・資材」がひとつの降着橋頭堡に凝縮されている。
  - 防衛体制が極めて堅牢であり、先行文明にとっても力ずくの排除は大きな出血を強いられる。

## 3. 技術発展の自由度：環境適応のマルチツリー

先行文明における技術発展は画一的な一本道ではなく、**「過酷な惑星環境のどの側面を克服・利用したか」**によって発展の方向性を自由に選択できる。

```text
                     ┌──────────────────────────────┐
                     │ 惑星適応ドクトリンの選択分岐 │
                     └──────────────┬───────────────┘
         ┌──────────────────────────┼──────────────────────────┐
         ▼                          ▼                          ▼
   【生体・共生系】           【重機・環境改変系】       【局所情報・閉鎖自律系】
 (Bio-Symbiosis)            (Geo-Engineering)          (Sub-Network Autonomy)
 ・異星植物の発酵・樹脂化   ・極端気候を力尽くで       ・惑星特有の電磁嵐を
   による生分解性複合材       防ぐ防壁・大気改変プラント 逆手に取った有線/光通信
 ・風土病ワクチンの独自精製 ・超重掘削機、多脚装甲車   ・スタンドアロン型自律兵器
 ・現地生態系トラップ/生物兵器 ・地下空洞都市・重防護要塞 ・非対称ゲリラ通信網
```

1. **生体・共生系（Bio-Symbiosis）**:
   - 異星の植物・微生物を取り込み、燃料・樹脂・医薬品を現地生産。
   - 補給コストが極小化し、住民の健康度・食糧自給率が跳ね上がる。山岳や森林でのゲリラ戦・隠密行動に強い。
2. **重機・環境改変系（Geo-Engineering）**:
   - 過酷な大気や嵐を巨大シールドドームやテラフォーミング施設で強引に遮断。
   - 膨大なエネルギーと鉄鋼を消費するが、地球規格に近い大規模重工業ラインを維持し、重装甲車両や要塞砲を大量生産可能。
3. **局所情報・閉鎖自律系（Sub-Network Autonomy）**:
   - 異星特有の電离層の乱れや磁気嵐で長距離電波が遮断される環境を前提に、独立分散型の小型ドローン群や有線・音響通信網を発展。
   - 局所戦における戦術情報優位と自動防衛ラインの構築に長ける。

## 4. 「距離の防壁」と「規模感」が生む抗戦力学

本作において、一方の勢力が技術的に優勢であっても、あるいは首都が電撃的に制圧されても、**「劣勢側がしぶとく抗戦し、容易に滅びない」**構造的理由がここに存在する。

```text
  [先行文明・首都圏]                                            [後発文明・橋頭堡]
  ┌──────────────┐                                              ┌──────────────┐
  │ 占領された都市 │                                              │ 堅固な降着拠点 │
  └──────┬───────┘                                              └──────▲───────┘
         │                                                             │
         │ (逃亡・地下化)                                                │ (兵站延伸・補給破綻)
         ▼                                                             │
  ┌─────────────────────────────────────────────────────────────┐      │
  │                   広大な未開領域・距離の防壁                │──────┘
  │        (数千kmの荒野 / 猛毒胞子地帯 / 電波不能の磁気砂漠)   │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                                 ▼
                     [先行文明・奥地分散拠点群]
                     ┌───────────────────────┐
                     │ 山岳採掘基地 / 農業開拓村│ (自給自足とゲリラ戦の母胎)
                     └───────────────────────┘
```

### 4.1 数千キロに及ぶ「未開の荒野（距離の防壁）」

- 都市と都市の間には地球のような舗装道路網は存在せず、過酷な原生林、毒性地帯、荒涼たる乾燥大地が広がる。
- 進撃する侵攻軍は、進めば進むほど**「燃料消費の増大」「補給車両の故障」「未知の生物による奇襲」「過酷な天候による通信途絶」**に晒される。
- 劣勢側は**「奥地へ後退するだけ」で敵の進撃限界（キルゾーン）を作り出す**ことができる。

### 4.2 分散した「規模感」の頑強さ

- 先行文明は100年の蓄積により、主要都市以外にも「山岳の採掘プラント」「湿地帯のバイオ農場」「地下シェルター群」など、独立したライフラインを持つ拠点が星の各地に点在している。
- 敵軍が一部の都市を占領しても、それは「点」を制圧したに過ぎず、残された無数の「点」から物資・義勇兵・サボタージュ工作が継続的に供給される。

### 4.3 泥沼の占領統治への帰結

この「距離」と「規模」が存在するからこそ、軍事制圧後の**「占領統治システム（軍政・経済分断）」**がゲームの核心となる。

- **占領軍の孤立**:
  - 都市を落とした占領軍は、広大な敵対的大地に浮かぶ「孤島」となる。
  - 後方補給線は数千キロの荒野でゲリラに狙われ、本国（あるいは降着拠点）からの補給は滞る。
- **現地調達の死活問題**:
  - 補給が届かないため、占領都市の住民や農村から食糧・燃料を徴発しなければ占領軍自身が飢餓に陥る。
  - しかし、強権的な徴発を行えば住民は奥地の残党勢力と結託して全面蜂起し、緩やかな自治を許せば都市内で地下経済と反乱準備が進む（前述の「統治のジレンマ」へ直結）。

## 5. 終局力学：共生を経過点とする最終戦争と「勝者の選択」

本作における終局は、静的なムービーが流れて終了するような古典的エンディングではない。
「共生」すらもゴールではなく**単なる経過点・手段**に過ぎず、プレイヤーは神（超越知性）の立場から人間文明のみならず**「エイリアン（星の生体群）」すら直接操作し、この星をどうするかの最終戦争**を戦い抜くことになる。

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │ 【フェーズ1：人間同士の開拓・泥沼占領戦】                              │
 │ ・人間ユニット（歩兵・装甲車・憲兵）の操作                             │
 │ ・泥臭い治安維持、補給線、食糧自給、都市の奪い合い                     │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │ 共通意識の覚醒・接触（中盤）
                                     ▼
 ┌────────────────────────────────────────────────────────────────────────┐
 │ 【フェーズ2：大方針の決断と同盟（星を守るか、滅ぼすか）】              │
 │ ・「共生」の選択：全生命の救済か、それとも覇権のための生体兵器か       │
 │ ・【同盟ルート（経済・同盟）】：他勢力と「星の処遇」を合意して共闘     │
 │ ・【単独ルート（独立独歩）】：自国単独で星の運命を決定し全方位抗戦     │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │ プレイヤー権能の超越的拡張
                                     ▼
 ┌────────────────────────────────────────────────────────────────────────┐
 │ 【フェーズ3：最終戦争（エイリアン直接操作・総力決戦）】                │
 │ ・プレイヤーの謎の力で、文明軍だけでなくエイリアン群も直接操作         │
 │ ・「星の集合意識を守る陣営」 vs 「反逆・滅ぼす陣営」の惑星規模決戦     │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │ 勝敗の冷酷な帰結
                                     ▼
 ┌────────────────────────────────────────────────────────────────────────┐
 │ 【終局：勝者の選択のみが世界の結果となる】                             │
 │ ・死んだらそれまで（完全滅亡ならどうしようもない）                     │
 │ ・負ければ勝者に「降る（従属・秩序に服す）」か、地下で「どうにかする」 │
 │ ・決着がつかなければ、終わるまで終わらない（泥沼の継続）               │
 └────────────────────────────────────────────────────────────────────────┘
```

### 5.1 上空の宇宙生物：宇宙進出を制約する所与のフタ

- 大気上層〜低軌道に君臨する超巨大宇宙生物は、特別なボスではなく**「宇宙進出を現在地球並みに抑え込む物理的フタ（エベレストのような所与の自然障害）」**として機能する。
- 人類は軌道兵器や大規模宇宙船を運用できず、関心と軍事力のすべてを地表の大地と生態系の上に注ぎ込むことになる。

### 5.2 「共生」の位置づけ：ゴールではなく、最終戦争への突入切符

- 序盤にうっすら感じていた動植物のまとまりが、中盤で「惑星全体の共通意識（ハイブマインド）」であると判明する。
- しかし、共通意識と同調・共生することは平和的ハッピーエンドではない：
  - **全生命の救済**: 星の意識と精神的に調和し、人類全体を新たな生体秩序へ導く思想。
  - **覇権のための手段**: 共通意識の生体シグナルを掌握し、エイリアン群を強力な生体兵器として他国殲滅に投入する手段。
- 共生を選んだ側も、拒絶した側も、最終的に**「この星（集合意識）をどう処遇するか」という根本の対立**に直面する。

### 5.3 プレイヤーの超越権能：エイリアン直接操作

- 終盤において、プレイヤーという「謎の力を持つ超越的存在」の操作権能が拡張される。
- 通常の軍隊ユニット（歩兵・装甲車・ドローン）の指揮にとどまらず、**「星の集合意識の末梢であるエイリアン（原生生物群）」すらも直接選択・移動・攻撃指示を出せるようになる**。
- 生体の大群を率いて敵の要塞都市を呑み込むか、あるいは機械化部隊とエイリアンの混成軍で戦線を突破するかという、異次元の総力戦が展開される。

### 5.4 同盟・単独の選択と、負けたときの冷徹な力学

1. **同盟（経済・同盟ルート）**:
   - 他勢力と手を組む場合、最初に**「この星（集合意識）を守るか、滅ぼすか」**という大方針の合意を形成する。
   - 共通の経済圏・兵站網を敷いて共同戦線を張り、反抗する他陣営と戦う。
2. **単独（覇権ルート）**:
   - 妥協を排し、自国の信じる方針（星の完全保全、あるいは完全排除・地球化）を掲げて全方位を相手に単独で戦う。
3. **冷酷な帰結（死・降伏・泥沼）**:
   - **死んだらそれまで**: 指導者・全拠点が物理的に殲滅されれば、その勢力は歴史から消滅し、どうしようもない。
   - **負ければ降る**: 劣勢を悟って降伏すれば、勝者の掲げた大方針（星の処遇）の下に従属勢力として組み込まれる。あるいは、被占領民として地下に潜り「どうにかする（ゲリラ・残党として機会を窺う）」。
   - **勝者の選択のみが結果となる**: 途中で誰がどんな崇高な理念を語ろうと、**「最後に勝った者の選択だけが、この星の確定した未来」**となる。
   - **終わるまで終わらない**: 決着がつかず、互いに降伏も絶滅もしない限り、泥沼の戦いは終わるまでどこまでも続く。

## 6. データモデル・ゲームメカニクス連動案

本世界観をシステム側で表現するための主要パラメータとデータ構造の指針：

```rust
/// 地域の惑星環境・生態系プロファイル
pub struct EcosystemProfile {
    /// 未知の病原体・胞子毒性（非適応部隊の損耗率に影響）
    pub toxicity_level: f32,
    /// 地形走破抵抗（補給線維持コスト、車両故障率）
    pub logistical_friction: f32,
    /// 土着バイオマス利用度（生体技術系による現地食糧・燃料生産効率）
    pub native_biomass_utility: f32,
    /// 電磁嵐・通信障害指数（自律ドローンの有効性、長距離索敵の妨害）
    pub atmospheric_interference: f32,
    /// 惑星共通意識の同調度・活性度（中盤以降の生態系反応・イベントに関与）
    pub hive_resonance: f32,
}
```

## 7. まとめ

1. **宇宙は見ない（天井としての宇宙生物）**: 宇宙生物の存在が宇宙進出を現代地球レベルに制約する自然のフタとなり、人々の全関心を地表の泥土の上に縛り付ける。
2. **技術の逆転と自由度**: 地球の停滞した旧式技術を抱える後発に対し、過酷な惑星の刺激で独自適応・飛躍を遂げた先行文明が優位に立つ。発展方向はプレイヤーの自由。
3. **距離と規模の安全弁**: 未開の長大な荒野と、100年で分散した複数拠点の規模感が、劣勢側にもしぶとい抗戦能力を与え、戦争を長期の占領・統治摩擦へと昇華させる。
4. **共通意識と王道マルチエンド**: 生態系のまとまり（序盤）から共通意識の把握（中盤）、能動的選択（終盤）を経て、融合エンドをはじめとする定番のマルチエンドへ着地する安心感のあるフレームワーク。メインの体験はあくまで「地表の統治・経済・軍政」に集中させる。
