# 情報提示とビューアー設計仕様：固定情報（Wiki）と動的状況（ゲーム内UI）の明確な分離

本ドキュメントは、プレイヤーへの情報提示において、**「固定的な普遍情報（Wiki/百科事典形式）」**と**「ゲーム内の動的・状況依存情報（ゲーム内HUD/インスペクター/マップ）」**の役割分担・境界線を明確にし、それぞれの最適なビューアー設計を定義する仕様書である。

---

## 1. 核心原則：ビューアーの明確な二元化

ゲーム内の膨大な情報を混同させず、プレイヤーが混乱なく直感的に把握できるよう、情報レイヤーとビューアーを厳格に分離する。

```text
+---------------------------------------------------------------------------------------+
|  【固定情報：静的百科・Wikiビューアー】        │  【動的情報：ゲーム内状況インスペクター】    |
|  - 普遍的な設定・スペック・基本ルール          │  - 「今、ここ」の状況・立地・地政学          |
|  - ドキュメント/Civilopedia形式                │  - 現場UI（部隊・都市・外交・補給マップ）    |
+---------------------------------------------------------------------------------------+
|  - モジュールの設計思想・基本口径規格          │  - この工場が今生産しているモジュール        |
|  - 8大産業の定義・基本類似性マトリクス        │  - 自国の鉄道網・港湾の現在の積載限界        |
|  - 各国の歴史的背景・建前条約の理念            │  - 現在締結している軍事同盟・禁輸措置        |
|  - エイリアン種別の基本生態・既知弱点          │  - 前線部隊の稼働率・現地応急改修状況        |
+---------------------------------------------------------------------------------------+
```

---

## 2. 2大ビューアーの詳細設計

### 2.1 固定情報ビューアー：Wiki形式ドキュメント（Codex / Civilopedia）

普遍的なリファレンス（辞書・マニュアル・世界観図鑑）として機能する。

- **役割**:
  - ゲームのルール、各要素の基礎知識、設定、静的スペックの確認。
  - プレイ中に「そもそも120mm滑腔砲ってどういう位置づけ？」「IND-4火薬産業って何に波及する？」という普遍的な疑問を解決する。
- **表示形態**:
  - **Wiki / ドキュメントビューアー（モーダル / フルスクリーン）**:
    - 目次ツリー、検索窓、Wikipedia風のハイパーリンク、スペック表、系譜図。
    - ゲーム内いつでも呼び出し可能（`F1`キー等）。
- **扱う情報**:
  1. **兵器モジュールカタログ**: 基準スペック（重量、口径、威力、必要スロット）、基本系譜、共通化グループ。
  2. **産業マトリクス定義**: 8大産業の基本接続度、素材相性。
  3. **戦闘団編成定義**: 各戦闘団の標準定数・役割（軽歩兵、機甲、航空化機動など）。
  4. **世界観・国家設定**: 本星条約の基本設定、各国家の建前と理念。
  5. **ゲームルール解説**: オートリゾルブ計算式、補給線接続ルール、地形効果。

---

### 2.2 動的情報ビューアー：ゲーム内インスペクター・マップHUD

「今プレイしているセッションの、このタイル・この部隊・この外交関係」という生きた動的状態を表示する。

- **役割**:
  - 地理的立地、サプライチェーンの開通状況、外交・禁輸による制限など、ゲーム内状況に基づく意思決定・状況把握。
  - 「なぜこの戦車はチタン装甲なのか？」「なぜこの砲弾が不足しているのか？」の答えを示す。
- **表示形態**:
  - **マップ連動型インスペクションパネル（HUD / サイドシート）**:
    - タイル選択パネル、部隊詳細パネル、外交関係マップ、兵站オーバーレイ。
- **扱う情報**:
  1. **地理・立地要因**:
     - 選択したタイルの「工場規模」「港湾・河川接続」「鉄道トンネル限界（通過可能重量・サイズ）」。
  2. **サプライチェーン動態**:
     - 補給ルートの現在Throughput（インフラ容量）、ボトルネック箇所、輸送中の物資。
  3. **外交・国際情勢の反映**:
     - 現在の同盟国からのライセンス供与状況、敵国による禁輸品目リストと影響範囲。
  4. **現場部隊の実態**:
     - 正規部品の充足率、代替部品による応急充足の有無、現場での現地改修（Field Mod）バリアント。

## 3. 両ビューアーの連携（相互ジャンプ・コンテキスト連携）

2つのビューアーを分離しつつも、プレイヤーが迷子にならないよう**「動的情報から固定情報への即時ジャンプ」**をシームレスに繋ぐ。

```text
[ゲーム内インスペクター (動的)]
 └─ 部隊選択: 「第3機甲戦闘団」
      ├─ 稼働率: 85% (動的)
      ├─ 現在地: 内陸山岳セクター4 (動的)
      └─ 搭載砲: [120mm 滑腔砲 Mk-IV]  ◀── クリック or F1
                                                    │
                                                    ▼
                             [Wikiビューアー (固定)]
                              └─ 記事: 「120mm 滑腔砲」
                                   ├─ 概要・基本スペック
                                   ├─ 類似モジュール系譜
                                   └─ 必要な産業ジャンル (IND-4)
```

1. **動的UI内の名詞クリック / F1ヘルプ**:
   - 部隊パネルや都市パネル内のモジュール名、産業名、エイリアン名をクリックすると、Wikiビューアーが該当記事を開いてオーバーレイ表示される。
2. **Wiki側からの「逆引き（ゲーム内フォーカス）」**:
   - Wikiで「120mm滑腔砲」を見ている時、「現在自国でこれを装備している戦闘団一覧」「これを生産可能な自国工場タイル一覧」へのジャンプリンク（ゲーム内ハイライト）を提供。

---

## 4. 設計上のメリット

1. **開発・運用のシンプル化**:
   - Wikiは固定データ（設定・基礎スペック）に専念できるため、複雑なリアルタイム計算をWiki描画エンジンに持ち込まずに済む。
2. **プレイヤー認知の整理**:
   - 「普遍的な仕様を知りたい時はWikiを見る」
   - 「今起きている戦況・兵站・外交のボトルネックを知りたい時はゲーム画面・インスペクターを見る」
   という明確な使い分けができ、UIが極めて見通し良くなる。
