# 国家降伏処理と国家残滓のサプライチェーン力学仕様書

(Concept Capitulation Dynamics, Remnants & Supply Chain Severance)

本ドキュメントは、国家崩壊・全面降伏（Capitulation）時における**「国家残滓（領土・軍事力・技術・人的資源・工廠網）の多角的帰属と流出」**および、その根源的推進力となる**「サプライチェーンの寸断（Supply Chain Severance）」**をゲーム内データ構造・アルゴリズム・挙動モデルとして体系化した設計仕様書である。

---

## 1. コア思想：国家崩壊の本質は「兵站・製造網の断絶」

従来の4Xゲームにありがちな「滅亡と同時に全土が自国領になり、敵の兵器や工場がそのまま自軍の戦力になる」という非現実的な抽象化を廃する。

近代・星間軍事力は、精緻を極めた**「専用弾薬・消耗品」「工作機械・治具・素材規格」「ソフトウェア・暗号鍵更新」**の巨大サプライチェーン網の上に成り立っている。
国家降伏・中央政府崩壊とは、この**サプライチェーンの即時寸断**を意味し、取り残されたあらゆる軍事アセットは「兵站的飢餓（Logistical Starvation）」に直面する。

```text
                     ┌──────────────────────────────┐
                     │   国家崩壊・中央統制の喪失   │
                     └──────────────┬───────────────┘
                                    │ 中央補給・パッチ・部品供給の即時停止
       ┌────────────────────────────┴────────────────────────────┐
       ▼                                                         ▼
 【戦勝国・第三国による接収摩擦】                               【取り残された軍事力の変質】
  ・異規格工廠の稼働率激減                                       ・共食い整備（Cannibalization）
  ・自軍兵站網の汚染（二重兵站）                                 ・規格ダウングレード（Jury-Rigging）
  ・莫大な規格換装（Refit）コスト                                ・補給確保を動機とする多様な残党化
```

---

## 2. 国家残滓の4大帰属先と変質メカニクス

国家が崩壊した瞬間、その領土・軍事力・技術は以下の4つのルートへと動的に分岐する。

```text
       ┌──────────────┬─────────────┴───────────────┬─────────────────┐
       ▼              ▼                             ▼                 ▼
 ┌───────────┐  ┌───────────┐                 ┌───────────┐     ┌───────────┐
 │ ① 戦勝国  │  │ ② 他戦勝国│                 │ ③ 第三国  │     │ ④ 残党化  │
 │  (自国)   │  │ (同盟/競合)│                 │ (中立/メガ │     │  (多種多様)│
 │           │  │           │                 │  コーポ)   │     │           │
 └─────┬─────┘  └─────┬─────┘                 └─────┬─────┘     └─────┬─────┘
       │              │                             │                 │
   直接併合       勢力圏分割                   亡命政権受入       軍閥・私設防衛
   傀儡国家樹立   ヤルタ的密約                 技術者・頭脳流出   テロ・非対称ゲリラ
   設備略奪接収   冷戦の火種                   規格ロンダリング   自律暴走防衛システム
```

### 2.1 ① 戦勝国自国への帰属（消化不良と選択肢）

プレイヤー（または特定戦勝国）が敗戦国のアセットをどう扱うかの選択。

1. **直接併合（Direct Annexation）**:
   - **実態**: 領土・鉱山・工廠を直接領有。
   - **摩擦**:
     - **互換性の4重障壁（Layer 1〜4）**が直撃。旧敵国の工廠は自軍規格の兵器を作れず、稼働率が一時的に15〜30%に急落。
     - 自軍兵站網に旧敵国の補給物資（125mm弾、異種高圧セル等）が混入し、兵站スループットが低下する「兵站汚染ペナルティ」。
     - 治安維持部隊の常駐義務（未配備時はサボタージュ発生）。
2. **傀儡政権・保護国化（Puppet State）**:
   - **実態**: 旧体制の官僚機構と局所工廠を温存し、親自国政権を樹立。
   - **利点**: 旧規格のまま自律稼働させられるため、**サプライチェーンを局所閉鎖ループとして維持可能**。自国の兵站網を汚染しない。
   - **制約**: 上納される資源・税収は一部（30〜60%）にとどまり、軍事統制も間接的。
3. **設備略奪・技術接収（Asset Stripping / Operation Paperclip）**:
   - **実態**: 領土統治を放棄し、中核工作機械、極秘研究データ、重要科学者だけを自国本土へ強制連行。
   - **利点**: 治安コストを払わずに特定技術ツリーのブーストを獲得。
   - **代償**: 廃墟となった地域は即座に無政府状態となり、凶悪な残党や軍閥の温床になる。

---

### 2.2 ② 他戦勝国との山分け・競合（多国間講和と分割統治）

共同作戦や別戦線から同時に攻め込んだ強国同士による分割。

1. **戦争貢献度（War Score）と勢力圏境界線**:
   - ドイツ分割やヤルタ会談のように、進撃停止線や協定に基づき領土が分断される。
   - 境界線を挟んだ隣接タイルは、双方の哨戒部隊が睨み合う「冷戦摩擦ホットスポット」となる。
2. **「共通の敵」消滅による関係急冷**:
   - 降伏成立の瞬間、同盟補正（Alliance Modifier）が解除され、獲得領土や接収技術の配分を巡る疑心暗鬼（Rivalry）が急上昇する。
3. **キーアセットの先占競争（Scramble for Capital Assets）**:
   - 首都の「先端AI研究所」や「試作宇宙戦艦ドック」をどちらの部隊が先に確保したかによる技術奪回工作。

---

### 2.3 ③ 第三国・中立国・メガコーポへの波及（流出とロンダリング）

交戦していなかった外部アクターが、崩壊したサプライチェーンの間隙を縫って利益を得る。

1. **亡命政権の庇護（Government-in-Exile）**:
   - 脱出した旧敵国の首脳・残存艦隊が、反戦勝国的な第三国へ逃亡。
   - 第三国は「正統政府の保護」を大義名分に掲げ、戦勝国に対する外交カード・プロキシ戦争の基点とする。
2. **頭脳流出（Brain Drain）**:
   - 戦犯追及や粛清を恐れた技術者集団が、巨額の報酬を提示した民間メガコーポや中立国へ亡命。
   - 第三国の特定軍事技術が一夜にして跳ね上がる。
3. **アフターマーケット・規格ロンダリング（Black Market Proliferation）**:
   - 寸断されたサプライチェーンを補うため、第三国の軍需企業が「非公認のコピー弾薬・汎用互換部品」を密造・販売。
   - 兵站を失った残党や非正規軍へ武器が拡散し、星系全体の治安レベルが不可逆的に悪化する。

### 2.4 ④ 残党化（サプライチェーン寸断への対症療法による分類）

前線の部隊や防衛システムが、中央政府の降伏命令を拒絶または受領できず独立アクター化する現象。
残党がどのような組織に変質するかは、**「絶たれた補給をどう誤魔化して生き延びようとしているか」**によって完全に決定づけられる。

## 3. 共食い整備と規格ダウングレードのシミュレーション仕様

### 3.1 部隊の兵站自立度と枯渇タイムリミット

補給網を失った部隊は、保有する内蔵ストック（`native_reserves`）を消費して活動する。
これが枯渇した部隊は、以下のステップで**「不可逆な変質・自壊」**を遂げる。

```text
 [補給途絶] ──> [専用弾薬・部品枯渇] ──> [共食い整備(稼働数減少)] ──> [粗悪現地改修] or [自沈・放棄]
```

1. **共食い整備（Cannibalization）**:
   - 3個大隊のうち1個大隊を「部品取り用」に解体し、残り2個大隊の稼働率を維持する。
   - **結果**: 戦闘を行っていなくても、時間経過とともに戦力総数が段階的に減少（100% → 66% → 33%）。
2. **規格ダウングレード（Jury-Rigged Refit）**:
   - 専用の高精度レーザー発振器や電子信管が手に入らなくなったため、手近な民生用ボイラー溶接材や旧式無誘導ロケットを無理やりボルト留めする。
   - **結果**: ユニットの最大射程・命中精度が大幅低下、故障率（クリティカル自己破損率）が跳ね上がる。

## 4. データ構造と内部処理 (Rust)

```rust
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

/// 勢力・地域の識別子
pub type FactionId = String;
pub type RegionId = u32;
pub type TileCoord = (i32, i32);
pub type UnitId = u64;

/// 国家降伏・崩壊時の総合処理結果
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CapitulationSettlement {
    pub defeated_faction_id: FactionId,

    /// ① 戦勝国（自国）の選択による結果
    pub direct_annexations: Vec<RegionId>,
    pub established_puppets: Vec<PuppetStateConfig>,
    pub stripped_assets: Vec<StrippedAsset>,

    /// ② 他戦勝国との分割結果
    pub partitioned_spheres: HashMap<FactionId, Vec<RegionId>>,

    /// ③ 第三国・闇市場への流出
    pub external_leakages: ExternalLeakageSummary,

    /// ④ 各地に発生した残党勢力
    pub active_remnants: Vec<RemnantEntity>,
}

/// 傀儡政権設定
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PuppetStateConfig {
    pub puppet_faction_id: FactionId,
    pub assigned_regions: Vec<RegionId>,
    /// 自国への資源・軍事上納比率 (0.0 ～ 1.0)
    pub tribute_ratio: f32,
    /// 旧規格兵站網の独立維持フラグ (true: 自軍の兵站を汚染しない)
    pub isolate_logistics: bool,
}

/// 略奪接収アセット
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum StrippedAsset {
    MachineTools { factory_id: u32, production_bonus: f32 },
    ClassifiedBlueprints { tech_id: String, progress_gain: f32 },
    KeyScientists { count: u32, research_domain: String },
}

/// 第三国への流出サマリー
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ExternalLeakageSummary {
    pub exiled_fleets: Vec<(FactionId, Vec<UnitId>)>, // 亡命先と部隊
    pub leaked_scientists_to_rivals: Vec<(FactionId, u32)>,
    pub black_market_arms_volume: u32, // 周辺海賊の装備近代化指数
}

/// 孤立・残党部隊の兵站適応ステータス
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LogisticSeveranceState {
    /// 正規サプライチェーン接続フラグ
    pub is_connected_to_grid: bool,
    /// 残存専用弾薬・消耗品ストック（ターン数）
    pub native_reserves: u32,
    /// 部品枯渇時の共食い整備モード有効
    pub cannibalization_active: bool,
    /// 現在の適応形態
    pub adaptation: LogisticAdaptation,
}

/// 兵站寸断への適応形態
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum LogisticAdaptation {
    /// 原型維持（共食いのみで延命、性能100%だが部隊数が毎期減少）
    OriginalWithCannibalization,
    /// 現地粗悪改修（民生部品・鉄板溶接。稼働率は保つが故障率UP・射程低下）
    JuryRigged { failure_rate_penalty: f32, accuracy_penalty: f32 },
    /// パトロンによる正規規格換装完了（互換化完了、自前補給可能）
    RefittedToStandard { refit_cost_paid: u64 },
    /// 重装備自沈・非正規ゲリラ化（民生サプライチェーン潜伏）
    InsurgentSubversion,
    /// 補給ゼロの孤立死守（撃ち尽くしたら機能停止）
    DoomedIsolation,
}

/// 残党勢力エンティティ
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RemnantEntity {
    pub remnant_id: String,
    pub remnant_type: RemnantClassification,
    pub base_location: TileCoord,
    pub controlled_units: Vec<UnitId>,
    pub logistics_state: LogisticSeveranceState,
}

/// 残党の行動類型
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum RemnantClassification {
    /// 軍閥（拠点の工場・鉱山を押さえ、局所自給）
    WarlordHoldout { local_resource_pool: u32 },
    /// 地下抵抗ゲリラ（民生潜伏、治安攻撃）
    UndergroundInsurgency { camouflage_rating: f32 },
    /// 傭兵会社（戦勝国/第三国と雇用契約可能）
    PrivateContractor { hire_price_per_cycle: u64 },
    /// 自律暴走キルゾーン（命令更新拒絶、無差別迎撃）
    AutonomousDeadHandZone { detection_radius: u32 },
    /// 略奪海賊（通商路狙い）
    RaiderCorsair,
}
```

## 5. プレイヤー視点における戦後処理の戦略的意思決定

国家を屈服させたプレイヤーは、単なる領土の拡大にとどまらず、以下の「胃の痛いトレードオフ」を迫られる：

1. **鹵獲兵器の処遇**:
   - **「莫大な予算とターンを投じて自軍規格に換装（Refit）するか？」**
   - **「弾薬が切れるまで前線の消耗品・肉壁として使い潰すか？」**
   - **「いっそブラックマーケットや第三国に二束三文で叩き売って現金化するか？」**
2. **旧敵国工廠の統治**:
   - **「自国直接併合で稼働率低下と治安反乱リスクを背負いながら自国規格に改修するか？」**
   - **「傀儡国家を立てて旧規格のまま兵站ループを自立させ、完成品だけ上納させるか？」**
3. **取り残された残党の処理**:
   - **「弾薬・バッテリー切れで自壊するまで遠巻きに封鎖・放置するか？」**
   - **「金を払って傭兵（PMC）として懐柔し、他戦勝国との境界線の盾にするか？」**
   - **「泥沼のゲリラ掃討戦に治安部隊を長期間拘束されるか？」**

このメカニクスにより、戦争の終結は「ゲームのクリア」ではなく、**「新たな地政学・兵站パズルの幕開け」**としてプレイヤーに極めて濃厚な体験を提供する。
