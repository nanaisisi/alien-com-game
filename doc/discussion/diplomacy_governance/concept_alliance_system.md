# 思想ベース同盟システム仕様書 (Ideology-Based Immutable Alliance System)

本作（4X大戦略・ターン制）における、**「3大思想ベースの共有による不変・不可逆な同盟ブロック」「陣営内の協調・分業・規格統合」「終局の決着形態」**に関する詳細仕様書。

---

## 1. 基本設計思想

従来の4Xゲームでありがちな「好感度メーターが変動して同盟を組んだり裏切ったりする」「金銭や一時的な取引で敵味方がクルクル変わる」という軽薄な外交システムを完全に排する。

本作では、ゲーム開始時（または序盤の基本理念選択時）に、この星（原生生態系・集合意識）に対する**「3つの根本思想のベース」**を選択・共有する。
根本思想が一致した勢力同士は**「不変・不可逆な運命共同体（同盟ブロック）」**となり、ゲーム終了まで同盟関係が破綻・変化することはない。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   3大思想の選択による不可逆な陣営決定                  │
└────────────────────────────────────────────────────────────────────────┘
   │
   ├── ①【共生・同化 陣営】        （星の生態系・意識と融合する派）
   │     └─ 同陣営内：不変の運命共同体（裏切り不可・最終的に完全同化）
   │
   ├── ②【地球化・テラフォーミング 陣営】  （星を地球環境へ完全に上書きする派）
   │     └─ 同陣営内：不変の開発・統治同盟（戦後秩序を共同管理）
   │
   └── ③【集合意識支配・家畜化 陣営】      （エイリアンを鎖に繋ぎ家畜・兵器化する派）
         └─ 同陣営内：不変の軍事・搾取同盟（資源・生体兵器を共同分配）

 ※ 思想が異なる陣営同士：妥協の余地がない絶対敵対（根本理念の全面衝突）
 ※ 同一思想の勢力間：同盟関係は恒久的であり、「関係解消・裏切り」は発生しない
 ※ 単独覇権（独自路線）：どの同盟ブロックにも属さず、全方位を敵に回す孤立選択
```

## 2. 不変同盟における陣営内ダイナミクス

同盟関係が変化し得ないからこそ、プレイヤーの外交・内政プレイは「誰を裏切るか」ではなく、**「同じ思想を掲げる同盟国と、いかに効率よく分業し、規格を統一し、敵対陣営を打ち破るか」**という協調と調整に集中する。

### 2.1 産業・兵器規格の統合（アライアンス共通規格圏）

* **コンポーネント相互供給と分業**:
  * 同盟国内の得意分野に応じた自然な産業分業が成立する（例: 連邦の重工車体 ＋ 共同体の高度電子FCS）。
  * 同盟国間では兵器プラットフォームのライセンス供与や準完成シャーシの輸入が活発化。
* **通信・データリンクの共通化**:
  * 最高機密であるC4I（通信暗号・IFF・射撃管制データリンク）の適合プロトコルを同盟国間で共有・標準化。
  * 共同艤装ドックを通じて、同盟国の兵器を即座に自軍戦闘団へ編入可能な体制を構築する。

### 2.2 合意に基づく平和的タイル移管

* **摩擦なき前線・後方の調整**:
  * [`concept_faction_consensus_and_standardization.md`](./concept_faction_consensus_and_standardization.md) に基づき、領土の奪い合いではなく、防衛線維持や補給効率を高めるための「合理的なタイル割譲・管轄移管」が同盟国間で平和的に行われる。
  * 駐留部隊は友好的に本国領内へ後退し、インフラ・施設は完全な状態で引き継がれる。

### 2.3 作戦・防衛線の連帯

* **安全保障の相互乗り入れ**:
  * エイリアンの巣窟や敵対思想ブロックからの攻勢に対し、前線タイルでの共同防衛線を構築。
  * 部門（防衛軍司令部）間のパイプを通じて、共同作戦目標の提示や哨戒情報の共有が行われる。

## 3. 陣営間（対立思想ブロック）の力学：妥協なき総力戦

* **不可逆な対立**:
  * 思想が異なるブロック同士は、この星の未来像（環境を焼き払うか、同化するか、家畜化するか）そのものが相反するため、和平条約や同盟締結は原理的に不可能。
* **冷戦から全面戦争へ**:
  * 序盤・中盤は緩衝地帯や国境線での睨み合い・代理紛争にとどまるが、最終的にはどちらか一方が屈服・降伏するまで終わらない総力戦へと発展する。

## 4. 終局（ビクトリー）における決着形態

勝利条件は「同盟ブロック全体の勝利」として決着する。

| 思想ルート | 同盟ブロック勝利の帰結 | 単独覇権（独自路線）の帰結 |
| :--- | :--- | :--- |
| **① 共生・同化** | 同盟国・他国を問わず、最終的に人類全体が星の共通意識（ガイアネットワーク）の中に溶け合い、**国家・同盟という枠組みを超えた単一の生体秩序へと完全統合**される。 | 妥協なく単独で融合を完遂し、自らが生体秩序の中枢となる。 |
| **② 地球化・テラフォーミング** | 勝利後、同盟国間で**「惑星統治連合」**を設立。星のテラフォーミング計画を共同推進し、新たな居住区・資源地帯をブロック加盟国で平和的に分配・共同管理する。 | 他国の干渉を武力で完全に排除し、自国単独の主権下で惑星全土を地球化・独占支配する。 |
| **③ 集合意識支配・家畜化** | 同盟国間で**「生体資源共同管理協定」**を締結。鎖に繋いだ巨大集合意識の制御権・生体兵器・特異資源を加盟国間で協調して分配・私物化する。 | 集合意識の制御コアを自国中枢のみが独占し、他国をすべて従属・属国化して絶対覇権を敷く。 |
