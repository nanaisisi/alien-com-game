# 状況依存型兵器体系・産業形成システム設計仕様（Dynamic Arsenal & Geospatial Industry）

本ドキュメントは、兵器体系が単なる固定ツリーや抽象パラメータとして存在するのではなく、**「地理的・立地条件（工場の位置、資源、輸送インフラ）」**および**「外交関係・国際情勢（同盟、禁輸、ライセンス、技術圏）」**というゲーム内の動的状況から**自然と淘汰・形成されていくシステム（環境・状況依存型兵器体系形成メカニクス）**の設計仕様書である。

---

## 1. コア思想：「兵器体系はゲーム内の地理と歴史（外交）が創り出す」

現実の軍事史において、兵器体系は机上の理想設計だけで決まったことはなく、常に**「どこにどんな工場があるか」「資源と港湾・鉄道がどう繋がっているか」「どの国と同盟し、誰から禁輸されているか」**によって必然的に規定されてきた。

```text
+-----------------------------------------------------------------------------------------+
| 【地理的・立地要因 (Geospatial & Logistical Constraints)】                             |
|  - 製鉄・重工コンビナートが沿岸部にあるか内陸山岳にあるか                                 |
|  - 鉄道網・河川輸送の積載限界、チョークポイント（海峡・山道）の有無                       |
|  - 前線までの兵站距離と局所的ボトルネック                                               |
+--------------------------------------------┬--------------------------------------------+
                                             │ 
                                             ▼ 相互作用
+-----------------------------------------------------------------------------------------+
| 【外交・地政学要因 (Diplomatic & Geopolitical Dynamics)】                               |
|  - 同盟国からのライセンス供与・部品依存（共同開発・標準化）                             |
|  - 敵対国による特定資源・希少モジュールの輸出規制・海上封鎖                             |
|  - 本星条約の建前と入植地における即物的な密貿易                                         |
+--------------------------------------------┬--------------------------------------------+
                                             │ 
                                             ▼ 必然的帰結
+-----------------------------------------------------------------------------------------+
| 【自然形成される兵器体系 (Dynamic Arsenal Emergence)】                                 |
|  - 例A: 沿岸重工＋同盟国電子＝「長距離対艦ミサイル搭載・重巡航戦車体系」                 |
|  - 例B: 内陸山岳＋経済封鎖＝「軽量化・多孔性セラミック＋エイリアン毒素砲体系」           |
|  - 例C: 輸送路切断＝「現地町工場での応急口径短縮型・廃車再生アセンブリ」               |
+-----------------------------------------------------------------------------------------+
```

## 2. 地理的・立地要因による兵器体系の規定メカニクス

工場が「どのタイル（親タイル環境・サブタイル位置）」に存在するかにより、生産可能なモジュール規格や輸送コストに強い物理的制約・特性バイアスがかかる。

### 2.1 タイル立地と産業機能の分業

1. **臨海・河川下流コンビナート（沿海・大河タイル）**:
   - **特性**: 大型重量物の輸送（大型船・バージ船）が容易。輸入原料の受入能力が極大。
   - **形成される兵器特性**:
     - 重量級・大型兵器（60t超の重戦車、大口径自走榴弾砲、超大型艦艇ブロック）。
     - 素材・加工の大型鍛造プレスや大開口ソナー/レーダーなど、超大型モジュール（Size Class XL）の生産拠点となる。
2. **内陸山岳・資源直結拠点（山岳・高地タイル）**:
   - **特性**: 鉱山直結で特殊金属・チタン・タングステンの純度は高いが、輸送路（山岳道路・山岳鉄道）の積載トン数制限が厳しい。
   - **形成される兵器特性**:
     - 軽量・高強度合金を用いた装甲材、山岳向け軽量装輪装甲車、牽引型・分割空輸型火砲。
     - 規格外の重量車体は搬出できず、自然と「コンパクト・高密度・機動重視」の兵器体系へ収斂する。
3. **都市・学術・内陸ハブ（平野大都市タイル）**:
   - **特性**: 労働力と電力インフラが豊富。半導体工場、精密機械加工街（町工場群）、AI研究所が集積。
   - **形成される兵器特性**:
     - 射撃管制AI（FCS）、アビオニクス、精密誘導キット、ドローン制御ユニットなどのハイテク小型モジュール（Size Class S/M）。

### 2.2 輸送インフラの物理限界と「兵装のサイズ規格（ゲージ制限）」

- **鉄道・トンネル限界（Railway Clearance / Loading Gauge）**:
  - 工場から前線基地へ通じる鉄道インフラの規格（標準軌、トンネル幅、橋梁耐荷重）が、生産・配備できる車体幅や砲身長を自動制限する。
  - 耐荷重40tの橋梁しかない内陸戦線では、重機甲戦闘団は配備できず、「装輪装甲戦闘団」や「軽量自走砲」が主力兵器体系として選択を迫られる。

## 3. 外交・国際情勢による兵器体系の動的淘汰

外交関係の変化（開戦、同盟、制裁、密約）は、産業サプライチェーンの切断と再編を直接引き起こし、兵器体系を急激に変容させる。

### 3.1 技術圏・規格ブロック（Standardization Blocs）

国家間の条約・同盟関係によって、自然と**「共通規格圏（兵器ファミリー）」**が形成される。

- **同盟・友好ブロック**:
  - 連邦C（重工・車体シャシー強み）と共同体E（電子・半導体強み）が軍事・産業同盟を結ぶと、双方が互いのモジュールを安価・迅速に融通。
  - 自然と**「連邦製頑強シャシー ＋ 共同体製高性能FCS」というハイブリッド兵器体系**が標準化され、量産効果でユニットコストが大幅低減する。
- **孤立・独自規格ブロック**:
  - 帝国Aが大国としてのプライドや外交的孤立から独自規格（独自口径・独自通信プロトコル）を維持する場合、他国との互換性はゼロになるが、他国の制裁や禁輸の影響を一切受けない「完全自給自足の独自重厚体系」を築く。

### 3.2 経済制裁・海上封鎖と「代替技術の創発」

敵国からの禁輸や輸送船団の撃沈により、特定モジュールや原材料の輸入が断たれた場合、ゲーム内システムは以下のような**「状況依存型の兵装進化（窮余の策）」**を発生させる。

1. **特定原料の欠乏による素材置換**:
   - タングステンの輸入が止まった場合、APFSDS（装弾筒付翼安定徹甲弾）の弾芯が自動的に「劣化ウラン」や「高炭素鋼（貫通力低下）」へ置換される。
   - 希土類・GaN半導体の禁輸を受けた場合、AESAレーダーの生産が停止し、旧式の「機械走査型パルスドップラーレーダー（IND-2/7共用型）」へ生産ラインが逆行・転換される。
2. **鹵獲兵器・敵対技術の現地適応（リバースエンジニアリング）**:
   - エイリアンとの局所激戦地やNPC撃破地点では、回収された生体組織や敵モジュールを現地の町工場が独自解析し、ドクトリンが「バイオ適応型兵装」へと傾斜していく。

## 4. ゲームシステムへの統合メカニクス

プレイヤーがすべての設計図をゼロから引くのではなく、**「現地の地理」×「現在の外交」**をインプットとして、ゲーム内部で利用可能な兵装選択肢や最適化案が動的に立ち上がってくる構造を採る。

```text
[立地・インフラデータ]
 (工場タイル、鉄道規格、港湾容量)
        ＋                          ───▶ 【現地の生産可能モジュール候補群】
[外交・貿易条約データ]                                │
 (同盟国の部品供給、禁輸品目)                           ▼
                                          【状況適合型 兵器パッケージの自動生成】
                                             - 「沿岸製 重砲塔仕様」
                                             - 「山岳配備用 チタン軽量仕様」
                                             - 「同盟規格ハイブリッド仕様」
                                                      │
                                                      ▼ プレイヤーの決定
                                          【軍備ドクトリン採択 / 部隊自動充足】
```

### 4.1 「開発ツリー」の撤廃と「環境創発型カタログ」

- 抽象的な「一本道の研究ツリー」ではなく、プレイヤーが支配する**「領土内の工場立地（サブタイル集積度）」**と**「締結している外交条約」**の組み合わせによって、生産可能な兵装カタログがリアルタイムにアンロック・変化する。
  - 例: 連邦と同盟を結んだ瞬間、カタログに「連邦製120mm滑腔砲モジュール」が出現。
  - 例: 山岳タイルに特殊冶金プラントを完成させた瞬間、「チタン複合装甲パッケージ」が選択可能になる。

### 4.2 前線現場の「現地改修バリアント（Field Modification）」

- 補給線が細い遠隔地や孤立した戦闘団では、現地のサブタイル施設（自動車修理工場、廃品回収所）の能力に応じて、**「現地改修型（Field Mod）」**が自動派生する。
  - 例: 砲弾補給が途絶した戦車小隊が、現地の採石場から調達した無反動砲やロケット弾ポッドを砲塔側面に溶接した「即席火力支援車」。

## 5. プレイヤー体験（UI・フレーバー演出）

### 5.1 地理・外交インスペクション

ユニットや兵装のツールチップにおいて、その兵装が**「いかなる歴史的・地理的必然性で生まれたか」**の出自（オリジン）を明示する。

```text
+-------------------------------------------------------------------+
|  105mm 自走軽突撃砲 [山岳改修型]                                  |
|  - 出自: 鉄嶺山岳工廠 (IND-1/2) ＋ 連邦C技術供与 (FCS-7A)          |
|  - 立地制約: 第3山岳鉄道の通過限界(全幅2.8m/重量22t)に適合    |
|  - 外交背景: 帝国Aによるレアメタル禁輸措置を受け、                |
|              装甲をチタン・アルミ複合材へ緊急設計変更した型式。    |
+-------------------------------------------------------------------+
```

### 5.2 外交交渉・戦争目標とのダイレクトな連動

- 「あの敵国の沿岸製鉄都市を占領すれば、我が国も60t級重戦車が量産可能になる」
- 「共同体Eとの関係が悪化すれば、最新型レーダーの補給部品が止まり、航空団が飛べなくなる」
といった、**地政学・産業拠点そのものが戦争と外交の直接的な動機（Casus Belli）**となる。
