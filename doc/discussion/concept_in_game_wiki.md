# ゲーム内Wikiシステム（In-Game Wiki / Codex）設計・実装計画

本作（4X大戦略＋サブタイル戦術・戦闘団制）における、膨大な兵器モジュール、産業マトリクス、エイリアン生態、国家・勢力設定、ゲーム内メカニクスをプレイヤーが直感的に探索・逆引きできる**「ゲーム内Wiki（Civilopedia / Codex / 兵科・産業大百科）システム」**の設計および実装計画。

---

## 1. 目的と体験設計（なぜゲーム内Wikiが必要か）

本作は「要素は細密・多層、操作は集約・自動化」をコア思想としており、裏で動くサプライチェーンやモジュール類似度、エイリアン弱点、各戦闘団の構成小隊などのデータが膨大に存在します。

1. **インスペクションUIからのシームレスなジャンプ**:
   - 戦闘団や工場パネルの「120mm滑腔砲」「オプティマ・テック製FCS」「IND-4 火器産業」などをクリックすると、即座に該当Wikiページへジャンプ。
2. **相互リンクと依存関係・ツリーの可視化**:
   - 「このモジュールは何に搭載できるか？」「この素材はどの産業で必要か？」「このエイリアンにはどの兵器が有効か？」をWikipediaライクにハイパーリンクで探索可能。
3. **データ駆動（Single Source of Truth）による完全同期**:
   - Wikiの解説文やパラメータをゲーム本体のデータ定義（Rustコード／データ定義ファイル）から自動生成・同期し、メンテナンスコストと表記ブレをゼロにする。
4. **発見・調査によるアンロック（Fog of Lore / Dynamic Codex）**:
   - 最初から全情報を開示するのではなく、未知のエイリアンや古代遺跡、敵国技術は実戦交戦や調査団による研究進捗によって記事が順次アンロック・追記される。

## 2. Wikiコンテンツの分類と構造

Wikiは以下の主要カテゴリーに体系化される。

```text
【ゲーム内Wiki (Codex) の情報構造】
├── 1. 兵器・モジュール体系 (Armaments & Modules)
│    ├── モジュール図鑑（砲身・装甲・FCS・推進器・APS等）
│    ├── 類似性・系譜ツリー（親モジュール・派生型・共通化グループ）
│    └── 接続性マトリクス（サイズ階層・搭載可能戦闘団・スロット要件）
├── 2. 産業・サプライチェーン (Industries & Logistics)
│    ├── 8大産業ジャンル（素材、重工、動力、火薬、航空、造船、電子、AI）
│    ├── 産業間接続マトリクス（転用効率・サプライチェーン相関図）
│    └── サブタイル施設図鑑（コンビナート、町工場、ポンプ場、浄水施設等）
├── 3. 部隊・戦闘団体系 (Units & Combat Groups)
│    ├── 陸上戦闘団・艦隊・航空団の規定編成と小部隊内訳
│    ├── 多種族混成・技術融合バリエーション
│    └── 戦術ドクトリンと補正一覧
├── 4. エイリアン・生態・脅威 (Xeno-Biology & Threats)
│    ├── 生態分類・生息地域・弱点属性（熱・酸・電磁・運動等）
│    ├── 危険度ランク・ドロップ素材・変異種
│    └── 調査進捗度による段階的情報開示（0% 〜 100%）
├── 5. 勢力・国家・歴史 (Factions & World Lore)
│    ├── 各国家・種族の特徴、固有特性、主要企業・メーカー
│    └── 外交関係・歴史的経緯・事件年表
└── 6. ゲームメカニクス・ヘルプ (Game Concepts & Rules)
     ├── 戦術戦とオートリゾルブのルール
     ├── サプライチェーン伝播と部品品質
     └── 用語集（用語ホバーツールチップと連動）
```

## 3. システム・アーキテクチャ設計

### 3.1 データ構造（Rust側設計イメージ）

データ定義にメタデータ（名前、解説、アイコン、カテゴリー、タグ、前提アンロック条件）を付与し、Wiki記事エントリーを構築する。

```rust
pub struct WikiEntry {
    pub id: String,                    // e.g. "mod_120mm_smoothbore"
    pub category: WikiCategory,        // e.g. WeaponModule
    pub title: String,                 // 表示タイトル
    pub summary: String,               // 概要文（ホバーチップ用にも兼用）
    pub body_markdown: String,         // 本文（リッチテキスト／Markdown）
    pub tags: Vec<String>,             // 検索用タグ
    pub related_entries: Vec<String>,  // 関連ページID
    pub unlock_condition: UnlockState, // 開示条件（常時 / 調査率 / 技術取得）
    pub dynamic_stats: DynamicData,    // ゲーム内実数値（攻撃力、重量、類似度等）
}
```

### 3.2 記事自動生成パイプライン（Single Source of Truth）

- 各モジュールや産業ジャンルの実データ（Rustの構造体・定数・設定ファイル）から、スペック表や接続・類似度グラフを自動レンダリング。
- ゲームバランス調整で威力が変わっても、Wiki内の数値は自動追従するため手動更新が不要。

### 3.3 UI・UX仕様

- **グローバルアクセス**: 画面右上アイコン または キーボードショートカット（`F1` / `Ctrl+W`）でどこからでもオーバーレイ表示。
- **コンテキスト連動（F1ヘルプ / 右クリック）**: 画面上の任意のモジュール、ユニット、施設を右クリックまたはF1押下で、該当Wiki記事に直接ダイレクトジャンプ。
- **高速インクリメンタル検索**: あいまい検索、タグ検索（「火薬」「徹甲」「装輪」など）、履歴（進む・戻るボタン）、お気に入り（ピン留め）。
- **用語ホバーツールチップ**: UIや他のWiki記事内の青色リンクテキストにマウスを乗せると、Wikiの要約カードがポップアップ。

## 4. 開発ステップ（マイルストーン）

### Step 1: ドキュメント化とWikiデータ仕様策定（本フェーズ）

- `doc/discussion/concept_in_game_wiki.md` を作成し、Wikiシステムの詳細仕様、リンク構文、アンロック段階基準を定義。

### Step 2: データモデル＆Codexレジストリ（Rust基幹）

- `WikiEntry`、`WikiCategory`、検索インデックス、アンロック判定のデータ基盤実装。
- 既存の兵器モジュール・産業マトリクス定義と結合。

### Step 3: UIビューアー＆相互リンクレンダリング

- 検索バー、カテゴリツリー、本文レンダリング、進む/戻るナビゲーションの実装。
- ホバーツールチップ機構の実装。

### Step 4: ゲーム内インスペクション連動＆動的アンロック（Fog of Lore）

- ユニット詳細パネル・産業パネルからの直接ジャンプ機能。
- エイリアン調査団・交戦データによる動的記事追記機能の連携。
