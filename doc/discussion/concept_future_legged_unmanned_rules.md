# 未来基準・歩行車両・無人化の体系的検討（3ルール設計仕様書）

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「未来基準（SF世界観の定常化と技術水準）」「歩行車両（多脚・二脚兵器の必然性）」「無人化（自律兵器と人間性の境界）」**という3つの重要要素を、相互に矛盾なくゲームシステムとして機能させるための**3大ルール（設計原則）**を定義・体系化したものである。

---

## 1. 全体像と3ルールの相互連動

SF作品において「二足歩行ロボット」「完全自律ドローン」「超未来テクノロジー」を無秩序に投入すると、世界観の説得力（リアリティの破綻）や、既存の装軌・装輪兵器とのバランス崩壊を引き起こす。
本作では、これらを**「過酷な異星環境（地勢・電磁・生態系）」**と**「産業サプライチェーンの制約」**という共通基盤から導き出し、以下の**3つのルール**で規定する。

```text
+-----------------------------------------------------------------------------------------+
| 【ルール1：未来基準の日常化・定常化 (Rule of Normalized Futurity)】                    |
|  - 「超未来」は奇跡ではなく定常インフラ。技術進化は性能インフレではなく適応の多様化。   |
|  - 旧地球規格（物理・重工）vs 異星適応規格（生体・超伝導・局所最適）の断絶と相克。      |
+--------------------------------------------┬--------------------------------------------+
                                             │ 必然性の供給
                                             ▼
+-----------------------------------------------------------------------------------------+
| 【ルール2：歩行車両の排他機能主義 (Rule of Exclusive Legged Utility)】                 |
|  - 「戦車の上位互換」ではなく「装軌・装輪が物理的に進入・踏破不能な極限環境の開拓具」。|
|  - 接地圧・姿勢制御・三次元不整地（裂罅・エイリアン樹海・結晶地帯）の踏破に特化。       |
+--------------------------------------------┬--------------------------------------------+
                                             │ 運用形態の収斂
                                             ▼
+-----------------------------------------------------------------------------------------+
| 【ルール3：無人化の階層的限界と倫理線 (Rule of Hierarchical Autonomy & Kill-Chain)】    |
|  - 電子戦・瘴気擾乱による「通信途絶下での自律（エッジAI）」と「母艦・有線ネットワーク」|
|  - 消耗品としての端末型無人機 vs 責任・判断を担保する有人指揮ノードの明確な二層化。    |
+-----------------------------------------------------------------------------------------+
```

## 2. ルール1：未来基準の日常化・定常化（Normalized Futurity）

### 2.1 思想：「未来」は驚異ではなく、維持すべき日々の足場である

- **日常化した超技術**: 核融合炉、常温超伝導、ナノコーティング、自動照準AIなどは「特別に開発するチート技術」ではなく、すでに社会の底流にある**コモディティ（日用品）**である。
- **制約こそが未来基準を形作る**:
  - 地球本星から切り離された植民惑星では、「ハイテク部品を生産する希少レアメタルの枯渇」「精密工場の維持部品の欠乏」こそが日常の戦いとなる。
  - したがって技術発展は「数字のインフレ」ではなく、**「手持ちの限られた資源で、いかに機能を代替・局所適応させるか（ローカライズ）」**に向かう。

### 2.2 ゲームメカニクスへの落とし込み

1. **技術アフィニティ（二大潮流の相克）**:
   - **地球純血派（Orthodox Terran）**:
     - 高信頼性、重工業、内燃・核分裂、均質装甲、モジュールの互換性・大量生産性に優れる。
     - 欠点：極限環境（瘴気・電磁嵐）での摩耗・故障率が高く、地球系特有の希少鉱物サプライチェーンに依存。
   - **惑星適応派（Xeno-Adaptive / Native）**:
     - 異星原生生物の外殻素材、常温バイオケミカル、自己修復セラミックを採用。
     - 利点：現地調達率が高く、エイリアン環境（酸性雨、結晶地帯）への完全耐性。
     - 欠点：工業規格が歪で他国との互換性が低く、熟練の生体工学技師を要する。
2. **「定着した未来」のコスト感覚**:
   - 高度な技術（例: プラズマ荷電砲、アクティブ光学迷彩）ほど、平時の維持費・冷却リソース・整備工数が跳ね上がり、経済力のない勢力では「配備しても前線で動かせない」という経済的淘汰を受ける。

## 3. ルール2：歩行車両の排他機能主義とロマン枠（Exclusive Utility & Flawed Romance）

### 3.1 思想：「どこでも行ける万能」ではなく「不便さの多いロマン・限定枠」

「歩行車両ならどこでも行ける」という全地形万能主義は採用しない。現実の力学・機構学と同様、歩行脚は装軌（キャタピラ）や装輪（タイヤ）に比べて**極めて多くの構造的弱点、低いエネルギー効率、膨大な整備工数、故障リスク**を抱えている。

したがって、歩行兵器は「万能の主力」ではなく、**「欠点や不便さにまみれつつも、特定の極限環境やロマン的ドクトリンから運用される限定枠（未確定・要議論深化枠）」**として位置づける。

```text
【地形適正と機構的リアリズム】
・平原・舗装路   : 装輪（Wheel）   >> 圧倒的高速・高燃費・容易な整備
・泥濘・湿地・荒地: 装軌（Track）   >> 高接地圧分散・重装甲積載（陸戦の王道）
・裂罅・密林・岩礁: 多脚（Multi-leg）>> 段差跨越は可能だが、極めて鈍重・整備困難・高故障率
・垂直高低差・廃墟: 二脚（Bipedal）  >> 高所観測・限定跳躍。だが転倒脆弱・極小積載の「極端な尖り枠」
```

### 3.2 歩行車両の2大分類と課題（議論深化事項）

#### ① 多脚歩行車両（Quad / Hexapod - 4脚/6脚）:「鈍重・高整備負荷の特殊工兵・重砲台」

- **機能・特徴**:
  - **段差跨越・姿勢安定**: 裂罅や岩礁など特定の難地形を「跨ぎ越す」能力、杭打ち固定（アンカー）による反動相殺。
  - **脚部冗長性**: 複数脚による冗長性はあるが、アクチュエータや関節サーボの摩耗が激しい。
- **現実的な不便さ・欠点**:
  - **圧倒的な鈍重さ**: 平地巡航速度は装輪・装軌の半分以下。
  - **兵站の悪夢**: 多数の関節・油圧・シーリングを異星の砂塵・瘴気から守るための整備時間・部品消費が極大。
  - **軟弱地盤での埋没**: 泥濘や砂地では単位面積あたりの接地圧が集中し、キャタピラ以上に足を取られやすい。

#### ② 二脚機動兵器（Bipedal / Light Walker）:「脆弱性と表裏一体のロマン枠」

- **機能・特徴**:
  - **高所射線・立体観測**: 立ち上がりによる遮蔽越しのセンシング、急斜面での限定的跳躍。
- **現実的な不便さ・欠点**:
  - **致命的なバランス脆弱性**: 片脚の被弾・関節ロック・足場の崩壊で即座に転倒・行動不能。
  - **装甲の制約**: 重装甲化すると自重で脚部フレームが持たないため、極めて薄い装甲しか持てない。
  - **運用性の低さ**: 戦術的メリットに対して生産・整備コストが釣り合わない「実験機・ロマン兵器」の域を出にくい。

> [!IMPORTANT]
> **歩行兵器の定義と位置づけに関する継続議論**:
> 独立した「歩行戦闘団」として大戦略マップに常備配備するのか、あるいは特定の戦闘団に対する「特殊工兵アタッチメント」「極限地形用オプションモジュール」とするのか、ゲームシステム上での扱いをさらに深める必要がある。

## 4. ルール3：無人化の階層的限界と倫理線（Hierarchical Autonomy & Kill-Chain）

### 4.1 思想：「完全自律の万能無人軍」が存在しない理由

作中世界において、完全無人兵器だけで戦線が完結しない理由は**「過酷な電子戦・瘴気ノイズ」**と**「キルチェーン（交戦責任）の法的・倫理的デッドロック」**にある。

1. **電磁・瘴気擾乱（EW & Miasma Interference）**:
   - 遠隔操作（リモートコントロール）は、前線の強いジャミングやエイリアン胞子帯（電波散乱媒質）によって容易に切断される。
   - したがって、遠隔操縦型ドローンは「母艦・指揮車から見通し数キロの直視圏内」でしか使えない。
2. **エッジAIの計算限界と「友軍誤射・暴走リスク」**:
   - 通信途絶下で自律行動するスタンドアローン型端末は、搭載できる推論プロセッサの制約から「敵味方識別（IFF）の誤認」や「騙され（敵のデコイへの釣られ）」が多発する。
   - 完全自律兵器による友軍誤爆・民間虐殺を防ぐため、最終的な射撃承認権限（Human-in-the-loop）が必須とされる。

### 4.2 無人化の3階層（Tier）システム

```text
+-----------------------------------------------------------------------------------------+
| [Tier 1: 消耗型自律端末 (Attritable Swarm / Loitering Munition)]                        |
|  - 自爆ドローン、超小型偵察UAV、地雷型クモ型UGV                                         |
|  - 役割: 使い捨ての目と槍。母機から放出され、単純アルゴリズムで目標へ突入。             |
|  - コスト極小、装甲ゼロ、補給不要（撃ちきり消耗品扱い）。                               |
+--------------------------------------------▲ 制御・射出
                                             │
+-----------------------------------------------------------------------------------------+
| [Tier 2: 随伴型無人僚機 (Loyal Wingman / Autonomous Escort)]                            |
|  - 無人多脚砲台、無人装甲車（UGV）、護衛戦闘UAV                                          |
|  - 役割: 有人指揮ユニットの「盾」「弾薬庫」「追加火力」。高度なFCSと防護装甲を持つ。     |
|  - 単独では作戦行動不可。半径Nマス以内に「有人母機」が存在しないと能力が半減。          |
+--------------------------------------------▲ 統制・指示
                                             │
+-----------------------------------------------------------------------------------------+
| [Tier 3: 有人指揮結節 (Manned Command Node / Cockpit Unit)]                            |
|  - 指揮装甲車、有人重歩行車両、前線航空統制機                                           |
|  - 役割: 戦場全体の状況判断、交戦承認、強力なEW対抗ノード（暗号化ローカルメッシュ展開）。|
|  - 搭乗員の疲労・生命維持（生命維持装置、脱出装置）のリソースを消費するが、戦線の中核。|
+-----------------------------------------------------------------------------------------+
```

### 4.3 ゲームプレイにおけるトレードオフ

- **有人主体の部隊**:
  - メリット: 電子戦（ECM）に極めて強く、状況に応じた臨機応変な射程・陣形変更が可能。士気・経験値（ベテランボーナス）が蓄積する。
  - デメリット: 人命損失による国内世論・政治支持率（War Weariness）の低下。生命維持モジュールの容積圧迫による積載兵装の減少。
- **無人主体の部隊**:
  - メリット: 人命損失ゼロで世論の反発がない。G耐性や生存空間が不要なため「極小サイズに大口径火器」を積める。
  - デメリット: 強力なジャミングを受けると行動停止や誤射を起こす。Tier 3の指揮ユニットを撃破されると部隊全体が崩壊（機能麻痺）する。

## 5. 3要素が融合した戦闘団（Battlegroup）の運用具体例

サブタイル戦術マップ（343マス）において、本3ルールがどのように有機的に組み合わさるかの実例。

### 事例：山岳裂罅・瘴気森林突破作戦

```text
[作戦環境]
・地形: 深い裂罅（クレバス）と巨大樹木が密集し、一般の装軌戦車・装輪車は侵入不可。
・環境: 濃厚な瘴気により広域衛星通信・長距離無線リンクが完全遮断（強ECM環境）。

[編成（戦闘団アセンブリ）]
1. 【有人指揮二脚車両（Tier 3 / High-Mobility Walker）】× 1両
   - コックピット＋広帯域レーザー通信マスト＋局所FCSを搭載した高機動二脚機。
   - 樹上や断崖を登攀して高所から俯瞰視界を確保し、有線・近距離光通信で僚機を統制。
2. 【支援無人四脚砲台（Tier 2 / Quad UGV Heavy Mortar）】× 2両
   - クレバスを跨いで進出し、4脚アンカーで反動を完全に殺して大口径迫撃砲・徹甲ロケットを曲射。
   - 人員が乗らないため、空いた容積すべてに弾薬コンテナを満載。
3. 【自律マイクロ偵察群（Tier 1 / Swarm Crawlers）】× 多数
   - 樹海の下層を這い回り、敵エイリアン巣窟や敵潜伏歩兵をサーマル探知して即座に母機へピン留め。
```

このように、

- **未来基準の日常化**（過酷環境下での機能限定と局所適応）
- **歩行車両の排他機能主義**（クレバスと高低差を克服するための脚部）
- **無人化の階層構造**（電波遮断下での有人光通信ノード＋無人弾薬庫砲台）
が組み合わさることで、「ただのロボット自慢」ではない**「極めて説得力のあるリアルなSF戦術体験」**がプレイヤーに提示される。

## 6. まとめと今後のシステム拡張項目

1. **車体（Chassis）モジュールの選択肢拡張**:
   - `ChassisType`: `Wheel`（装輪）, `Track`（装軌）, `Hover`（浮上）, `MultiLeg`（多脚）, `Bipedal`（二脚）。
   - 各Chassisに「地形走破プロファイル（段差許容度、泥濘耐性、登坂力）」と「反動許容値（アンカーボーナス）」を紐付け。
2. **指揮・制御リンク（C2 Link / Kill-Chain）の属性**:
   - 部隊内に「Tier 3 有人ノード」が存在するかを常時判定。通信妨害度（Jamming Index）に応じて無人ユニットの命中率・行動可否が動的に変動。
3. **産業チェーンとの連携**:
   - 脚部関節アクチュエータ（高トルク人工筋肉・油圧シリンダ）は精密機械・高度合金工場を要求し、装軌・装輪よりもサプライチェーンの高度化を要する。
