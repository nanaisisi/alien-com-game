# 惑星人口動態・人工子宮工学および生物種変容論（人口動態検討仕様書）

(Planetary Demographics, Ectogenesis Engineering, Reproductive Divergence & Speciation Dynamics)

本ドキュメントは、本作における**「母星の極限少子化に伴う人工子宮（体外発生・生体培養）技術の導入」「入植フロンティアにおける自然出産と人工生殖の二重構造」「異星生態系（エイリアン）との相互作用に伴う人類の生物種としての変容・分化（スペシエーション）」**を体系化した設計仕様書である。

## 1. 根本背景：母星の超少子化と「人工生殖社会」への移行

### 1.1 母星（地球）自体がすでに人工生殖社会へ転換している必然性

人工子宮（Ectogenesis）は「宇宙船のためだけに突如発明された実験的技術」ではない。
恒星間船団を建造する以前の段階で、**母星（地球）自体がすでに自然出産中心の社会から、人工生殖・人工子宮を基軸とする社会体制へ移行を完了している**。

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                      母星（地球）の人口動態パラダイムシフト            │
 │   1. 伝統的家族・自然出産の衰退（少子化の極限進行と個人の自由化）       │
 │   2. 国家生存をかけた「計画的人工生殖・人工子宮」のインフラ化          │
 │   3. 必要最適数のみを生産・教育する「厳密な計画人口社会」の定着        │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
 ┌────────────────────────────────────────────────────────────────────────┐
 │                 なぜ「生身の大量移民」ではなく「受精卵＋ポッド」か？   │
 │   ・母星の環境収容力（熱・資源・生態系）の飽和による外星分散の必然性   │
 │   ・計画社会ゆえに「宇宙へ捨てる余剰成人人口」が存在しない             │
 │   ・生身成人の恒星間輸送は代謝・質量コスト（ロケット方程式）が最悪     │
 │   ・「現地に到着してから社会を解凍する」超合理的ブートストラップ       │
 └────────────────────────────────────────────────────────────────────────┘
```

1. **母星での不可逆な少子化と「計画的人工生殖社会」への移行**:
   - 地球文明の後期、個人の自由化、経済的負担、環境不安により自然出産率は劇的に低下し、いかなる財政インセンティブや伝統的家族観も少子化を止められなかった。
   - 国家機能とインフラを維持するため、各国政府は「妊娠・出産を個人の生殖本能・身体的負担に依存しない」政策へと舵を切り、**公的生体培養施設（人工子宮センター）が社会の基本インフラ**となった。
   - 人口は自然増減ではなく、社会の必要維持コストに合わせて「必要な数だけ計画生産される」体制が定着し、**「子どもが人工ポッドから生まれ、公的カリキュラムで育つこと」は日常の既成事実**となった。

2. **なぜ「生身の大量移民船」ではなく「受精卵＋人工子宮」なのか？**:
   - **母星の環境収容力（キャパシティ）の飽和**:
     - 人工生殖技術があっても、地球上の資源、居住可能圏、排熱限界、生態系への負荷はすでに限界を迎えており、「地球上でこれ以上人口を増やすこと」が不可能だった。文明の存続とリスク分散（破滅的回避）のため、外星への生存圏拡大が不可避となった。
   - **「余剰人員」の不在**:
     - 厳密に最適化された計画人口社会であるため、かつての植民地時代のように「職にあぶれた失業者や過剰人口を船に乗せて厄介払いする」ような余剰成人人口が存在しない。社会の歯車として機能している成人を大量に宇宙へ引き抜くことは社会システムの混乱を招く。
   - **生身輸送の物理的・エネルギー的無謀さ（ロケット方程式）**:
     - 何十年〜何百年にも及ぶ恒星間航海において、生身の成人数万人を生かすための食糧、酸素、水、居住空間、心理維持設備の重量は天文学的であり、推進剤の必要量を指数関数的に跳ね上げる。
     - **「すでに母星で日常的に完成・確立されている人工子宮設備と、数万〜数十万人分の遺伝子ライブラリ（凍結胚）」**を積み、極少数の専任クルー（十数人〜数百人）がコールドスリープで船を誘導・管理する方が、工学的・経済的に何百倍も合理的である。

## 2. 人口生産の二重構造：人工子宮 vs 自然出産

惑星降着後、文明が直面する人口増加メカニクスは、**「工業的人口増殖（人工子宮）」**と**「社会的生活・世代交代（自然妊娠・出産）」**という異なる特性・コストを持つ二つの軸で推移する。

```text
  【人工子宮・生体培養ポッド (Industrial Ectogenesis)】
    - 生産速度: 高（数ヶ月〜1年で胎児成育）
    - 資源コスト: 莫大な高純度アミノ酸、電力、無菌培養液、医療半導体
    - 人口性質: 遺伝的欠陥のスクリーニング済み、規格化された労働力
    - ボトルネック: 高度工作機械・バイオプラントの維持限界

  【自然妊娠・出産・家族社会 (Biological Reproduction)】
    - 生産速度: 低（妊娠10ヶ月＋成人まで15〜20年の投資スパン）
    - 資源コスト: 一般食糧、住宅、家庭内ケア、初等教育
    - 人口性質: 予測不能な遺伝的多様性、強い地域帰属意識、高い精神的安定
    - ボトルネック: 異星環境（重力・放射線・未知の毒素）による生殖障害
```

### 2.1 人工子宮の段階的制約と「培養の壁」

人工子宮は無尽蔵に人間を吐き出す魔法の箱ではない。
入植初期の工業ブートローダーと直接連動する：

1. **Stage 0（初期解凍と即応労働力）**:
   - 宇宙船の生命維持リアクター直結で、初期ロット（数百人規模）を培養・育成。
   - 成長促進（ホルモン・代謝加速）はテロメア短縮や神経変性リスクを伴うため、基本的には「15〜18年の実成育」または「幼児期までの人工保育＋早期技術訓練」が必要。
2. **Stage 1（バイオケミカル消耗品の枯渇）**:
   - 宇宙船持参の「合成羊水」「高純度栄養塩」「無菌フィルター」が数年で尽きる。
   - 現地の動植物から抽出した有機化合物で代替培養液を精製できなければ、**人工子宮ラインは停止する**（産業サプライチェーンとの完全同期）。
3. **Stage 2（社会統合の歪み・世代間格差）**:
   - 「ポッド生まれ（Pod-born）」と「自然出産（Natural-born）」の間で、社会階層意識、文化的帰属意識、権利意識の軋轢（分断）が生じる。

## 3. 異星環境・エイリアンとの相互作用と「生物種としての変容」

人類がこの惑星で世代を重ねる（第2世代〜第4世代以降）につれ、**「地球人類のままでは生き残れない」**という冷徹な淘汰圧と、現地の生態系（エイリアン動植物・微生物）からの不可逆な影響により、人類自身が**生物種として分岐・変容（Speciation）**していく。

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                  異星環境（エイリアン生態系）の淘汰圧                  │
 │   ・未知の胞子、大気成分、重力差、微小重金属、強烈な紫外線・磁気嵐     │
 │   ・「地球規格の生体防御」では、呼吸器疾患・不妊・免疫不全で死に至る   │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │
                 ┌───────────────────┴───────────────────┐
                 ▼                                       ▼
     【受動的変容：エピジェネティクス】       【能動的変容：遺伝子改変・生体共生】
     ・風土病への自然抗体獲得                 ・人工子宮胚へのゲノム編集
     ・現地共生菌による腸内叢・肺組織置換     ・エイリアン生体組織・酵素の組み込み
     ・自然出産の高流産率を越えた適応児       ・重力・大気耐性ハイブリッド種族の創出
```

### 3.1 生物種としての3大分化経路（Speciation Factions）

国家や共同体の統治思想と、採用する人口・バイオ政策によって、住民の「生物としての姿」が乖離していく。

```text
                          ┌───────────────────────────┐
                          │   人類の生物種的分岐軸    │
                          └─────────────┬─────────────┘
          ┌─────────────────────────────┼─────────────────────────────┐
          ▼                             ▼                             ▼
   【純血地球主義】              【適応型共生変容種】          【特化型人工デザイナー種】
 (Earth-Pure Preservation)      (Bio-Symbiotic Adaptation)    (Industrial Engineered Strains)
 ・大気密閉ドームに固執         ・エイリアン微生物・胞子を     ・人工子宮による目的別生体設計
 ・厳格な遺伝子保護政策           腸内・粘膜に共生導入         ・高重力・軍事・強靭代謝の付与
 ・「地球人」の純血統を誇るが   ・防護マスクなしで大気呼吸可能 ・世代を超えて形質が遺伝し、
   環境適応コストが指数増大     ・自然交配で適応形質を次世代へ   新たな人類の亜種として定着
```

1. **純血地球主義（Earth-Pure Strain）**:
   - 「われわれは地球の人間である」というアイデンティティを保つため、人工子宮でも遺伝子改変を拒否し、密閉ドーム・空気清浄・完全殺菌食糧で暮らす。
   - **メリット**: 後発移民（地球から新たに降着した勢力）との親和性・外交的信頼が高い。
   - **デメリット**: ひとたびドームやフィルターが破壊されると即死・全滅。入植地の拡大コストが極めて高い。
   - **交配関係**: 他の変容種との交配も生物学的には可能だが、純血主義のイデオロギー的・宗教的禁忌として「血の混交」を忌避・処罰する。

2. **適応型共生変容種（Alien-Symbiont / 土着適応人類）**:
   - 異星の微生物、植物花粉、共生菌を体内に取り込み、粘膜や肺胞を進化させた人々。
   - 現地大気を直接呼吸でき、現地の非加熱動植物を消化吸収できる。
   - **交配と生殖のダイナミズム**:
     - **生殖能力は完全に維持されており、むしろ自然出産を通じて適応形質がより強固に子孫へ遺伝・定着する**。
     - 地球から来た後発移民や純血派と自然交配した場合、その子どもは「異星適応形質を受け継いだハイブリッド（雑種強勢）」となり、世代を追うごとに適応遺伝子がコミュニティ全体へ自然拡大していく。
     - 母星の旧式倫理観を持つ勢力からは「エイリアン混じりの変異体」と蔑視される一方、フロンティアでは最も生命力に満ちた新世代となる。

3. **特化型人工デザイナー種（Industrial Engineered Strains）**:
   - 人工子宮ラインを国家工廠と見なし、鉱山労働、重装甲歩兵、電磁嵐耐性など、過酷なフロンティア環境を力尽くで制覇するための生体設計が施された人々。
   - **交配と定着**:
     - 単なる使い捨てのクローンではなく、**生殖機能を保持しており、彼ら同士や他系統との交配によって「強靭な形質を持つ新人類の部族・血統」として惑星に根を下ろす**。
     - 人工子宮で作られた第1世代から、自然交配による第2世代・第3世代へと広がるにつれ、「国家の所有物」から「独自のアイデンティティと生存権を主張する新民族」へと進化し、独立運動や政治勢力化の火種となる。

## 4. 人口動態のゲームシステム・パラメータ設計

ゲームメカニクスとして、人口は単なる「数値（頭数）」ではなく、**「身体の適応度」「生産手段（ポッド vs 自然）」「文化的断絶」**を持つ動的アセットとして管理される。

### 4.1 コア・ステータス

| パラメータ | 意味・影響 |
| --- | --- |
| **総人口（Headcount）** | 労働力・兵力の供給母体。 |
| **環境適応係数（Planetary Fitness）** | 0%（地球純血・完全防護服必須）〜 100%（外気呼吸・現地食糧完全適応）。維持費と病気罹患率に直結。 |
| **生殖バランス（Ecto vs Natural Ratio）** | 人口のうち人工子宮出身者と自然出産出身者の構成比。社会連帯感や暴動率に影響。 |
| **遺伝的健全度（Genetic Integrity）** | クローンや人工培養の繰り返しによるエラー蓄積度。低下すると先天奇形・突然死・不妊率が上昇。 |

### 4.2 ゲーム進行における「人口の戦略的ジレンマ」

1. **急激な人口増殖の代償（ポッド乱用の罠）**:
   - 人工子宮をフル稼働させれば数ターンで労働力・前線歩兵を倍増できる。
   - しかし、彼らを成育・教育するための高純度物資、消費財、社会教育が追いつかず、**「スラム化」「低技能労働者の余剰」「反乱予備軍」**化する。
2. **自然出産の防衛（人口再生産の安定性）**:
   - 自然出産による人口増は遅いが、維持コストが安く、住民の士気（Morale）の根幹となる。
   - しかし、異星の未知のウイルスや毒性胞子嵐が襲来した際、妊婦や新生児が最初に被害を受け、**「向こう10年間の労働力再生産が途絶する」**致命的危機に直面する。
3. **「エイリアンとの境界線」をめぐる内戦・対立**:
   - 劣勢に立たされた国家が、生き残りのために「現地のエイリアン生体組織や遺伝子」を人工子宮ラインに混ぜて急進的な適応兵士を造り始めたとき、国内の保守派市民や他国から「人道に対する罪・外星生物への堕落」として激しい非難・宣戦布告を受ける。
