# 未作成・不足ドキュメント体系と開発ロードマップ (Missing Documents & Expansion Roadmap)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「現在何が不足しており、今後どのドキュメントを段階的に作成・発展させていくべきか」**を体系的にまとめた設計ロードマップ管理書です。

---

## 1. ドキュメント整備状況の俯瞰（成熟度マトリクス）

現在のプロジェクトは、「軍事・戦術・兵器設計」および「占領・統治・産業基盤」に関するハイレベルな議論は豊富に揃っている一方、**ゲームをプレイ可能な4Xゲームとして完結させるための「イベント・物語」「ゲーム進行・勝利条件」「都市内政」「研究ツリー」が空白**となっています。

```text
【領域別のドキュメント充実度】
・軍事・兵器・戦術ルール : ★★★★★ (ほぼ網羅。歩行兵器や共通化の整理完了)
・産業・サプライチェーン : ★★★★☆ (3層構造、コンビナート、共通化を網羅)
・外交・占領・戦後処理   : ★★★★☆ (降伏処理、二重経済、統治方式を網羅)
・世界観・開拓背景       : ★★★☆☆ (100年の時間差、国家概念の枠組みあり)
──────────────────────────────────────────────────────────────────────────
・イベント・ナラティブ   : ★☆☆☆☆ (ロジック枠組みのみ。中身・具体例が未作成)
・進行フェーズ・勝利条件 : ★☆☆☆☆ (ゲーム開始から終了への流れが未作成)
・都市内政・人口・政策   : ★☆☆☆☆ (都市成長、食糧、治安の仕様が未作成)
・研究開発・技術ツリー   : ★☆☆☆☆ (アフィニティ別ツリーの構造が未作成)
・基本経済・リソース品目 : ★★☆☆☆ (一次資源・中間部品の具体項目が未作成)
```

## 3. 段階的な作業ステップ（作業フェーズ）

不足ドキュメントを一気に作るのではなく、相互依存関係に沿って段階的に作成・保存していきます。

```text
【ステップ1: 物語とドラマの注入（最優先）】
  └─ concept_event_catalog_and_chains.md の作成
     （ゲームが面白くなる具体的な事件・選択肢・連鎖を充実させる）

【ステップ2: ゲームの骨格と終わりの定義】
  └─ concept_game_progression_and_victory.md の作成
     （開拓初期から大戦争へのフェーズ移行、勝利条件を定義）

【ステップ3: 大戦略の足腰（内政と研究）】
  ├─ concept_city_growth_and_governance.md の作成（都市・人口・食糧）
  └─ concept_technology_tree_structure.md の作成（技術ツリー・研究開発）

【ステップ4: 経済・生態系のディテール】
  ├─ concept_resource_economy_and_logistics.md の作成（資源品目・物流）
  └─ concept_alien_lifecycle_and_nest_mechanics.md の作成（エイリアン生態）
```
